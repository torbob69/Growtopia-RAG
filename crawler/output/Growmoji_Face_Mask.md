# Growmoji Face Mask

When you're tired of using all those crazy facial muscles, this mask is here to help! Hide your tired human face with this reliable, totally-not-creepy one instead!

The **Growmoji Face Mask** is an unsplicable face item which was added as part of Player Appreciation Week 2018.
##  Function
When equipped, Growmoji Face Mask serves a fully cosmetic purpose.
