The **Battle Pet Cage** is a splicable non-solid foreground block which was added as part of the Pet Battles update.
##  Function     _Main article:Pet Battle Abilities_
A Battle Pet Cage can be used to train a battle pet, which can be used to fight Pet Trainers or other players.
First, one needs to determine the pet to use for fighting. Each pet has a different ability, so using the correct pet and ability combination is important. Once it is put into a cage, it cannot be removed. Only pets of the same type can be used in a Battle Pet Cage, unless a CRISPR Technology is used.
Then, gene-splice a new ability on top of the first pet. Each gene-splice costs 10 World Locks. When used, the pet is also gone forever. Another pet needs to be gene-spliced, to have a set of three pets. Two battle pet sets are required to for a Battle Leash.
Placing the finished sets of battle pets into a Battle Leash to finish this entire process.
