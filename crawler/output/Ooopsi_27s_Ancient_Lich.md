##  Function
Lich life!

RIP!

When equipped, the **Ooopsi's Ancient Lich** grants the _Build Range: Ooopsi's Ancient Lich_ mod, which allows the player to build one tile further.
##  Trivia
  * This item is sponsored by Ooopsi for completing all the Epic Quests.
  * The Ooopsi's Ancient Lich uses the same sprite as the following items:
    * Dungeons Shopkeeper
    * Dungeons Cryptkeeper
  * This item is inspired by the Ancient Lich, a character from the open-source, turn-based strategy game, The Battle for Wesnoth.
