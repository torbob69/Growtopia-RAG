The **Angry Adventure Gorilla** is a splicable toggleable deadly foreground block which was added as part of The Adventure Pack Strikes Back! update on June 1, 2017.
##  Function
It kills any player who touches it but will let them pass for ten seconds if they feed it an Adventure Item - Banana.
##  Trivia
  * The sprite is a reference to the 1981 arcade game Donkey Kong.
