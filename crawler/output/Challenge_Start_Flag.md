# Challenge Start Flag

Use this with a Challenge Timer. Wrench it to set an ID, so it knows which Challenge Timer to work with.
Properties
This item never drops any seeds.
This item can only be used in World-Locked worlds.
This item has special properties you can adjust with the Wrench.
Data: Paint PreviewType — Challenge Flag – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single
Collision Type: No Collision
Hardness: **6 Hits** **5 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Combination

In any Chemical Combiner, mix together...
Race Start Flag **(×20)** ,
Challenge Timer **(×1)** and
Transmog Crystal **(×1)**.
This recipe will yield **1** item.
The **Challenge Start Flag** is an item added as part of Player Appreciation Week 2016.
##  Function
When a Challenge Timer is started by wrenching, it will spawn the player in the Challenge Start Flag associated by its ID.
