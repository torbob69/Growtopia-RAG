The **Sugarloaf Pineapple Block** is an unsplicable solid foreground block which was added as part of Super Pineapple Party 2015 on May 30, 2015.
##  Function
When placed, the Sugarloaf Pineapple Block serves a fully aesthetic purpose.
##  Trivia
  * Sugarloaf Pineapple Block is one of four Pineapple Blocks which was added on Super Pineapple Week 2015, with the other blocks including Roasted Pineapple Block, Frozen Pineapple Block, and Pineapple Block.
