# Geisha Makeup

Applied with exacting precision and exquisite materials, this makeup is a statement to the world that its bearer is poised, beautiful, and probably displeased with shenanigans. ANY shenanigans.

The **Geisha Makeup** is an unsplicable face item which was added as part of Harvest Festival 2018 on September 21, 2018.
##  Function
When equipped, the Geisha Makeup serves a purely cosmetic purpose.
