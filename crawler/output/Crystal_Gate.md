The **Crystal Gate** is an unsplicable non-solid door foreground block which was added as part of the Crystals update.
##  Function
As a door, the Crystal Gate can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
When the destination of a **Crystal Gate** is set to KILIMA:OKAVANGO and the door is placed in a world that starts with the letter Y, the door will be destroyed and drop an Illuminati Stone. This will complete an Epic Quest.
