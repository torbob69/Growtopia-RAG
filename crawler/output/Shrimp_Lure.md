# Shrimp Lure

This is bait for fishing. Equip a fishing rod and then use this bait on water that you are standing next to in order to start fishing. There is no fish too big to enjoy a shrimp lure.
Properties
This item never drops any seeds.

The **Shrimp Lure** is a consumable which was added alongside the Fishin' Pack on September 11, 2015.
##  Function
### Fishing
Items which can be caught with Shrimp Lure include:
  * Seaweed
  * Sunfish
  * Mahi Mahi
  * Gar
  * Whale
  * Sand Shark
  * Great White Shark
  * Fishing Stool
  * Fishnet Stockings
  * Jellyfish
  * Electric Eel
  * Fish Wall Mount
  * Lobster Trap
  * E-Z Rod
  * Shield Fragment
  * Whizmo Gizmo

### Lobster Trap
Items which can be caught in Lobster Traps with Shrimp Lure include:
  * Tentacle Beard
  * Mermaid Tail
  * Octopus Head
  * Pet Frog

Both the lists above are sorted by rarity.
