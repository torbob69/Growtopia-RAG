The **Air Conditioner** is a splicable solid foreground block which was added as part of the Block Party update on June 12, 2015.
##  Function
When placed, the Air Conditioner serves a purely aesthetic purpose. The block features an animation of a spinning fan which cannot be turned off by the player.
