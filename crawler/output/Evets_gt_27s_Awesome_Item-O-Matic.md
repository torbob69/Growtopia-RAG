**evets_gt's Awesome Item-O-Matic** is an unsplicable non-solid provider foreground block which was added as part of Block Party 2 on April 1, 2019.
##  Function
Every 5 days, it will generate one of the five special blocks with evets_gt's face on it:
  * evets_gt's Red Block ×10
  * evets_gt's Green Block ×10
  * evets_gt's Yellow Block ×10
  * evets_gt's Blue Block ×10
  * evets_gt's Ruby Block ×2
