# Stethoscope

Congratulations on winning the Doctor's Duel Daily Challenge! With this Stethoscope on, you are half as likely to make mistakes in surgery!

Daily Challenge

Place in the top three of the **Doctors' Duel** Daily Challenge.
The **Stethoscope** is an unsplicable chest item which was added as part of the Daily Challenges update on November 18, 2015.
##  Function
When equipped, players are half as likely to perform skill fails while doing surgery. This effect doesn't stack with any usage of Tea.
