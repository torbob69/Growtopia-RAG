# Disgusting Mess

This abomination is what happens when you let video gamers cook. Do NOT eat.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **2 Hits** **2 Hits** – Restores after **2s** of inactivity
Gems Drop: **N/A**
**1h**
Failing a Cooking Recipe

Can be obtained by cooking a food below its required percentage.
The **Disgusting Mess** is a consumable that was added as part of the Cooking update.
##  Function
When consumed, it will cause the character to puke. This effect is purely visual.
