# Mega Buckazoid

Now you're talking! This is worth 100 buckazoids! Double-tap this in your inventory to break it back down into 100 buckazoids. You can exchange buckazoids for rare interstellar rewards by calling Sales-Man on your Telephone at 53785!
Properties
This item cannot be dropped or traded.
This item never drops any seeds.
This item has no use... by itself.

Made by double-tapping/clicking  Buckazoid **(×100)** in one's inventory.
Always creates **1** item each.
**Mega Buckazoid** is an unsplicable component item which was added as part of the Startopia Update on July 1, 2018.
##  Function
Mega Buckazoids can be used to purchase Startopia related items from the Sales-Man when using a Telephone by dialing 53785.
