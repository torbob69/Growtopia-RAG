The **Riding Cloud** is an unsplicable and untradable feet item that was added as part of Player Appreciation Week 2021 Day 3 on August 25, 2021.
##  Function
Run with the breeze!

Cloud Burst!

When equipped, the **Riding Cloud** grants the _Speedy: Riding Cloud_ mod, which allows the player to move faster on land.
##  Trivia
  * The appearance of this item mimics Lakitu's Cloud from the Super Mario franchise.
