The **Easter Egg - Rainbow** is an unsplicable solid foreground block which was added as part of Easter Week 2015.
##  Function
When placed, Easter Egg - Rainbow serves a purely aesthetic purpose.
The  Event Exclusive Mission - All Aboard For Easter Fun! mission requires 1 of this item.
