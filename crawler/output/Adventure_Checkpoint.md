The **Adventure Checkpoint** is a splicable non-solid checkpoint foreground block which was added as part of The Adventure Pack Strikes Back! update on June 1, 2017.
##  Function
Being a checkpoint block, the Adventure Checkpoint acts as where the player respawns after dying.
After going through a Race Start Flag and then through a Race End Flag, all checkpoints will be reset and the player would respawn at the Main Door on death. The same goes with the Challenge Timer and /kick, /kickall command.
