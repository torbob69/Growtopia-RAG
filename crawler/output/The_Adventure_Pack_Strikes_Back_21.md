# The Adventure Pack Strikes Back!

Growtopia Gazette
> June 1st: The Adventure Pack Strikes Back!
> We've got tons of new items and functions for the Adventure Pack this month!
> Create amazing adventures for other players with new blocks that respond to Adventure Items they're holding, or Tomb Robbers that steal them!
> Explore the depths of the jungle with the new Jungle Blast.
> Try wrenching a Gateway To Adventure for detailed documentation on the new features.
> - @Seth and @Hamumu
The **The Adventure Pack Strikes Back!** update was introduced on the 1st of June 2017 and was designed to add items to the Adventure Pack. As of this update, all adventure items collected now appear above the player's username and have effects when an item is collected.
The price of the Adventure Pack was increased from 8,000 gems to 20,000 gems. It now contains:
  * Gateway To Adventure x4
  * Path Marker x4
  * Lazy Cobra x1
  * Adventure Brazier x1
  * Adventure Barrier x4
  * Adventure Item - Rope x1
  * Adventure Item - Torch x1
  * Adventure Item - Key x1
  * Adventure Item - Golden Idol x1
  * Adventuring Mustache x1
  * Explorer's Ponytail x1
  * Adventurer's Sling Bag x1
