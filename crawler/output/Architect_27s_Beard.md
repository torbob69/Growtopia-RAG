The **Architect's Beard** is an unsplicable face item which was added as part of Summer Clash 2018 on June 1, 2018.
##  Function
When equipped, the Architect's Beard serves a fully cosmetic purpose.
##  Trivia
  * This item is considered a part of the Architect's set, which consists of the following items:

    * Architect's Beret (hat)

    * Architect's Beard (face)

    * Architect's Compass (chest)

    * Architect's Robes (shirt)
