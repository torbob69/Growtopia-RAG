# Strawbeanie

A beanie made out of a giant strawberry.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Cotton Candy Clouds **(×50)** ,
Polka Dot Block **(×50)** and
Strawberry Block **(×1)**.
This recipe will yield **1** item.
The **Strawbeanie** is an unsplicable hat item which was added as part of Valentine's Week 2022 on February 11, 2022.
##  Function
When equipped, the Strawbeanie serves a purely cosmetic purpose.
##  Trivia
  * The Strawbeanie's name is a portmanteau of "strawberry", an edible red fruit, and "beanie", a type of brimless cap. As suggested by the Strawbeanie's description, the item's design is based on both objects.
