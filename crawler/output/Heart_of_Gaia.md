# Heart of Gaia

Tired of harvesting trees on your own? Perhaps it's time we made nature work for US, for a change! Empower this pulsing Heart with enough Gems, tell it to target any tree of your choosing, and it will harvest them AUTOMAGICALLY!
Properties
This item never drops any seeds.
This item can only be used in World-Locked worlds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item has special properties you can adjust with the Wrench.

The **Heart of Gaia** is an unsplicable solid foreground block which was added as part of the Role Up! update on September 17, 2018.
##  Function
When wrenched, it lets the player add Gems to be able to harvest trees automatically starting from the top-left up to the bottom-right of the world with a rate of 1 gem per 1.5 seconds.
