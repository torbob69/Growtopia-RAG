**Blue Facepaint** is an unsplicable face item which was added in the Balloon Warz update. It is a rare drop from harvesting a Balloon-O-Matic.
##  Trivia
  * Blue Facepaint is one of three facepaints which was added in the update, with the others including Green Facepaint and Red Facepaint.
  * The description of this item is a reference to the movie Braveheart.
