The **Golden Riding Raptor** is an unsplicable feet item which was added as part of Growassic Park on October 7, 2016.
##  Function
You can move faster!

You are slow again.

When equipped, the **Golden Riding Raptor** grants the _Speedy_ mod, which allows the player to move faster on land.
