The **Weather Machine - Apocalypse** is a weather machine that was added as part of the Night of the Sewing Dead update. It is available in the Growtopia Store for 150,000 gems, only during the Apocalypse.
##  Function
Every hour, somebody will be infected with the g-Virus and players in the world can kill zombies (a Zombie Brain is not rewarded from killing zombies).
