The **Offering Table** is an unsplicable non-solid foreground block which was added as part of Harvest Festival 2022 on September 9, 2022.
##  Function
When placed, the Offering Table can be used to offer mooncakes and songpyeons to the Moon in return for a random reward. Depending on the types of mooncakes offered the possible rewards may vary. Additionally, upon placement, the Offering Table will transform the world's background to the background of a harvest moon-blasted world.
The Offering Table can only be used during Harvest Festival. Upon wrenching the Offering Table outside of Harvest Festival, the following message will be returned: _The Moon is currently not available to offer Mooncakes to._
