The **Winter Event Player Medal: Bronze** is an unsplicable platform foreground block which was added in the Winter Clash update. One can be obtained from placing third in a Winter Clash event on the Personal Event Leaderboard.
##  Function
A Winter Event Player Medal: Bronze behaves as a platform, thus a player can jump pass through it from underneath.
##  Trivia
  * After the first Winter Clash, the earned medals could be dropped and traded. The glitch was fixed soonly after, leaving very few instances of dropped Winter Clash Medals behind.
