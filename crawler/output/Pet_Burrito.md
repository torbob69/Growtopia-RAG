The **Pet Burrito** is an unsplicable pet hand item which was added as part of Cinco De Mayo Week 2014 on May 2, 2014.

##  Trivia
  * This item's name is a wordplay. _Burro_ means donkey in Spanish, while _-ito_ means little. Thus, burrito technically means _little donkey_. There is also a Mexican food with a similar name in real life, whose Growtopian counterpart is used in creating this item.
    * The description of this item refers to this fact.
