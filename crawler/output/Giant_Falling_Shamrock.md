# Giant Falling Shamrock

Shamrocks are lucky.... lucky it doesnt fall like a rock! Hold the jump button while falling to cushion your fall. Only found in Blarney 5, 7 and 9.
Properties
This item never drops any seeds.
This item can be transmuted.

The **Giant Falling Shamrock** is an unsplicable hand item which was added as part of St. Patrick's Week 2020 on March 12, 2020.
##  Function
Oooooh I'm slowly falling!

Aaargh, too fast!

When equipped, the **Giant Falling Shamrock** grants the _Slow-Fall: Giant Falling Shamrock_ mod, which allows the player to glide slowly to the ground when holding the jump button.
