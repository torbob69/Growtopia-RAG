The **Super Cape - Pink** is an unsplicable back item that was added as part of Easter Week 2016.
##  Function
You can jump in mid-air! It's like flying, but less.

Gravity - it's the law.

When equipped, the **Super Cape - Pink** grants the _Double Jump_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * The description of this item refers to the Heroman Cape.
