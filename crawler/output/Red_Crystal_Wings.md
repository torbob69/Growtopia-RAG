**Red Crystal Wings** is an unsplicable wings back item which was added as part of the Crystals update on January 20, 2015.
##  Function
You can jump in mid-air! It's like flying, but less.

Gravity - it's the law.

When equipped, the **Red Crystal Wings** grants the _Double Jump!_ mod, which allows the player to jump a second time in mid-air.
