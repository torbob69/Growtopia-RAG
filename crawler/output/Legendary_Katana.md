# Legendary Katana

This legendary blade was said to have sliced through 3 tomatoes AND a tin can during the course of a single infomercial! Nobody knows if that's really true, but it's certainly a big sword.
Properties
This item can kill zombies during a Pandemic!
This item cannot be dropped or traded.
This item never drops any seeds.

The **Legendary Katana** is an unsplicable hand item. One can be obtained from finishing the _Quest of the Blade_ from the Legendary Wizard.
##  Function
None can stand against you!

Maybe you should sit down.

When equipped, the **Legendary Katana** grants the _Legendary Swordmaster_ mod, which allows the player to break blocks faster, punch one tile further, and knock back other players further. It will also replace the player's punching animation with giant golden slashes.

  19. Deliver 20 Crystal Glaives.
