The **Shining Block - Red** is a solid foreground block which was added as part of Player Appreciation Week 2019 Day 1 on August 19, 2019.
##  Function
As a light source, a Shining Block - Red emits light in dark areas. The block periodically glows brighter and dimmer; this effect is purely visual and has no effect on the block's actual light radius.
##  Trivia
There are three Shining Blocks in total, the other two being  Shining Block - Purple and  Shining Block - Yellow.
