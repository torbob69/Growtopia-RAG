The **Crime In Progress** is an unobtainable non-solid foreground block which was added alongside the Crime Wave pack and Superhero Pack. One can be created as a placed block from a _Crime in Progress!_ special event.
##  Function
A Crime In Progress serves as a stand-in for a villain. When a player punches one, they will be able to fight it if they have the cards to do so.
