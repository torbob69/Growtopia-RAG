The **Xenoid Suit** is an unsplicable shirt item which was added as part of the Geiger Day update on May 5, 2017, the same day Cinco De Mayo Week 2017 was released.
##  Function
When equipped, the Xenoid Suit serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Xenoid set, which consists of the following items:

    * Xenoid Mask (Face)

    * Xenoid Suit (Shirt)

    * Xenoid Leggings (Pants)

    * Xenoid Shoes (Feet)

    * Xenoid Claws (Hand)
  * Supervillain  H.R. Geiger can be seen wearing this item.
  * This item is a reference to the torso of the Xenomorph in the Alien franchise. H. R. Geiger is also a reference to the creator of the film, whose name is H. R. Giger.
