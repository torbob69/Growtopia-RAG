The **Hospital Curtain** is an unsplicable non-solid foreground block which was added as part of the Growtopia General Hospital update on November 22, 2013.
##  Function
When placed, the Hospital Curtain serves a purely aesthetic purpose.
##  Trivia
  * The Hospital Curtain is based on a real-life object with the same name, which is typically used in a medical treatment facility in order to provide a private enclosure for patients.
  * As part of the Block Party 2 update, the quantity of Hospital Curtains obtained from surgery was increased from 1 to 5.
  * Hospital Curtain has a redesigned version:  Mage's Curtains.
