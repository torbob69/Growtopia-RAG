The **Castle Door** is an unsplicable non-solid door foreground block which was added as part of the Summer Season Events on June 1, 2018.
##  Function
As a door, the Castle Door can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
