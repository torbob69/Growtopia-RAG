# Deep Iron Ingot

You've managed to process this ore into a pure, shining ingot, just by tossing it into a fire!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **9 Hits** **7 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Combustion

Burn a(n)  Deep Iron Ore **(x1)** in a  Highly Combustible Box.
The **Deep Iron Ingot** is an unsplicable consumable which was added as part of the Spelunkorama! update.
##  Function
This item is only used to forge a Pick Blade or an Iron Buckle. Both items have the same recipe; however, forging an Iron Buckle requires a Buckle Design in the player's inventory, which will be used up.
