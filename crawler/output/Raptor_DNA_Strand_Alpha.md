# Raptor DNA Strand Alpha

This is a strand of prehistoric DNA. It appears to be the beginning of a velociraptor DNA sequence. Perhaps there's a way to recombine it and bring them back! That doesn't seem like a terrible idea at all.
Properties
This item never drops any seeds.
This item has no use... by itself.

The **Raptor DNA Strand Alpha** is a DNA released along as part of the Growassic Park Update. It is obtainable from extracting fossil drops using a DNA Extractor.
##  Function
It is used to make riding raptors.
