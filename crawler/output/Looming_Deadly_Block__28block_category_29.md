# Looming Deadly Block (block category)

A **looming deadly block** is a type of foreground block which acts as a deadly block for a while when a player passes by.
##  List of Looming Deadly Blocks
Items: Special FunctionBountiful Growtopian-Eating Looming Plant: None.
Morbid Hand: None.
Laser Grid: None.
Looming Pineapple: None.
Looming Shadows: Does not kill players with the Demented Cowl equipped. Instead, it gives them a unique clothing animation while they are standing on the Looming Shadows.
Looming Triffid: None.
Vapor Vent: None.
