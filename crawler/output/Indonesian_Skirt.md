# Indonesian Skirt

A skirt made out of the best fabric in Indonesia!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Pants – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Floral.
Sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Overcasting Stitch**.
Lastly, sew a  Silk Bolt - Red to the previous bolt using a(n) **Saddle Stitch**.
Each recipe gives **1** item.
The **Indonesian Skirt** is an unsplicable pants item which was added as part of Player Appreciation Week 2021 Day 7 on August 29, 2021.
##  Function
When equipped, the Indonesian Skirt serves a fully cosmetic purpose.
##  Trivia
  * This item is part of the Indonesian clothing set introduced on Player Appreciation Week 2021 Day 7, alongside the Indonesian Headdress (hat) and Indonesian Blouse (shirt).
