# Candyland Blast

Create a Candyland mixed with love to make the world taste good! This beautiful Dessert Blast is not made of sand for those brooding space wizards out there!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Growtopia Store

Purchase the **Candyland Blast** for **15 Grow Voucher** in the Growtopia Store.
"Create a Candyland mixed with love to make the world taste good! This beautiful Dessert Blast is not made of sand for those brooding space wizards out there!"
Every purchase will give **1** item.
The **Candyland Blast** is an unsplicable blast consumable which was added as part of Voucher Dayz 2024 on November 14, 2024.
##  Function
Upon consumption, the blast will create a new world featuring a candyland-themed world filled with candy blocks.
Naturally-generated Blocks

Main Door
Bedrock Candy
Colorful Cake
Colorful Cake Slice
Colorful Cake Toppings
Cherry on Top
Hot Fudge
Data Bedrock Candy
##  Trivia
  * Candyland Blast is the only blast that is sold in exchange for Grow Vouchers.
  * Using a Door Mover in a Candyland blasted world spawns a regular  Bedrock rather than a  Bedrock Candy.
