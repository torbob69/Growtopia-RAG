# Pineapple Slice

Slice of pineapple.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Food Grinding

In a Food Grinder, grind...
Pineapple **(x50)**.
This recipe will yield **1** item.
The **Pineapple Slice** is an unsplicable consumable which was added as part of Super Pineapple Party 2017 on June 8, 2017.
##  Function
When consumed, the player will say "YUM!" and do the :D ⦅⦆ emote.
