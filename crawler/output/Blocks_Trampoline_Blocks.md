# Blocks/Trampoline Blocks

< Blocks
**Trampoline Blocks** are solid blocks which causes the player to bounce when jumped on, and by holding the jump button, the player can jump even higher. The _High Jump_ mod also boosts one's jump height on a trampoline block.
