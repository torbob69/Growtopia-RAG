**Dummy Alien Computer** is an unobtainable non-solid foreground block which was added as part of Star Trek Prodigy on June 27, 2022.
##  Function
Dummy Alien Computer is a block found while doing Protostar missions in a Protostar Starship Blast. Compared to the Alien Computer, the Dummy Alien Computer's lights flicker.
