##  Function
This tool must be used with care.

Go nuts!

When equipped, the **Rock Hammer** grants the _Precision Tool_ mod, which allows the player to break blocks more slowly and pull other players towards them upon punching them. It will also decrease punch range.
The Rock Hammer is primarily used to extract Fossils out of any type of fossil rocks. When one punches an untouched fossil rock while wearing this item, there is a slight chance that the rock will enter an "extracted" phase, thus allowing the user to start chipping it with a Rock Chisel. Multiple punches might be required in order for this to happen. The player may need to wait for a while after having punched the rock several times so as to prevent it from being accidentally destroyed.
