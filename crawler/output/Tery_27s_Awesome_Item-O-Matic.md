This item was given to **Tery** for their contributions as a content creator as part of the Block Party 2 update.
**Tery's Awesome Item-O-Matic** is an unsplicable non-solid provider foreground block which was added as part of Block Party 2 on April 1, 2019.
##  Function
Every 5 days, it will generate one of the five special blocks with teryjaki's face on it:
  * Tery's Red Block ×10
  * Tery's Green Block ×10
  * Tery's Yellow Block ×10
  * Tery's Blue Block ×10
  * Tery's Ruby Block ×2
