This item was given to **Muninn** for their contributions as a voluntary moderator.
**Muninn's Unity Wings** is an unsplicable back item which was added on July 1, 2019.
##  Function
Go Muninn!

Wings concealed!

When equipped, the **Muninn's Unity Wings** grants the _Double-Jump: Unity_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * On August 20, 2025, the item’s name was updated from **Munnin's Unity Wings** to **Muninn's Unity Wings** to correctly reflect the moderator’s name.
