# Climbing Rocks

These plastic steps are perfect for indoor wall climbing!
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

Render Type: Single

The **Climbing Rocks** is a splicable foreground block which was added as part of Player Appreciation Week 2025 on September 18, 2025.
##  Function
When placed against a vertical wall, players can cling onto Climbing Walls by holding their jump when using one of the following items:
  * Claws of Barko
  * Climbing Boots
  * Climbing Picks
  * Ezio's Boots
  * Mountain Boots
  * S.P.I.D.E.R. Legs
  * Tarantula Legs
  * Will of the Wild (earth version)
