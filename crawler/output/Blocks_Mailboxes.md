# Blocks/Mailboxes

< Blocks
**Mailboxes** are blocks where anyone who has access to a Blue Mailbox can view messages left behind by other players as well as the players' names. Anyone can also punch the Blue Mailbox in order to see how many mails there are. A maximum of 20 mails can be placed inside a mailbox.
