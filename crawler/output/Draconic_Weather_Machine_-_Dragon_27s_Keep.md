The **Draconic Weather Machine - Dragon's Keep** is an unsplicable non-solid weather machine foreground block which was added as part of Lunar New Year 2025 on January 23, 2025.
##  Function
As a weather machine, the Draconic Weather Machine - Dragon's Keep can be toggled on or off via punching. When toggled on, it will change its appearance, transforming the world's background.
