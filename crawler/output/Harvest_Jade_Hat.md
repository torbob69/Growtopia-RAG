The **Harvest Jade Hat** is an unsplicable hat item which was added as part of Harvest Festival 2021 on September 16, 2021.
##  Function
Spin Attack Activate!

Oddjob no more!

When equipped, the **Harvest Jade Hat** grants the _Punch Range : Harvest Jade Hat_ mod, which allows the player to punch one tile further. It will also throw the Jade Hat when punching, replacing the Fist.
