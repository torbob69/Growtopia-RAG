# Flamingo Wings

Majestically soar in the sky with these wings.... wait, that's not right! Flap wildly like a crazy Flamingo with these equipped!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hand – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Sun Block **(×50)** ,
Pastel Pink Block **(×200)** and
Heartcastle Stone **(×150)**.
This recipe will yield **1** item.
The **Flamingo Wings** is an unsplicable hand item which was added as part of SummerFest 2020 on July 3, 2020.
##  Function
Up, up and away

Heading South for the winter and back to earth!

When equipped, the **Flamingo Wings** grants the _High jump: Flamingo Wings!_ mod, which allows the player to jump one tile higher.
