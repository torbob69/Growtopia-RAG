# Silkworm Soul

The great thing about silkworms is that they don't have unique souls. They're totally interchangeable! Jam this into any dead silkworm to bring it back for a 2nd chance.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **4 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Balance Mooncake **(×1)** ,
Ancestor Mooncake **(×1)** and
Longevity Mooncake **(×5)**.
This recipe will yield **1** item.
Mooncake Offering

| 1 may be received as a common reward from offering mooncakes using an Offering Table, when the offering contains:
•  Balance Mooncake, or
•  Ancestor Mooncake  |
The **Silkworm Soul** is an unsplicable consumable which was added as part of Harvest Festival 2016 on September 15, 2016.
##  Function
When used on a dead silkworm, the Silkworm Soul will revive the silkworm.
