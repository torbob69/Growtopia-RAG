# Pineapple Headphones

Sweet beats for when you're scoffing pineapple treats! Dance along to some funky tunes looking totally awesome in these!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Face – Clothes

Daily Challenge

Place in the top three of the **Pineapple Panic** Guild Daily Challenge, only if the player had contributed points to the challenge.
The **Pineapple Headphones** is an unsplicable face item which was added as part of Super Pineapple Party 2020 on June 4, 2020.
##  Function
<https://growtopiawiki.com/w/File:Tropic.ogg>The Pineapple Headphones' music
When the player enters the command /dance or /dab command, tropical music will be played.
