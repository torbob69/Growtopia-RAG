# Rainbow Kite

The most colorful kite in all of Growtopia!

**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Aqua.
Sew a  Silk Bolt - Purple to the previous bolt using a(n) **Locking Stitch**.
Lastly, sew a  Silk Bolt - Green to the previous bolt using a(n) **Saddle Stitch**.
Each recipe gives **1** item.
The **Rainbow Kite** is an unsplicable pet hand item which was added as part of the Night of the Sewing Dead update.
##  Function
When equipped, a rainbow-colored kite pet appears and follows the player around. The Rainbow Kite serves a purely cosmetic purpose.
