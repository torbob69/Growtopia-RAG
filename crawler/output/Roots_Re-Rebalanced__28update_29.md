# Roots Re-Rebalanced (update)

Growtopia Gazette
> September 17th: Roots Re-Rebalanced! Based on the feedback we received from you from the most recent survey, we have made some balancing changes to Roots! Please read the Change Log and Dev Diary for more information!

The **Roots Re-Rebalanced** update is a minor update which was introduced on September 17, 2020. It focused around balancing changes to the Roots feature.
##  **Changes**

Roots

  * Roots now need one fewer cycle to mature.
  * The gem drop rates of all Mature Roots have been balanced accordingly.

Buffs related to hardness

  * The number of hits required to break a Bountiful Bamboo Background have been decreased from 6 to 4.
  * The number of hits required to break a Bountiful Bamboo Ladder have been decreased from 12 to 6.
  * The number of hits required to break a Bountiful Bamboo Platform have been decreased from 8 to 4.
  * The number of hits required to break a Bountiful Bamboo Spikes have been decreased from 14 to 6.
  * The number of hits required to break a Bountiful Jungle Temple Pillar have been decreased from 9 to 7.

Nerfs related to hardness

  * The number of hits required to break a Bountiful Growtopian-Eating Looming Plant have been increased from 5 to 6.
  * The number of hits required to break a Bountiful Lattice Fence have been increased from 4 to 5.
  * The number of hits required to break a Bountiful Monkshood have been increased from 3 to 6.

##  Trivia
  * The name of this update alludes to the fact that the Roots update had already been given a balancing update once.
  * On October 4, 2020 the number of hits required to break a Bountiful Growtopian-Eating Looming Plant and a Bountiful Lattice Fence have both been decreased by 1 hit.
