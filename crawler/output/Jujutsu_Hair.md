The **Jujutsu Hair** is an unsplicable hair item which was added as part of Player Appreciation Week 2023 Day 4 on August 31, 2023.
##  Function
When equipped, the Jujutsu Hair serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Jujutsu set, which consists of the following items:

    * Jujutsu Hair (hair)

    * Jujutsu Shirt (shirt)

    * Jujutsu Pants (pants)

    * Jujutsu Scarf (neck)

    * Jujutsu Shoes (Feet)
  * The Jujutsu set is a reference to Yuji Itadori, the main protagonist of the manga Jujutsu Kaisen.
