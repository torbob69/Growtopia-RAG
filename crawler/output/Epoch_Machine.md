**Epoch Machine** is an unsplicable weather machine which was added alongside the Guilds update as Aprils 2018's Item Of The Month on April 1, 2018.
##  Function
When placed in a world, the owner or accessed admins can wrench on the machine and choose which of the three weathers (Ice Age, Volcano, and Floating Islands) to be shown as the background for the world, with a Cycle time (in minutes) to change in between the selected settings.
##  Trivia
  * Epoch Machine is the first and only weather machine not to contain the phrase _Weather Machine -_.
