# Yellow Bunting

Fancy the place up a little with some lovely yellow fabric.
Properties
This item never drops any seeds.
Data: Paint PreviewType — Foreground Block – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Horizontal
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **1s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Yellow.
Sew a  Silk Bolt - White to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Overcasting Stitch**.
Each recipe gives **5** items.
The **Yellow Bunting** is a non-solid block that was added on Night of the Sewing Dead update.
##  Function
When placed, the Yellow Bunting serves a fully aesthetic purpose.
