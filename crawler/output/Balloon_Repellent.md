# Balloon Repellent

Drinking this will keep those pesky balloons away for a while! The bubble of protection is extremely fragile. One hit and your protection will be gone!
Properties
This item cannot be dropped or traded.
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **4 Hits** **3 Hits** – Restores after **5s** of inactivity
Gems Drop: **N/A**
**1h**
Balloon-O-Matic Reward

Use or blow up a  Balloon-O-Matic.
The **Balloon Repellent** is an untradable consumable which was added as part of Balloon Warz 2017.
##  Function
When consumed, a Balloon Repellent creates a bubble which protects the player from a single war balloon hit. The Balloon Repellent can only be used during Balloon Warz only.
##  Trivia
  * Attempting to consume a Balloon Repellent while Balloon Warz is not active will result in the message, "_This is useless right now, wait for the next war to begin._ "
