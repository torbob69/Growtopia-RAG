# Sky Lantern

Release this lantern into the wind to celebrate the harvest!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **30 Hits** **23 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Harmony Mooncake **(×2)** ,
Prosperity Mooncake **(×2)** and
Peace Mooncake **(×2)**.
This recipe will yield **3** items.
Mooncake Offering

1 may be received as a common reward from offering mooncakes using an Offering Table.
The **Sky Lantern** is an unsplicable consumable which was added in Harvest Festival on September 18, 2013.
##  Function
When consumed, the Sky Lantern will appear and float up for a few seconds before disappearing.
