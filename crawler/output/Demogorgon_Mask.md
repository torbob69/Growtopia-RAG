The **Demogorgon Mask** is an unsplicable face item which was added as part of Halloween Week 2020 on October 22, 2020.
##  Function
Let there be light!

The candle died out

When equipped, the **Demogorgon Mask** grants the _Lightsource : Demogorgon Mask_ mod, which allows the player to emit light in dark areas.
##  Trivia
  * The Demogorgon Mask is based on a fictional underworld demon of the same name.
