The **Fancy Pants** is an unsplicable pants item that was added as part of the Locke The Traveling Salesman update on March 22, 2015.
##  Function
When equipped, the Fancy Pants serves a fully cosmetic purpose.
##  Trivia
  * This item is considered a part of the Locke The Salesman set, which consists of the following items:

    * Pink Fedora (hat)

    * Distinguished Grey Hair (hair)

    * Pencil Mustache (face)

    * Pink Suitcoat (shirt)

    * Fancy Pants (pants) .
  * Equipping the set completes the _"Dress up asLocke The Salesman"_ Epic Quest.
  * When first introduced, they were named _Pink Pants_. However, Hamumu later decided to rename them to Fancy Pants after a user referred to them as Fancy Pants in a forums post.[[1]](https://growtopiawiki.com/w/Fancy_Pants#cite_note-1)
