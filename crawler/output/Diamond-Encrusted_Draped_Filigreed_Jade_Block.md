The **Diamond-Encrusted Draped Filigreed Jade Block** is an unsplicable solid foreground block which was added alongside the Fashion Pack on May 15, 2015.
##  Function
When placed, the Diamond-Encrusted Draped Filigreed Jade Block serves a fully aesthetic purpose.
The  Myths and Legends : The Eye of the Heavens mission requires 200 of this item.
