The **Summer Artifact Chest** is an unsplicable non-solid foreground block which was added as part of SummerFest 2021 on July 8, 2021.
##  Function
When placed, the Summer Artifact Chest serves a purely aesthetic purpose.
When smashed, the Summer Artifact Chest has a chance to drop one of the following items:
  * Super Summer Surprise ×1
  * Super Fireworks ×1
  * Ultra Blue Neptune Fragment ×1
  * Ultra Red Phoenix Fragment ×1
  * A limited number of old Phoenix items specified in the Store ×1

##  Trivia
  * As of SummerFest 2022, the Summer Artifact Chest now drops x1 of a limited number of old Phoenix items every 3 hours specified in the Growtopia Store instead of x1 of a limited number of _one_ old Phoenix Item every 3 hours specified in the Growtopia Store implemented back in SummerFest 2021.
