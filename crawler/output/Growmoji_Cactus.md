# Growmoji Cactus

Pop some spicey spikes into your chat with this cactus! Just consume to add it to your available Growmojis!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Pinata Bash

Participate in successfully smashing an  Ultra Pinata during the **Pinata Bash!** event.
May give **1** item each time.
The **Growmoji Catus** is an unsplicable consumable which as added as part of Cino De Mayo Week 2018 on May 4, 2018.
##  Function
When consumed, the player will be able to use the cactus growmoji by typing (cactus).
