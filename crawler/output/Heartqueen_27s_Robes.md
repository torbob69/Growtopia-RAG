The **Heartqueen's Robes** is an unsplicable shirt item which was added as part of the Valentine's Week 2019 update on February 8, 2019.
##  Function
When equipped, the Heartqueen's Robes serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Heartqueen set, which consists of the following items:

    * Heartqueen's Crown (Hat)

    * Heartqueen's Robes (Shirt)
