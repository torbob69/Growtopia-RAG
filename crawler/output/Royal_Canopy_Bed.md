The **Royal Canopy Bed** is an unsplicable non-solid bed foreground block which was added as part of the Summer Clash 2018 on June 1, 2018.
##  Function
Being a bed, executing the /sleep command in chat while standing on the same tile as a Royal Canopy Bed will cause the player to sleep in it.
