# Pizza

I'll have the Supreme With Cheese!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **4 Hits** **3 Hits** – Restores after **5s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Dough **(×3)** ,
Tomato **(×1)** and
Swiss Cheese Block **(×1)**.
This recipe will yield **1** item.
Growtopizza

Buy this item from the **Growtopizza** ( 30912) for 1  Big Lock.
The **Pizza** is an unsplicable consumable which was added as part of the Rise of the Desert Dragons update on August 3, 2013.
##  Function
When consumed, the player will say "YUM!" and do the :D ⦅⦆ emote.
### Silkworm Food     _Main article:Guide:Silkworm Care_
This consumable can be fed to a Silkworm to give it a red color, thus allowing it to produce 1–10  Silk Thread - Red per harvest.
