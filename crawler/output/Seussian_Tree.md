# Seussian Tree

These particular trees, near the Jurassic seas, produced quite a crunchety fruit. Though scientists say that it tasted okay, we can't pollinate so it's moot.

The **Seussian Tree** is an unsplicable non-solid foreground block which was added as part of the Growassic Park update on October 7, 2016.
##  Function
When placed, the Seussian Tree serves a purely aesthetic purpose.
##  Trivia
