The **Mailbox** is a splicable non-solid mailbox foreground block which was added on April 6, 2013.
##  Function
The Mailbox is the first mailbox block added to _Growtopia_. Anyone who has access to a Mailbox can view messages left behind by other players as well as the players' names. Anyone can also punch the Mailbox in order to see how many mails there are. A maximum of 20 mails can be placed inside a mailbox.
The  Letter item serves as an image placeholder for the mail icon.
