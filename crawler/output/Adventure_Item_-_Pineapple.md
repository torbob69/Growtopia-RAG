# Adventure Item - Pineapple

Place this in your world to be used in your Gateways To Adventure! Players can pick it up by punching it. They lose it if they leave your world.

This item never drops any seeds.

The **Adventure Item - Pineapple** is an unsplicable non-solid adventure item foreground block which was added as part of Super Pineapple Party 2017 on June 8, 2017.
##  Function
As a type of adventure item, the Adventure Item - Pineapple may work in conjunction with the Gateway To Adventure.
