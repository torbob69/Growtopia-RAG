# White Bunting

Fancy the place up a little with some lovely white fabric.
Properties
This item never drops any seeds.
Data: Paint PreviewType — Foreground Block – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Horizontal
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **1s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - White.
Sew a  Silk Bolt - White to the previous bolt using a(n) **Locking Stitch**.
Lastly, sew a  Silk Bolt - Grey to the previous bolt using a(n) **Triple Stretch Stitch**.
Each recipe gives **5** items.
The **White Bunting** is an unsplicable non-solid foreground block that was added as part of the Night of the Sewing Dead update.
##  Function
When placed, the White Bunting serves a purely aesthetic purpose.
