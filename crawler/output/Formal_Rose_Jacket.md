The **Formal Rose Jacket** is an unsplicable shirt item that was added as part of Valentine's Week 2022 on February 11, 2022.
##  Function
When equipped, the Formal Rose Jacket serves a fully cosmetic purpose.
##  Trivia
This item is considered a part of the Masculine Formal Rose set, which consists of the following items:

  *     * Formal Rose Shoulders (Chest)

    * Formal Rose Jacket (Shirt)

    * Formal Rose Pants (Pants)
