The **Diamond Shamrock Checkpoint** is an unsplicable non-solid checkpoint foreground block which was added as part of the Pre-WinterFest 2022 update on December 1, 2022.
##  Function
Being a checkpoint block, the Diamond Shamrock Checkpoint acts as where the player respawns after dying.
After going through a Race Start Flag and then through a Race End Flag, all checkpoints will be reset and the player would respawn at the Main Door on death. The same goes with the Challenge Timer and /kick, /kickall command.
