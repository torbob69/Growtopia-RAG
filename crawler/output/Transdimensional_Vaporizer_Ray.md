# Transdimensional Vaporizer Ray

This is a highly advanced alien device with one purpose: it can fire right through solid matter to vaporize background blocks without doing any harm to the foreground blocks. It uses alien batteries which we can't replace, so each Vaporizer can only be used once.

The **Transdimensional Vaporizer Ray** is a background item which was added as part of the Daily Challenges update on November 18, 2015.
##  Function
It removes the background behind a foreground block without affecting the latter. The Transdimensional Vaporizer Ray gets used up after.
