The **Building Blocks Machine** is an unsplicable non-solid foreground provider block introduced during the Block Party 2 update on April 1, 2019.
##  Function
When harvested (by being punched), a Building Blocks Machine will randomly drop one stack of the following blocks, most of which can be obtained through other ways. One can be harvested every 24 hours for ten days before turning into a Used Building Blocks Machine.

##  Trivia
  * Building Blocks Machines used to drop Corn and Sheet Music: Lyre Note. The former was removed since the developers didn't intend to include it as a reward in the first place, while the latter was removed due to an unknown reason.
  * The Building Blocks Machine is regularly abbreviated by players as BBM.
  * Collecting 100 items from providers such as Cows will earn the achievement **Milkin' It (Classic)**.
  * Collecting 500 items from providers such as Cows will earn the achievement **Moo Juice (Classic)**.
  * Collecting 10,000 items from providers such as Cows will earn the achievement **Collector Extraordinaire (Classic)**.
  * Collecting 1,000,000 items from providers such as Cows will earn the achievement **Providers Will Provide**.
