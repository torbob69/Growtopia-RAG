# Fire Wand

Use this on someone to MURDER THEM.
Properties
This item never drops any seeds.
Data

Gems Drop: **N/A**
**1h**
Fire Wand

Given exclusively to moderators and cannot be obtained by regular players by normal means, except when a moderator gives away or sells theirs.
The **Fire Wand** is an unobtainable consumable which has been added since Growtopia's launch.
##  Function
When consumed on a player, it will immediately kills the player in a similar manner to the Psychotic Bunny.
