The **Manhole Cover** is an unsplicable non-solid door foreground block which was added as part of the Block Party 2 update on April 1, 2019.
##  Function
As a door, the Manhole Cover can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
Similarly to the Password Door, a Manhole Cover is different from normal doors in the sense that it requires a password which can be set by any player with access to the block. If any player inserts the correct password, they will be redirected to the set location. If an incorrect password is entered, though, the player will not pass through.
