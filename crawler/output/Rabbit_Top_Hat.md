The **Rabbit Top Hat** is an unsplicable hat item which was added as part of the Voucher Dayz update on April 7, 2022. The item was formally introduced on April 8, 2022, the date when the event arrived.
##  Function
Pick a card, any card!

Poof!

When equipped, the **Rabbit Top Hat** grants the _Punch Range : Rabbit Top Hat_ mod, which allows the player to punch one tile further. Additionally, it makes the player's name higher than usual.
