# Exquisite Scythe

Built to exacting specifications by GrowTech engineers to find and remove temporal anomalies from infected trees!

In any Chemical Combiner, mix together...
Anomalizing Pristine Scythe **(×10)** ,

This recipe will yield **1** item.
The **Anomalizing Exquisite Scythe** is an unsplicable hand item which was added as part of Summer Clash 2018.
##  Function
Harvester of souls... zombie souls that is!

Not today matey!

When equipped, the **Exquisite Scythe** grants the _Exquisite Scythe_ mod, which allows the player to kill zombies during a Pandemic.
