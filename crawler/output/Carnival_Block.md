Won as a common prize in **Mirror Maze** in the Carnival.
The **Carnival Block** is an unsplicable solid foreground block which was added as part of The Carnival update on October 13, 2014.
##  Function
When placed, the Carnival Block serves a purely aesthetic purpose.
However, when walking over the block, an animation plays that is similar to that of the sand timer block.
##  Trivia
  * The description of this item is an onomatopoeia of the music produced by Calliopes, which can be heard in the CARNIVAL worlds.
