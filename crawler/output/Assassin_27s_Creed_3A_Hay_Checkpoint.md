The **Assassin's Creed: Hay Checkpoint** is an unsplicable checkpoint foreground block which was added as part of Assassin's Creed 15th Anniversary Celebration on September 23, 2022.
##  Function
Being a checkpoint block, the Assassin's Creed: Hay Checkpoint acts as where the player respawns after dying.
After going through a Race Start Flag and then through a Race End Flag, all checkpoints will be reset and the player would respawn at the Main Door on death. The same goes with the Challenge Timer and /kick, /kickall command.
