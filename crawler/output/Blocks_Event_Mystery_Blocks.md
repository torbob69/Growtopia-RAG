# Blocks/Event Mystery Blocks

< Blocks
**Event Mystery Blocks** are special blocks that are used in events to drop random items, these blocks can be spawned trough events or placed by the player.
**Event Mystery Blocks**

Item: Description
Lava Pinata: Too hot to handle, so punch it instead!
Mystery Pinata: Put this on top of a bunch of items you want to give away. Once placed, anybody can break it and get the items! The mystery is that certain items will transform into something more festive when it explodes...
Organic Turkey: So fat, so tender, so expensive!!
Pinata: Put this on top of a bunch of items you want to give away. Once placed, anybody can break it and get the items!
Summer Surprise: It's a box filled with summer excitement! Smash it with your friends.
Thanksgiving Turkey: Gobble gobble! Release the turkeys and begin the festivities! Thanksgiving is upon us, and it's time to celebrate!
Ultra Pinata: This is summoned by the Pinata Bash event, it's not an item a player can use.
