# Famine's Steed

The undead steed of one of the four riders of the Apocalypse, FAMINE. This dark steed withers all that it passes.
Properties
This item never drops any seeds.

The **Famine's Steed** is an unsplicable feet item which was added as part of Halloween Update 2018 on October 26, 2018.
##  Function
Decay follows in your wake!

Knocked off your high horse!

When equipped, the **Famine's Steed** grants the _Speedy: Rider of the Apocalypse_ mod, which allows the player to move faster on land.
##  Trivia
  * The item is a reference to The Four Horsemen of the Apocalypse.
