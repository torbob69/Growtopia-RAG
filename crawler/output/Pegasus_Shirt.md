The **Pegasus Shirt** is an unsplicable shirt item that was added as part of the Pegasus Pursuit update on June 28, 2021.
##  Function
When equipped, the Pegasus Shirt serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Pegasus set, which consists of the following items:

    * Pegasus Crown (hat)

    * Pegasus Pauldrons (neck)

    * Pegasus Shirt (shirt)

    * Pegasus Pants (pants)

    * Pegasus Shoes (shoes)
