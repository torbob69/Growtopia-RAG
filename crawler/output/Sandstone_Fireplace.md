The **Sandstone Fireplace** is an unsplicable non-solid toggleable animated foreground block which was added as part of Spring Clash 2019 on March 1, 2019.
##  Function
Being a toggleable animated foreground block, a Sandstone Fireplace can be toggled on or off via punching. When toggled on, a Sandstone Fireplace will change its appearance, showing a 2-framed animation. As a light source, a Sandstone Fireplace emits light in dark areas.
