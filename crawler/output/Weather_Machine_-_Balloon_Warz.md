**Weather Machine - Balloon Warz** is an unsplicable non-solid weather machine foreground block which was added as part of the Balloon Warz update.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into a scene of colorful balloons flying during daytime.
