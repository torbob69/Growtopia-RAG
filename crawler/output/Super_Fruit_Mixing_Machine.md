The **Super Fruit Mixing Machine** is a feature which was added as part as part of Super Pineapple Party 2023 on June 9, 2023. The Super Fruit Mixing Machine can be accessed from the top left of the screen during Super Pineapple Party.
##  Function
The Super Fruit Mixing Machine can be used to combine 3 different types of tropical fruits to create an item out of it. The total number of fruits should add up to 50 to juice a new item. Depending on which fruit you mix, the chance of receiving a tropical item related to that fruit increases.
