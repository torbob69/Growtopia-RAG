# Lock-Bot Remote

This handy remote will call Lock-Bot to your world at the location you specify. It only works once, so choose wisely! Lock-Bot will leave after 24 hours.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **2 Hits** **2 Hits** – Restores after **2s** of inactivity
Gems Drop: **N/A**
**1h**
NPC Trading

Buy 1 of this item from ** Locke The Salesman or  Lock-Bot** for  World Lock **(x10)**.
"Hey, sometimes I'm busy out of town. If that's the case, you can use this handy Lock-Bot Remote to call up my robot pal! I don't trust him with my fanciest goodies, but he's still got plenty to offer. One use only, and his batteries last about 24 hours!"
The **Lock-Bot Remote** is an unsplicable consumable which was added as part of the Pet Battles update on June 11, 2016.
##  Function
When consumed, a Lock-Bot will appear in the same tile as the player. The Lock-Bot will despawn after 24 hours.
