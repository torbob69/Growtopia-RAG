The **Snakewolf** is an unsplicable feet item that was added as part of the Blocktor's Orders! update.
##  Function
You have serpent speed!

No longer slithering with the pack.

When equipped, the **Snakewolf** grants the _Speedy: Snakewolf_ mod, which allows the player to move faster on land.
