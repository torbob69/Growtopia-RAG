# Frangipani

Put a flower in your hair. All the girls are doing it this summer! Just don't let Jim catch you stealing flowers from his garden... He's Crazy!

The **Frangipani** is an unsplicable hat item which was added as part of SummerFest 2017 on June 30, 2017.
##  Function
When equipped, the Frangipani serves a purely cosmetic purpose.
##  Trivia
  * The Frangipani is based on a real-life flowering plant with the same name, which is considered sacred in various cultures. A flower of this type is traditionally worn over the person's ear.[[1]](https://growtopiawiki.com/w/Frangipani#cite_note-1)
  * The description of Frangipani contains a reference to Crazy Jim, whom is based on Crazy Dave, a fictional character from the _Plants vs. Zombies_ series.
