# Silver Dragon Statue

Congratulations, you placed in the top 3 of the Grand Tournament!
Properties
This item never drops any seeds.
This item can only be used in World-Locked worlds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item can be placed in two directions, depending on the direction you're facing.

Grand Tournament

One can be obtained by placing 2nd-3rd in the monthly Grand Tournament.
The **Silver Dragon Statue** is an unsplicable non-solid foreground block which was added as part of the Grand Tournament update on December 1, 2016.
##  Function
When placed, the Silver Dragon Statue serves a purely aesthetic purpose.
