The **Groovy Wallpaper** is an unsplicable background block that was added as part of Thanksgiving Week 2025 on November 20, 2025.
##  Function
When placed, the Stuffins' Poster serves a purely aesthetic purpose.
##  Trivia
  * This item's description is a reference to the media franchise Scooby-Doo.
