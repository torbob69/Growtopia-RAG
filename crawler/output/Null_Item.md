# Null Item
Unobtainable

This item does not have any recipe because it is no longer, or was never obtainable.
A **Null Item** is a placeholder name used mostly for upcoming items. The name is changed to actual item name when released. The name consists of "null_item" followed by item's internal ID.
##  Trivia
  * Null Seeds were the main cause of the second rollback. By using a Harvest Moon Blast, some players managed to obtain these seeds. Recycling the seed was very risky, as it could bring the player up to 4,294,967,295 gems (the maximum signed 32 bit integer value), or pull them down to -4,294,967,295 (the minimum signed 32 bit integer value).
  * Due to the localization test that happened in April 2020, descriptions to null items were leaked, which said, "ADD HERE!"
