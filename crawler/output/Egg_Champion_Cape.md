The **Egg Champion Cape** is an unsplicable back item which was added as part of Easter Week 2020.
##  Function
Flutter through the sky with a smile!

Please don't run away!

When equipped, the **Egg Champion Cape** grants the _Double Jump: Egg Champion Cape_ mod, which allows the player to jump a second time in mid-air.
