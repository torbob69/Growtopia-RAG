# Jelly Block (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
**Jelly Blocks** are unsplicable blocks which were first added during WinterFest 2017. The blocks are bouncy like Pinball Bumpers or Mushrooms.

  * Lime
  * Lemon
