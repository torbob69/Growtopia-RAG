The **Swamp Monster Onesie** is an unsplicable shirt item which was added as part of Myths and Legends, the first set of Marvelous Missions, on March 18, 2021.
##  Function
When equipped along with the Swamp Monster Head, the player leaves trails of green slime particles when walking.
##  Trivia
  * This item is considered a part of the Swamp Monster set, which consists of the following items:

    * Swamp Monster Head (hat)

    * Swamp Monster Onesie (shirt)
    * As suggested by the descriptions of the items, this set was inspired by various swamp monster myths from around the world.
