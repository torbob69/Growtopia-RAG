# Roots (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
**Roots** may refer to:
  * Roots, an update released in July 2019.
  * Roots, a block created from a Fertile Soil Block when a particular bountiful item's tree has finished growing on top of it.
  * Mature Roots, a block created from a Roots block when a particular bountiful item's tree has finished growing on top of it for the fourth time.
