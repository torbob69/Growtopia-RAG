The **Thanksgiving Frame** is an unsplicable background block which was added as part of Thanksgiving Week 2019.
##  Function
When placed, the item automatically connects with each other to form a frame around any block placed inside. If background blocks are to be used, Block Glue can be applied to connect them smoothly.
