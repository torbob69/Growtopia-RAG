The **Firefighter Jacket - Red** is an unsplicable shirt item that was added alongside Firefighter Pack on October 8, 2015.
##  Function
When equipped, the Firefighter Jacket - Red serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the red firefighter set, which consists of the following items:

    * Firefighter Helmet - Red (hat)

    * Oxygen Mask (face)

    * Firefighter Jacket - Red (shirt)

    * Firefighter Pants - Red (pants)

    * Fire Hose (hand)

    * Fire Ax (hand)

    * Firefighter Boots (feet)
  * The  Firefighter Jacket - Red is a recolor of  Firefighter Jacket - Yellow.
