##  Trivia
  * The Super Crate Box's name is derived from a retro-styled indie platformer with the same name, which was originally developed by the Dutch independent video game developer Vlambeer around 2010.
    * Being a fan of the game, _Growtopia_ 's co-developer Hamumu asked Vlambeer whether he could use the name "Super Crate Box" for an item in _Growtopia_ , to which the latter obliged.[[1]](https://growtopiawiki.com/w/Super_Crate_Box#cite_note-1)[[2]](https://growtopiawiki.com/w/Super_Crate_Box#cite_note-2)
  * The item's description references a quote from the 1995 film SE7EN.
