# Super Exploding Pineapple

Wait... this isn't any normal super pineapple! It looks like it's about to blow! STAND BACK!!!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Super Pineapple **(×1)** ,
Uranium Block **(×20)** and
Mysterious Chemical **(×1)**.
This recipe will yield **1** item.
Crimefighting Reward

Defeat  Pine-Fresh in crimefighting.
May give **1** item each time.
The **Super Exploding Pineapple** is an unsplicable consumable which was added as part of Super Pineapple Party 2017 on June 8, 2017.
##  Function
When consumed, it creates pineapples that explode in the air.
