# Green Curtains

Fabulous Green curtains, which you punch to open! We do not recommend punching curtains in real life to open them though, that would be dangerous!
Properties
This item never drops any seeds.
This item has special properties you can adjust with the Wrench.

Render Type: Single

Gems Drop: **N/A**

Combination

In any Chemical Combiner, mix together...
Field Grass **(×5)** ,
Window Curtains **(×50)** and
Celtic Block **(×10)**.
This recipe will yield **1** item.
The **Green Curtains** is an unsplicable non-solid toggleable animated foreground block which was added as part of St. Patrick's Week 2021 on March 11, 2021.
##  Function
Being a toggleable animated foreground block, a Green Curtains can be toggled on or off via punching. When toggled on, a Green Curtains will change its appearance, showing a 2-framed sparkling animation.
