# Zodiac Rabbit Ears

A pair of fancy bunny ears! They still cover your actual ears though!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Bunny Ears **(×5)** ,
Jade Pillar **(×6)** and
Paper Dividing Wall **(×20)**.
This recipe will yield **1** item.
The **Zodiac Rabbit Ears** is an unsplicable hat item which was added as part of Lunar New Year 2023 on January 21, 2023.
##  Function
When equipped, the Zodiac Rabbit Ears serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Zodiac Rabbit set, which consists of the following items:

    * Zodiac Rabbit Ears (Hat)

    * Zodiac Rabbit Onesie (Shirt)
  * The  Zodiac Rabbit Ears is a recolor of the  Bunny Ears.
