The **Zodiac Rabbit Onesie** is an unsplicable shirt item which was added as part of Lunar New Year 2023 on January 21, 2023.
##  Function
When equipped, the Zodiac Rabbit Onesie serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Zodiac Rabbit set, which consists of the following items:

    * Zodiac Rabbit Ears (Hat)

    * Zodiac Rabbit Onesie (Shirt)
