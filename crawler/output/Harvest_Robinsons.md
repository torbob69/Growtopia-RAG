# Harvest Robinsons

These special edition Air Robinsons are themed to celebrate the harvest, or just be bright crazy colors, like all basketball shoes.
Properties
This item never drops any seeds.
This item can be transmuted.

The **Harvest Robinsons** is an unsplicable feet item which was added as part of Harvest Fest 2016 on 15 September, 2016.
##  Function
You can move faster!

You are slow again.

When equipped, the **Harvest Robinsons** grants the _Speedy_ mod, which allows the player to move faster on land.
