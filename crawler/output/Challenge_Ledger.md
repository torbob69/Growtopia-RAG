# Challenge Ledger

A monolith of knowledge for all aspiring challengers! This ledger will display Daily Guild Challenge point totals for all members of the guild to which you belong (if any). And hey, even if you don't have a guild (which would be weird, considering how you get this), it'll still show the leading guilds in the Daily Guild Challenge! Now that's value!
Properties
This item never drops any seeds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item has special properties you can adjust with the Wrench.

Daily Challenge

Place in the top five of any Guild Daily Challenge (awarded to the Guild Leader only).
The **Challenge Ledger** is an unsplicable non-solid foreground block which was added as part of the Challengers Approach! update.
##  Function
The Challenge Ledger displays information about Guild Daily Challenges. Upon wrenching, the Challenge Ledger will display the time remaining until the next Guild Daily Challenge begins, the name of the last Guild Daily Challenge and the top five Guilds during the last Guild Daily Challenge, along with their point score.
During a Guild Daily Challenge, the Challenge Ledger will display the top six Guilds during the Guild Daily Challenge (instead of the top five), as well as the points contributions for all other members of the Guild.
