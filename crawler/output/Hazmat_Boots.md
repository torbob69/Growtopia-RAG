The **Hazmat Boots** is an unsplicable feet item which was added as part of the Geiger Day update on May 5, 2017, the same day Cinco De Mayo Week 2017 was released.
##  Function
Fire walk with me! Fire does 50% damage.

Your feet are no longer safe.

When equipped, the **Hazmat Boots** grants the _Fireproof_ mod, which allows the player to take 50% less damage from lava pain blocks.
Equipping the Hazmat Helmet, Hazmat Suit, Hazmat Pants, and Hazmat Boots allows the player to create Uranium Glowing Lures from Radioactive Bits.
##  Trivia
  * This item is considered a part of the hazmat set, which consists of the following items:

    * Hazmat Helmet (hair)

    * Hazmat Suit (shirt)

    * Hazmat Pants (pants)

    * Hazmat Boots (feet)
  * The Hazmat Boots is the only item in the hazmat set which grants a playmod when equipped.
