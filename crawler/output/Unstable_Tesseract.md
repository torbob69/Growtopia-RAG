The **Unstable Tesseract** is an unsplicable solid foreground block which was added as part of the Role Up! update.
##  Function
The Unstable Tesseract works almost the same as the MAGPLANT 5000, except that it only collects blocks dropped from breaking blocks or harvesting trees. In addition, it also has a lower capacity of 1,500. Another feature it lacks is a remote, which prevents players from automatically placing blocks from its storage.
##  Trivia
On 27th May, 2020 a glitch was discovered which could be used to make the Unstable Tesseract collect seeds instead of blocks. This glitch could also be used to make Gaia's Beacon collect blocks.
