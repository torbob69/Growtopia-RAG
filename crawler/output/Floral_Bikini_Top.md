# Floral Bikini Top

Scandalous!

Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision

**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Green.
Sew a  Silk Bolt - Floral to the previous bolt using a(n) **Triple Stretch Stitch**.
Lastly, sew a  Silk Bolt - Purple to the previous bolt using a(n) **Overcasting Stitch**.
Each recipe gives **1** item.
The **Floral Bikini Top** is an unsplicable shirt item which was added as part of SummerFest 2017 on June 30, 2017.
##  Function
When equipped, the Floral Bikini Top serves a purely cosmetic purpose.
