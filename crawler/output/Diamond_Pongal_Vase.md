The **Diamond Pongal Vase** is an unsplicable non-solid foreground block which was added as part of Pre-WinterFest 2024 on December 1, 2024.
##  Function
When placed, the Diamond Pongal Vase serves a purely aesthetic purpose.
##  Trivia
  * The  Diamond Pongal Vase is a recolor of the  Pongal Vase.
  * The  Diamond Pongal Vase was able to drop  seeds upon release, until it was fixed a day later.
