The **Pineapple Turnover** is an unsplicable consumable which was added as part of Super Pineapple Party 2017 on June 8, 2017.
##  Function
Get triple XP for using consumables.

Your stomach's rumbling.

When consumed, this item grants the _Food: Consumable XP_ mod for 30 minutes, which triples the xp whilst using consumables.
