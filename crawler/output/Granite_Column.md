The **Granite Column** is an unsplicable solid foreground block which was added as part of the Block Party 2 update on April 1, 2019.
##  Function
When placed, the Granite Column serves a fully aesthetic purpose.
##  Trivia
  * Despite its name, the Granite Column was modeled after the  Marble Block instead of the  Granite Block.
