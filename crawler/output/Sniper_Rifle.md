Able to knock the wings off a fly at a thousand paces, this perfectly-calibrated rifle is an insect's greatest fear! Wait, you weren't planning on using it against anything else, were you??

##  Function
Scope up: It's time to go long!

Scope down: Time to get close!

When equipped, the **Sniper Rifle** grants the _Punch Range: Snipeshot_ mod, which allows the player to punch one tile further. It will also replace the player's punching animation with shooting bullets.
