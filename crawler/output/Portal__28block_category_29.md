# Portal (block category)

A **portal** is a type of non-solid foreground block that immediately moves the player to another tile when touched. A block with an ID must first be placed on the tile for this to work.
##  List of Portals
Items: Special FunctionBlue Portal: None.
Hellgate: None.
Love Portal: None.
Lucky Portal: None.
Mystery Portal: Several targets can be set to this portal. When one enters it, they will be moved to a random one.
Orange Portal: None.
Sungate: Can only be entered while there are seven Obelisks activated in the world. Functions as a basic non-solid block otherwise.
Time-Space Rupture: None.
