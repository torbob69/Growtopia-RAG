# Neptune (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
The **Neptune Series** are limited clothes which come every SummerFest started during 2020. There are approximately 500 of each Neptune items in game, a chance to be obtained from smashing Super Summer Surprises. The **Neptune Series** were mostly used as an alterative for specific Legendary Quests.
