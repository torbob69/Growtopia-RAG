The **Jellyfish Trio** is an unsplicable artifact item which was added as part of Wildlife Weekend on March 10, 2023.
##  Function
Shocktacular!

When equipped, the **Jellyfish Trio** grants the _Double Jump : Jellyfish Trio_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * This item is considered a part of the Jellyfish set, which consists of the following items:

    * Jellyfish Onesie (Shirt)

    * Jellyfish Trio (Artifact)
