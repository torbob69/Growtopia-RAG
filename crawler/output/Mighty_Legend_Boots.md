The **Mighty Legend Boots** is an unsplicable feet item which was added as part of the Garuda's Glory update on August 26, 2022.
##  Function
When equipped, the Mighty Legend Boots serves a purely cosmetic purpose.
When equipped alongside the  Mighty Legend Armor,  Mighty Legend Pants,  Mighty Legend Helm and  Mighty Legend Gauntlets, the player will hover above the ground.
##  Trivia
  * This item is considered a part of the Mighty Legend set, which consists of the following items:

    * Mighty Legend Helm (Hat)

    * Mighty Legend Armor (Shirt)

    * Mighty Legend Pants (Pants)

    * Mighty Legend Boots (Feet)

    * Mighty Legend Gauntlets (Hand)
  * The Mighty Legend set is a reference to the fictional character Gatotkaca from the Sanskrit epics of Ancient India titled Mahabharata.
