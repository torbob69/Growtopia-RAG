# DNA (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
**DNA** refers to items which can be placed in a DNA Processor to make other items. See DNA Combinations for recipes using DNA. The types of DNA are:
  * Dino DNA Strand A-273
  * Dino DNA Strand G-137
  * Dino DNA Strand C-904
  * Dino DNA Strand T-658
  * Plant DNA Strand Y-985
  * Plant DNA Strand X-277
  * Raptor DNA Strand Omega
  * Raptor DNA Strand Alpha
