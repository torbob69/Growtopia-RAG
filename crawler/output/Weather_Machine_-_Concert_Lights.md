The **Weather Machine - Concert Lights** is an unsplicable non-solid weather machine foreground block which was added as part of Grow4Good Week 2026 on April 24, 2026.
##  Function
As a weather machine, the **Weather Machine - Concert Lights** can be toggled on or off via punching. When toggled on, it will change its appearance, transforming the world's background.
This weather machine features several special customization functions. To set the color for the colour shifts, dots, and background gradients, the player needs to enter an RGB (Red, Blue, Green) value. To separate the individual values, the player needs to use a comma.
