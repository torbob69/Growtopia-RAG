# Punk Purple Hoodie

Break out of the routine and set your own style (as long as it's purple)! This hoodie will keep you warm and, more importantly, looking great in all kinds of weather!
Properties
This item never drops any seeds.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Purple.
Sew a  Silk Bolt - Purple to the previous bolt using a(n) **Locking Stitch**.
Lastly, sew a  Silk Bolt - Purple to the previous bolt using a(n) **Zigzag Stitch**.
Each recipe gives **1** item.
The **Punk Purple Hoodie** is an unsplicable shirt item which was added as part of Player Appreciation Week 2018 Day 1 on August 6, 2018.
##  Function
When equipped, the Punk Purple Hoodie serves a purely cosmetic purpose.
##  Trivia
  * The **Punk Purple Hoodie** is one of the three hoodies released on the same day, the other two are Big Bad Blue Hoodie and Little Red Hoodie.
