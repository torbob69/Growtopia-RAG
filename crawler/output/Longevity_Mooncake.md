# Longevity Mooncake

This pastry is filled with a sweet bean paste. "Longevity" is imprinted on the top in ancient Growtopian script. Mix this with other Mooncakes in a Laboratory or E-Z Cook Oven to create special Harvest Festival items.

This item never drops any seeds.

The **Longevity Mooncake** is an unsplicable Mooncake consumable which was added as part of Harvest Festival 2013 on September 18, 2013.
##  Function
When consumed, the player will say "_YUM!_ " and do the _:D_ emote. It is, however, more commonly used to make exclusive Harvest Festival items in a Chemical Combiner.

### Silkworm Food     _Main article:Guide:Silkworm Care_
This consumable can be fed to a Silkworm to give it a red color, thus allowing it to produce 1–10  Silk Thread - Red per harvest.
##  Trivia
  * The higher a tree's rarity is, the more likely it is for the tree to drop a Mooncake.
