The **Bad Witch's Dress** is an unsplicable shirt item which was added as part of Halloween Week 2024 on October 23, 2025.
##  Function
When equipped, the **Bad Witch's Dress** serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Bad Witch set, which consists of the following items:

    * Bad Witch's Hat (hat)

    * Bad Witch's Dress (shirt)
  * The full Bad Witch set is a reference to a fictional character called Elphaba Thropp, from the movie Wicked.
