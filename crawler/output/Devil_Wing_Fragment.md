# Devil Wing Fragment

This is about half of a Devil Wing. So if you had four of these, you could make a pair of Devil Wings!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Rewards of Sacrifice

Sacrifice a(n)  Angel Wings or  Dark King's Offering (chance) to Growganoth.
The **Devil Wing Fragment** is an unsplicable consumable which was added on Halloween Week 2013 on October 28, 2013.
