# CyBlocks Starter Pack
Growtopia Store

Purchase the **CyBlocks Starter Pack** for **5,000 ** in the Growtopia Store.
"CyBlocks Starter Pack includes one Rare ShockBot and 10 random movement commands to use with it. ShockBot is a perma-item, is never lost when destroyed."
Every purchase will give **1** item.
The **Cyblocks Starter Pack** , was released alongside the March Update. This pack is available for 5,000 gems in the gem store.
##  Contents of the Pack
This pack includes:
  * Command - Move Right
  * Command - Move Down
  * Command - Move Left
  * Command - Move Up
  * Command - Pause
  * ShockBot - Level 1 x1
