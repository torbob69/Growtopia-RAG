# Sunflower Dress

A dress themed after the best type of flower!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Pants – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Wool Bolt.
Sew a  Silk Bolt - Black to the previous bolt using a(n) **Saddle Stitch**.
Lastly, sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Overcasting Stitch**.
Each recipe gives **1** item.
The **Sunflower Dress** is an unsplicable pants item which was added as part of Harvest Festival 2021 on September 16, 2021.
##  Function
When equipped, the Sunflower Dress serves a purely cosmetic purpose.
The  The Seven Seas : A Tale of Tentacles! mission requires 10 of this item.
##  Trivia
  * This item is considered a part of the feminine sunflower set, which consists of the following items:

    * Feminine Sunflower Hair (hair)

    * Feminine Sunflower Shirt (shirt)

    * Sunflower Dress (pants)
