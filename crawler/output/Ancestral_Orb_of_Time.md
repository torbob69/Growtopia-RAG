Combination

In any Chemical Combiner, mix together...

The **Ancestral Orb of Time** is an unsplicable artifact which was added as part of the Stuff! Update on October 1, 2018.
## Function
Effortless time...

Aw, no more time reduction.

When equipped, the **Ancestral Orb of Time** grants the _Provider Time Reduced..._ mod, which allows the player to reduce provider time by 1%.
