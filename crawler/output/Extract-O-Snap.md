The **Extract-O-Snap** is a consumable which was added as part of Summer Clash 2018 on June 1, 2018.
##  Function
When used upon a tile containing dropped items, it will show a list of all the items found in the tile. The player may then choose one stack of items to be grabbed. Unlike the Extractor Dynamo, which has infinite uses, an Extract-O-Snap can only be used once.
##  Trivia

  * Only the world owner can use the Extract-O-Snap.
