# START

A world render of START.
**START** is a world where new players are sent to when they start playing Growtopia for the first time. In there, they are taught the basics of Growtopia, such as chatting, splicing, events, etc., before going on by themselves.
##  Trivia
  * START has been remade for various languages by the community.
  * All versions of START, which also includes the worlds START2 and START3, are currently owned by the Developer account @Ubidev, but they were previously owned by the moderator @Jenuine and before that the ex-moderator Seil.
  * Older versions of the current START are archived as OLDSTART and STARTOLD.
  * The newest version of START was designed and built by ex-moderator's Fournos and Ottowo.
