The **Weather Machine - Ancestral Plane** is an unsplicable non-solid weather machine foreground block which was added as part of Voucher Dayz 2025 on November 13, 2025.
##  Function
As a weather machine, the Weather Machine - Ancestral Plane can be toggled on or off via punching. When toggled on, it will change its appearance, transforming the world's background.
