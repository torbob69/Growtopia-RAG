Harvest a  Guild Flag - Arrow Tree.__
The **Guild Flag - Arrow (Harlequin)** is an unsplicable non-solid foreground block which was added alongside the Guilds update on April 1, 2018.
##  Function
When placed, the Guild Flag - Arrow (Harlequin) will display the color of the seeds of the player's guild mascot.
