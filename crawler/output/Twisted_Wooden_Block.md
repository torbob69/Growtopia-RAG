The **Twisted Wooden Block** is an unsplicable solid foreground block which was added as part of Halloween Week 2020 on October 22, 2020.
##  Function
When placed, the Twisted Wooden Block serves a purely aesthetic purpose.
This item, alongside several other Halloween Week blocks, are considered derivatives of the Haunted House block, which was added in 2013.
