# Oxen Battle Shirt

Strong, hardy and reliable! This item has all the attributes of those who are born under the sign of the Zodiac Ox!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Red.
Sew a  Wool Bolt to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Silk Bolt - Floral to the previous bolt using a(n) **Triple Stretch Stitch**.
Each recipe gives **1** item.
The **Oxen Battle Shirt** is an unsplicable shirt item that was added as part of the Lunar New Year 2021 update on February 4, 2021.
##  Function
When equipped, the Oxen Battle Shirt serves a fully aesthetic purpose.
##  Trivia
  * This item is considered a part of the Oxen Battle set, which consists of the following items:

    * Oxen Battle Helm (Hat)

    * Oxen Battle Shirt (Shirt)

    * Oxen Battle Pants (Pants)

    * Oxen Battle Boots (Feet)
