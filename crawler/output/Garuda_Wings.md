The **Garuda Wings** is an unsplicable back item which was added as part of the Garuda's Glory update on August 26, 2022.
##  Function
For Glory!

Forsaken!

When equipped, the **Garuda Wings** grants the _Double-Jump: Garuda Wings_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * This item is considered a part of the Garuda set, which consists of the following items:

    * Garuda Mask (Hair)

    * Garuda Armor (Shirt)

    * Garuda Legs (Pants)

    * Garuda Boots (Feet)

    * Garuda Wings (Back)

    * Garuda Battle Axe (Hand)
  * The Garuda set is a reference to a Hindu demigod of the same name described as the king of the birds known as the state insignia of India, Indonesia, and Thailand.
