# Ghost Mobile

Haunted by the spirit of a legendary stunt driver, this car can go from zero to spectral in 0.6 seconds!
Properties
This item never drops any seeds.

**1h**
The **Ghost Mobile** is a feet item that was introduced during the Time-Tossed! update. It is an extremely rare drop from exploding a Spirit Storage Unit with a Boss Goo.
##  Function
Faster than death!

Back to life!

When equipped, the **Ghost Mobile** grants the _Speedy: Ghost Mobile_ mod, which allows the player to move faster on land.
##  Trivia
  * The **Ghost Mobile** has an effect similar to the effect of the Ancestral Tesseract of Dimensions when viewed with Spectral Goggles.
