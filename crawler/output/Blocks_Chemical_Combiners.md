# Blocks/Chemical Combiners

< Blocks
**Chemical Combiners** are a type of foreground block which can be punched to be opened or closed. When opened, the chemical combiner will act as a non-solid block, and sets of three ingredients can be dropped and punching it will create a new item if the recipe is valid. When closed, nobody can see or access the items, and the chemical combiner will become a solid block.
