# Silk Skirt - Blue

A classic look, available in a variety of colors.
Properties
This item never drops any seeds.
Data

Type: Pants – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Blue.
Sew a  Silk Bolt - Blue to the previous bolt using a(n) **Straight Stitch**.
Lastly, sew a  Silk Bolt - White to the previous bolt using a(n) **Zigzag Stitch**.
Each recipe gives **1** item.
The **Silk Skirt - Blue** is an unsplicable pants item which was added as part of the Silkworms! update on February 1, 2016.
##  Function
When equipped, the Silk Skirt - Blue serves a purely cosmetic purpose.
##  Trivia
  * The **Silk Skirt - Blue** is one of the silk skirts added to the game, others include Silk Skirt - Purple, Silk Skirt - Black, Silk Skirt - Aqua, Silk Skirt - White, Silk Skirt - Red.
