# Silk Tie - Black

You will command respect in this power tie!
Properties
This item never drops any seeds.
Data

Type: Chest – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Grey.
Sew a  Silk Bolt - Black to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Silk Bolt - Black to the previous bolt using a(n) **Overcasting Stitch**.
Each recipe gives **1** item.
The **Silk Tie - Black** is an unsplicable chest item which was added as part of the Silkworm update on February 1, 2016.
##  Function
When equipped, the Silk Tie - Black serves a purely cosmetic purpose.
##  Trivia
  * This item is one of the five Silk Ties, the other four being Silk Tie - Yellow, Silk Tie - Blue, Silk Bolt - Grey, and Silk Tie - Red.
