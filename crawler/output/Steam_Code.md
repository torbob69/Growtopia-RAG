# Steam Code

The Steam Code is a law which is in the description of most steam blocks. It's purpose is the prevent players from placing too many steam blocks in one world which could create too much lag for players.
So far the two rules which are a part of the code are:
  * _The Steam Code prohibits more than 100 steam-powered items per world._
  * _The Steam Code prohibits more than 20 steam generators in a world._

Steam blocks which are considered "steam-powered items" include the Steam Door, Steam Vent, Steam Launcher, Steam Collector, and Steam Spikes.
Steam blocks which are considered "steam generators" include the Steam Revolver, Steam Stomper and Steam Engine.
