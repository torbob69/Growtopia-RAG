The **Explorer's Shovel** is a splicable hand item which was added alongside the Adventure Pack on June 14, 2014.
##  Function
You can smash bricks more quickly.

Smash time is over.

When equipped, the **Explorer's Shovel** grants the _Enhanced Digging_ mod, which allows the player to break blocks faster.
