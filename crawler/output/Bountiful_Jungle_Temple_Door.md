The **Bountiful Jungle Temple Door** is an unsplicable non-solid door foreground block which was added as part of the Roots (update) on July 11, 2019.
##  Function
As a door, the Jungle Temple Door can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
