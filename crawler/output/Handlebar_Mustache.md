# Handlebar Mustache

Probably the best mustache named after the part you hold onto on a bicycle!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Face – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Mining

1 has a chance to be dropped from exploding  Pure Magic Ore using  Mining Explosives, which are naturally generated in mines.
The **Handlebar Mustache** is an unsplicable face item which was added as part of Player Appreciation Week 2020 Day 7.
##  Function
When equipped, the Handlebar Mustache serves a purely cosmetic purpose.
##  Trivia
  * When _Handlebar Mustache_ is recycled, the player will gain 250 Gems.
  * The Handlebar Mustache is one of the three clothing items added on Player Appreciation Week 2020 Day 7 obtainable via breaking Golden Treasure Hoards, alongside the Long Nose and Golden Cuff Beard.
