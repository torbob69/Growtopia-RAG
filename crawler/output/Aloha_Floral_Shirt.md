# Aloha Floral Shirt

A Hawaiian style shirt straight out of the tropics to keep you cool and fantastically floral!
Properties
This item never drops any seeds.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Floral.
Sew a  Silk Bolt - Black to the previous bolt using a(n) **Locking Stitch**.
Lastly, sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Saddle Stitch**.
Each recipe gives **1** item.
The **Aloha Floral Shirt** is an unsplicable shirt item which was added as part of SummerFest 2019 on June 27, 2019.
##  Function
When equipped, the Aloha Floral Shirt serves a purely cosmetic purpose.
##  Trivia
  * The Aloha Floral Shirt is one of two aloha floral in Growtopia, alongside Aloha Floral Blouse.
