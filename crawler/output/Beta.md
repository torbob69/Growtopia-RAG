# Beta

[](https://growtopiawiki.com/w/File:Image-;-\(.png)The beta server.
**Beta** is a server used to test new items that will be added to _Growtopia_ , but whatever happens in Beta never saves. It is rarely used to test new updates before officially releasing them to the public.
Players can type in /beta into the chat to enter/exit the beta server or in some cases the beta server can become accessible via a button in the /news that plays the role of an invitation. Only when it is available. However, there will be a "level", "status" and "hours played" requirement to enter the beta server. And in some cases only certain clients (devices) can access the beta server.
  * If the player meets the requirements, they will enter the beta server immediately (e.g. must be level 30 and played for 100 hours). And note that these requirements can vary from a beta to another.

  * If the player doesn't, it will display a message that they do not meet the requirements, and they cannot enter the beta server. And if the players are supposed to join using a button and the player does not meet the requirements, the button will not show up.

If the player uses /beta when it is not available, it will tell them: "_Beta is not available to anyone right now._ "
On February 17, 2020, Ubisoft introduced the Content Creator Program where they selectively pick content creators that fits in their criteria. These chosen content creators will receive multiple perks in exchange for promoting Growtopia on their respective platforms, one of those perks is access to /beta. Read more here: Content Creator Program FAQ.
On October 1, 2024, The dungeon beta test system was the first time of it type being accessible by a button from the gazette. Additionally, content creators and moderators were given a chance to each vouch for some players, giving them the opportunity to bypass the requirements. (Devices requirement can not be bypassed) Read the full announcement in the Official Growtopia forums for more information.
