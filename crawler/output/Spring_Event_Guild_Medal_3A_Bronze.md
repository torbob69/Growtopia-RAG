# Spring Event Guild Medal: Bronze

Awarded for achieving THIRD PLACE in the Guild Leaderboards during the Spring season. Show off your victory by placing this medal in your world, and congratulations!
Properties
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item cannot be dropped or traded.

The **Spring Event Guild Medal: Bronze** is an unsplicable platform foreground block which was added as part of Spring Clash 2019. It is given to the Guild Leader for achieving 3rd place in a Spring Grow Event.
##  Function
A Spring Event Guild Medal: Bronze behaves as a platform, thus a player can jump pass through it from underneath.
