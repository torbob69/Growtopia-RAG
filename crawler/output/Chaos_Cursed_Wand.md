The **Chaos Cursed Wand** is an unsplicable hand item which was added as part of Halloween Week 2014 on October 30, 2014.
##  Function
You can launch deadly chaos!

Back to punching.

When equipped, the **Chaos Cursed Wand** grants the _Chaos_ mod, which allows the player to break blocks faster. It also changes the player's punches into red swirls and creates a growtopian soul (as seen when players respawn) on impact, except with a more faded color.
