The Arm Blaster is an unsplicable hand item which was added as a part of the Startopia 2.0 update on June 1, 2020.
##  Function
This is Mega err Dude

I Wily better stop now

When equipped, the **Arm Blaster** grants the _Punch Damage: Arm Blaster_ mod, which allows the player to break blocks faster. It replaces the punching animation to a red laser similar to the punch effect of a Cyclopean Visor.
##  Trivia
  * Arm Blaster is a reference to the Mega Man's Mega-Buster & Dr.Wily from Mega Man Classic series.
