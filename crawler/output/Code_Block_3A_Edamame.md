The Code Block: Edamame is a block which makes up a quarter of a QR code, added during the Systems Update. It is required for the Discover The Truth riddle.
To obtain, use a Henchman at the top right corner of a world, take a Superpower - Heat Vision, Superpower - Ice Shards, Superpower - Super Strength and Superpower - Shocking Fist, use them in order and then run away. Doing so will spawn the Code Block: Edamame.
