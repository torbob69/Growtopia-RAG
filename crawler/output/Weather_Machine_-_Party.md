The **Weather Machine - Party** is an unsplicable non-solid weather machine foreground block which was added as part of Anniversary Week 2015 on January 11, 2015.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into a vibrant scenery with constantly changing colors.
