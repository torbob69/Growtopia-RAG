# Growformer PowerKey

Boop beep! Give this a click to shift your Growformer into its alternate form! Also activates its security system if you have to leave it in the parking lot!
Properties
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item cannot be dropped or traded.
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **1 Hits** **1 Hits** – Restores after **2s** of inactivity
Gems Drop: **N/A**
**1h**
The **Growformer PowerKey** is an untradeable consumable that comes with equipping the Go-Go-Growformer!. When used, it will transform the Go-Go-Growformer! into a robot.
##  Trivia
  * This item can be returned into the player’s backpack after recycling or trashing it by re-equipping Go-Go-Growformer!.
