The **Sewing Machine** is a splicable non-solid foreground block which was added as part of the Silkworms! update.
##  Function
_See main article:Guide:Sewing_
A Sewing Machine allows players to sew items using 3 Silk Bolts.
By default, each player only has the Straight stitch. By sewing more, there is a chance that players can unlock different types of stitches to sew different items. The types of stitches are:
  * Straight Stitch
  * Zigzag Stitch
  * Overcasting Stitch
  * Locking Stitch
  * Triple Stretch Stitch
  * Saddle Stitch
  * Blind Stitch

##  Trivia
  * Sewing an incorrect recipe will give a Patchwork Mess.
