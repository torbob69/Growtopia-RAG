It can be found naturally generated in Fruit Kingdom-blasted worlds.

The **Juice Waterfall** is an unsplicable solid foreground block which was added as part of Super Pineapple Party 2026 on June 11, 2026.
##  Function
Being a type of vertical one side collision block, the **Juice Waterfall** allows players to pass through the block downwards but blocks them from passing the block upwards.
