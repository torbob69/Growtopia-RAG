# DNA Extractor

This experimental device can extract prehistoric DNA from objects which contain even small traces. To give it a try, just use an item on it and see what you find! This is very new technology, so results are unpredictable, and rarely successful.

The **DNA Extractor** is a non-solid foreground block which was added as part of the Growassic Park update.
##  Function
A DNA Extractor can be used to extract DNAs from Amber Blocks, Dino Ribcages, T-Rex Skulls or Ancient Plant Seeds, which will all be consumed as part of the process. The chance for one to be obtained from a single extraction is 2%. An Extractium Ore can be used to recieve a guaranteed DNA drop.
Extracted DNAs can then be used in a DNA Processor.
Extracting an Amber Block also has a chance to give a Rayman's Nose.
