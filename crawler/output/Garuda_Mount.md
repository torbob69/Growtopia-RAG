The **Garuda Mount** is an unsplicable feet item which was added as part of the Garuda's Glory update on August 7, 2025.
##  Function
Carried to the skies!

Brought back down to Earth.

When equipped, the **Garuda Mount** grants the _High Jump: Garuda Mount_ mod, which allows the player to jump one tile higher.
