# Legendary Clash Key - Series 8

A key to a mysterious treasure! This key is for Clash Series 8, running from Summer Clash 2025 through Spring Clash 2026. After three seasons, those who collect at least 10 of these keys will be able to open a special treasure chest. Make sure you have enough - just one won't do it!
Properties
This item cannot be dropped or traded.
This item never drops any seeds.
This item has no use... by itself.

**1h**
**Legendary Clash Key - Series 8** is an unsplicable component that was added on July 18, 2025. It can be obtained after completing a branch which can be found by tapping on the Leaderboard Button and tapping on "Summer/Winter/Spring Clash Rewards". The player needs to buy everything in the branch before receiving the Legendary Clash Key & Finale Ticket in the event span from Summer 2025 to Spring 2026.
##  Function
One needs to collect 10 **Legendary Clash Key - Series 8** throughout all the Seasonal Clashes to be able to claim Turbine Wings during Spring Clash 2026.
##  Trivia
  * Legendary Clash Key - Series 8 was accidentally made available during first Spring Clash of 2025, which was Cooking Conquerors on March 7th.
