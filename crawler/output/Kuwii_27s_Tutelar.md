The **Kuwii's Tutelar** is an unsplicable artifact item which was added as part of Wonder Week 2025 - Day 7 on October 12, 2025.
##  Function
Release your inhibitions!

No one else!

When equipped, the **Kuwii's Tutelar** grants the _Extra Blocks : Kuwii's Tutelar_ mod, which allows the player to get a chance for a block to drop an extra of itself when broken.
##  Trivia
  * This item is sponsored by Kuwii for completing all the Epic Quests.
  * Although this item creates a visual effect that displays the player's silhouette, the effect does not apply to customizable items. These items appear in their default, non-customized form within the silhouette.
