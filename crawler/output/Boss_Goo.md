# Boss Goo

Rare spectral ichor! You don't get this from just any ghost. I bet it could be turned into something useful... Warning: Is sure to overload any Spirit Storage Unit! Good news, though: The more ghosts you have in the SSU before you add this, the better your odds for something really good!
Properties
This item never drops any seeds.
This item has no use... by itself.

The **Boss Goo** is an unsplicable component which was added as part of the B.O.O. Update on May 1, 2018.
##  Function
When dropped into a Spirit Storage Unit after reaching at least 100%, it will automatically overload, the higher the percentage before using it, the more likely it is for the player to receive a better item.      _Main article:Spirit Storage Unit#Boss Goo Drops_
