The **Zero's Arms** is an unsplicable hand item which was added as part of Star Trek Prodigy on June 27, 2022.
##  Function
In control!

Outta control!

When equipped, the **Zero's Arms** grants the _Punch Damage : Zero's Arms_ mod, which allows the player to break blocks faster. It also replaces the player's fist with a slashing effect.
##  Trivia
  * This item is considered a part of the Zero set, which consists of the following items:

    * Zero's Containment Hood (Hair)

    * Zero's Medusan Mask (Face)

    * Zero's Arms (Hand)

    * Zero's Legs (Pants)

    * Zero's Shoes (Feet)
