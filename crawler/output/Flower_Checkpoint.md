The **Flower Checkpoint** is a splicable non-solid checkpoint foreground block which was added on Player Appreciation Week 2014 Day 3 on August 10, 2014.
##  Function
Being a checkpoint block, the Flower Checkpoint acts as where the player respawns after dying.
After going through a Race Start Flag and then through a Race End Flag, all checkpoints will be reset and the player would respawn at the Main Door on death. The same goes with the Challenge Timer and /kick, /kickall command.
