# Elder Sigil

This is the page for **Elder Sigil**.
You may be looking for **Sigil Of K'Tesh** instead.
This mystical item will teleport you directly into the gaping maw of Growganoth as many times you want for a short period. You must be in the GROWGANOTH world in order to use this item!

This item never drops any seeds.

Purchase the **Elder Sigil Pack** for **10,000 ** in the Growtopia Store.
"This mystical item will teleport you directly into the gaping maw of Growganoth as many times you want for a short period. You must be in the GROWGANOTH world in order to use this item!"
Every purchase will give **5** items.
The **Elder Sigil** is an unsplicable consumable item which was added as part of Halloween Week 2023 on October 19, 2023.
##  Function
When used, the Elder Sigil grants the _Elder Sigil : Mark Of K'Tesh'_ mod which allows the player to use the item to teleport directly to the Maw of Growganoth for a duration of 2 minutes. Using this item does not count for the Growganoth's Game daily challenge.
When used in a non-GROWGANOTH world, the player says, "_The sigil fizzles... try using it near Growganoth!_ "
##  Trivia
  * Elder Sigil's design and function are based on  Sigil Of K'Tesh.
