# Containment Field Power Node

Power this node with little ghosts to activate. Put four active nodes near each other to create a containment field that can weaken a Boss Ghost! Note: The Boss Ghost can only be damaged while weakened inside the field!

The **Containment Field Power Node** is an unsplicable non-solid foreground block which was added as part of the B.O.O. Update on May 1, 2018.
##  Function
When four nodes are placed and each node has been activated using a Ghost-In-A-Jar, a containment field will be created between the four nodes. If a Boss Ghost is within the containment field, the ghost will be weakened. The Containment Field Power Node will deactivate over some time and will require more Ghost-In-A-Jar in order to be activated again.
