**Beowulf's Beard** is an unsplicable face item which was added as part of the All Howl's Eve monthly event update on July 19, 2021. The item was formally introduced on July 21, 2021, the date All Howl's Eve arrived.
##  Function
When equipped, Beowulf's Beard serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Beowulf set, which consists of the following items:

    * Beowulf's Helm (Hat)

    * Beowulf's Beard (Face)

    * Beowulf's Shirt (Shirt)

    * Beowulf's Pants (Pants)

    * Beowulf's Blade (Hand)
  * The Beowulf set is based on a legendary heroic figure of the same name.
