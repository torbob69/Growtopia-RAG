The **Red Pet Apatoceratops** is an unsplicable hand item which was added as part of Growassic Park on October 7, 2016.
##  Function
When equipped, the Red Pet Apatoceratops serves a purely cosmetic purpose and summons a Red Pet Apatoceratops which follows the player around.
