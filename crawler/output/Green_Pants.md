The **Green Pants** is an unsplicable pants item which was added as part of St. Patrick's Week 2013 on March 13, 2013.
##  Function
When equipped, the Green Pants serves a fully cosmetic purpose.
##  Trivia
  * This item is considered a part of the Leprechaun set, which consists of the following items:

    * Leprechaun Hat (Hat)

    * Orange Beard (Face)

    * Leprechaun Suit (Shirt)

    * Green Pants (Pants)

    * Leprechaun Shoes (Feet)
