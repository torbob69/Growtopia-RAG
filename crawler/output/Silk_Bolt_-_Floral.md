# Silk Bolt - Floral

Sew silk items by using this in a sewing machine. It takes 3 bolts of silk to craft an item.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **4 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Summer Surprise

| Chance to be dropped from breaking a:
•  Summer Surprise
•  Treasure Chest naturally-generated in a beach-blasted world  |
May yield **1** item each time.
The **Silk Bolt - Floral** is an unsplicable consumable which was added as part of SummerFest 2017 on June 30, 2017.
##  Function
This item serves no purpose by itself.
