The **Primordial Jade Lance** is an unsplicable and untradable hand item which was added as part of Player Appreciation Week 2021 Day 1 on August 23, 2021.
##  Function
Ancient and justified!

Jaded!

When equipped, the **Primordial Jade Lance** grants the _Punch Damage : Primordial Jade Lance_ mod, which allows the player to break blocks faster. It also replaces the player's Fist with a green cosmic punching effect.
##  Trivia
  * The Primordial Jade Lance is a reference to the Primordial Jade Winged-Spear from the action role-playing game Genshin Impact.
