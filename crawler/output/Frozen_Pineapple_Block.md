# Frozen Pineapple Block

The problem with frozen pineapple is it gets mushy when it thaws. So this one has a built-in liquid nitrogen tank to keep it from ever thawing!

The **Frozen Pineapple Block** is an unsplicable solid slippery foreground block which was added as part of Super Pineapple Party 2015 on May 30, 2015.
##  Function
Being a slippery block, walking on a Frozen Pineapple Block causes the player to slide.
