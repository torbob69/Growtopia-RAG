# Friendly Coconut

This coconut is a bit of a castaway. Some say his face was painted on by a Growtopian who washed up on a desert island and didn't have a mirror!

The **Friendly Coconut** is an unsplicable solid foreground block which was added as part of SummerFest 2020 on July 3, 2020.
##  Function
When placed, the Friendly Coconut serves a purely aesthetic purpose.
##  Trivia
  * The Friendly Coconut is a reference to Wilson, the volleyball from the movie "Cast Away" which had a face drawn on with blood.
