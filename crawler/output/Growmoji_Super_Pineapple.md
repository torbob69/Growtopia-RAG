# Growmoji Super Pineapple

Pop a Super Pineapple into your chat! Just consume this to add it to your available growmojis!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
**Pineapple Magic**

Rewarded from the  Pineapple Magic mod.
_May yield**1** item each._
_Unlocked when at least 82,500,000 pineapples have been eaten globally. This item can only be obtained duringSuper Pineapple Party._
The **Growmoji Super Pineapple** is an unsplicable growmoji consumable which was added as part of Super Pineapple Party 2018 on June 1, 2018.
##  Function
When consumed, the player will be able to use the (pine) Growmoji.
