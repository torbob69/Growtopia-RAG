# Sheep

Baaaaaaa. You can shear a sheep once every few days!
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

**1h**

Combination

In any Chemical Combiner, mix together...
Ancestor Mooncake **(×1)** ,
Prosperity Mooncake **(×4)** and
Harmony Mooncake **(×4)**.
This recipe will yield **1** item.
Mooncake Offering

1 may be received as a common reward from offering mooncakes using an Offering Table.
The **Sheep** is an unsplicable non-solid provider foreground block which was added as part of Harvest Festival 2016 on September 15, 2016.
##  Function
When placed, the Sheep can produce up to 3 Wool every 3 days. A Sheep Shears can give twice as much wool per harvest, thus making the maximum amount of wool per sheep 6.
