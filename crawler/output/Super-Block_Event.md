# Super-Block Event

The **Super-Block Event** was a removed Grow Event added as part of the Guilds update on April 1, 2018. It began on April 13, 2018, a day after Easter Week had concluded,[[1]](https://growtopiawiki.com/w/Super-Block_Event#cite_note-1) and ended on April 16, 2018, thereby lasting for 4 days in total. This was the first and only occurrence of the event.
The Super-Block Event was the first ever guild event added to the game, and is considered a precursor to the current version of Seasonal Clashes.

##  Point System
Action: Points gained
| Break any block with a rarity of 5 or more. Blocks without rarity were not counted.   | • Amount of Points may vary based on the item's rarity.
• For example, a Chandelier yielded +12 Points each when broken.   |
| Harvest any tree with a rarity of 5 or more. Trees without rarity were counted.   | • Amount of Points may vary based on the tree's rarity.
• For example, a Chandelier Tree yielded +94 Points each when harvested, while a Director's Chair Tree yielded +70 each.
• Trees without rarity, such as Pineapple Trees and Wizard's Staff Trees yielded +217 Points each.   |
|  Splice any tree with a rarity of 5 or more.   | • Amount of Points may vary based on the tree's rarity.
• For example, a Ripper Wings Tree yielded +208 Points each when spliced.   |
Consume a  Grow Spray Fertilizer on any tree.: • +8 Points were given per usage.
Consume a  Deluxe Grow Spray on any tree.: • +200 Points were given per usage.
