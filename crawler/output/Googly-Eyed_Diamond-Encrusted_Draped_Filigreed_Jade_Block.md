The **Googly-Eyed Diamond-Encrusted Draped Filigreed Jade Block** is an unsplicable solid foreground block which was added alongside the Fashion Pack on May 15, 2015.
##  Function
When placed, the Googly-Eyed Diamond-Encrusted Draped Filigreed Jade Block serves a fully aesthetic purpose.
