The **Weather Machine - Autumn** is an unsplicable weather machine which was added as part of Harvest Festival 2017 on October 4, 2017.
##  Function
When placed and activated, the Weather Machine - Autumn changes the world's background. The sky takes on a blue-pink gradient and reddish-brown hills stretch across the landscape. A pile of leaves occupy the foreground, with a few falling from the sky.
