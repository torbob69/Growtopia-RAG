# Lucky Portal

This portal isn't actually lucky unless you set a destination for it that is lucky. So it's really up to you!
Properties
This item never drops any seeds.
This item has special properties you can adjust with the Wrench.

The **Lucky Portal** is an unsplicable non-solid portal foreground block which was added as part of St. Patrick's Week 2017.
##  Function
Being a type of portal, the Lucky Portal immediately moves the player to another tile when touched. A block with an ID must first be placed on the tile for this to work.
