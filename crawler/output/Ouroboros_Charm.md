The **Ouroboros Charm** is an unsplicable chest item which was added as September 2021’s Item Of The Month on September 1, 2021.
##  Function
Endless cycle!

Seemingly not that endless!!

When equipped, the **Ouroboros Charm** grants the _Build Range: Ouroboros Charm_ mod, which allows the player to build one tile further. Additionally, it replaces the player's punching animation to orange Ouroboros circles which leave a trail of sparkles.
##  Trivia
  * This item is a reference to Ouroboros, a symbol from ancient Egyptian mythology that represents cycle of life.
