##  Function
Dangerous Fish Activate!

As dangerous as a Goldfish!

When equipped, the **Swordfish Sword** grants the _Punch Damage: Swordfish Sword!_ mod, which allows the player to break blocks faster.
##  Trivia
  * The description of the Swordfish Sword contains a reference to "The pen is mightier than the sword", an adage penned by English author Edward Bulwer-Lytton in 1839.
