The **Map of Tyr** is an unsplicable hand item which was added as part of the Treasure Hunt update.
##  Function     _Main article:Guide:Treasure Hunting/Map of Tyr_
By successfully performing a massive trauma surgery in a world with Weather Machine - Night activated, a player holding the Map of Tyr has a chance to earn Tyr's Spear. This map can only be used during Tuesday (Growtopia Time).
##  Trivia
  * The name of this map and its prize references Tyr, the Nordic god of war.
