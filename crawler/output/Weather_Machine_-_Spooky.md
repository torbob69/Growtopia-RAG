The **Weather Machine - Spooky** is an unsplicable non-solid foreground weather machine block which was added as part of Halloween Week 2013 on October 28, 2013.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into a nighttime cemetery scenery. Bats will occasionally fly out of the mansion as a visual effect.
##  Trivia
  * The description of this item is a reference to the lyrics of _Thriller_ , a song recorded by American singer Michael Jackson.
