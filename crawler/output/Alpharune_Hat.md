The **Alpharune Hat** is an unsplicable hat item which was added as November 2024's Monthly Subscriber's Item on November 1, 2024.
##  Function
When equipped, the Alpharune Hat serves a fully cosmetic purpose.
##  Trivia
  * The Alpharune Hat's design is a reference to a hat worn by Ralsei, a character from the video game Deltarune, which alludes to the item's name.
