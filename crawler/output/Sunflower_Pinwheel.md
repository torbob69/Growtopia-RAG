# Sunflower Pinwheel

A sunflower-themed pinwheel.
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.
Data: Paint PreviewType — Foreground Block – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single
Collision Type: No Collision
Hardness: **12 Hits** **9 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Combination

In any Chemical Combiner, mix together...
Balance Mooncake **(×1)** ,
Purity Mooncake **(×1)** and
Unity Mooncake **(×1)**.
This recipe will yield **1** item.
Mooncake Offering

1 may be received as an uncommon reward from offering mooncakes using an Offering Table.
The **Sunflower Pinwheel** is an unsplicable non-solid foreground block which was added as part of Harvest Festival 2021 on September 16, 2021.
##  Function
When placed, the Sunflower Pinwheel serves a purely aesthetic purpose.
