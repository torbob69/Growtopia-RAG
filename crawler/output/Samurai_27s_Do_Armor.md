The **Samurai's Do Armor** is an unsplicable shirt item which was added as part of Player Appreciation Week 2019 Day 4 on August 22, 2019.
##  Function
When equipped, the Samurai's Do Armor serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Samurai set, which consists of the following items:

    * Samurai's Kabuto (Hat)

    * Samurai's Do Armor (Shirt)

    * Samurai's Suneate & Leggings (Pants)

    * Samurai's Waraji (Feet)
  * The description of this item is a reference to a quote made by Yoda in the movie The Empire Strikes Back.
