# Marker (block category)

**Markers** are a type of of non-solid foreground block. Players can set an ID, and have doors lead to them, however they cannot be entered into.
##  List of Markers
Items: Special FunctionCarnival Landing: Can only be found in the world **CARNIVAL**.
Gruesome Marker: None.

Objective Marker: None.
Path Marker: None.
