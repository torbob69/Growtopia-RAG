# Shield of Mining

Protects from falling debris. Also quite handy in a fight.
Properties
This item never drops any seeds.
This item can be transmuted.

Type: Hand – Clothes
Render Type: Single

Gems Drop: **N/A**
**1h**
Mining

1 has a chance to be dropped from exploding  Pure Magic Ore using  Mining Explosives, which are naturally generated in mines.
The **Shield of Mining** is a hand item which was added as a part of the Spelunkorama Strikes Back! update.
##  Function
When equipped, the **Shield of Mining** grants the _Knock Back Reduction_ mod, which allows the player to resist a percentage of knockback when punched by other players.
