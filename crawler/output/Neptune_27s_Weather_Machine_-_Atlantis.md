The **Neptune's Weather Machine - Atlantis** is an unsplicable non-solid weather machine foreground block which was added as part of SummerFest 2024 on July 11, 2024.
##  Function
As a weather machine, the Neptune's Weather Machine - Atlantis can be toggled on or off via punching. When toggled on, it will change its appearance, transforming the world's background weather into a underwater scenery containing a city.
Step 14 of the  Quest Of The Owl requires the player to deliver 1 of this item. Golden Silk Scarf can be given as an alternative.
