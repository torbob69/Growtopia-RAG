# Blocks/Game Blocks

< Blocks
**Game Blocks** are blocks used with Game Generators, each block has its own unique purposes.
**Game Blocks**

Item: Description
Busted Game Block: This Game Block has been smashed. It will rebuild when the Game is over.
Carried Game Egg: A flag being carried by a player. Get moving!
Carried Game Flag: A flag being carried by a player.
Game Block: Use your wrench to set which team this block belongs to! During a Game, the block can be smashed according to the Game rules, and it will rebuild after the game ends.
Game Egg: Use your wrench to set which team this flag belongs to! During a Game, players can steal enemy flags and deliver them to their own Game Goals.
Game Flag: Use your wrench to set which team this flag belongs to! During a Game, players can steal enemy flags and deliver them to their own Game Goals.
Game Goal: Use your wrench to set which team this block belongs to! During a Game, you may want to bring Flags here, or just reach here yourself, depending on the rules.
Game Goal Egg Basket: Use your wrench to set which team this block belongs to! During a Game, you may want to bring Eggs here.
Game Grave: Use your wrench to set which team this block belongs to! During a Game, players of that team will respawn here.
Game Grave Egg: Use your wrench to set which team this block belongs to! During a Game, players of that team will respawn here.
Missing Game Egg: This egg has been taken! It will return when the Game is over...
Missing Game Flag: This flag has been taken. It will return when the Game is over.
Staging Platform: If a player stands on this, they have first priority on joining a Game. Use your wrench to set which team this platform will assign them to!
