The **Assassin's Creed: Renaissance Scaffolding** is an unsplicable platform foreground block which was added as part of Assassin's Creed 15th Anniversary Celebration on September 23, 2022.
##  Function
An Assassin's Creed: Renaissance Scaffolding behaves as a platform, thus a player can jump pass through it from underneath.
