The **Trade-Scan** is an unobtainable component which was added as part of Player Appreciation Week Day 3 on August 30, 2023.
##  Function
This item serves as an image placeholder for the trade-scan tab found when doing the command /tradescan or by wrenching oneself. A player may exchange a World Lock for five Trade-Scan Credit which allows the player to view the average price of five items.
##  Trivia
  * Trade-Scan uses the same sprite as the Trade-Scan Credit.
