This item does not have any recipe because it is no longer, or was never obtainable.
**Blank** is the item used by the game to identify the absence of tiles in a spot, existing in any place without a foreground or background tile on it.
##  Trivia
  * When the Awkward Friendly Unicorn was first released, there was a bug which caused **Blank** to be occasionally dropped when breaking an Awkward Friendly Unicorn. This bug was soon patched and all the **Blank** items in the game were removed.
