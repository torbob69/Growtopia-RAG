Zips around with a glorious glow! Note: Rides on this buddy bug should be free, so if he asks you to pay, it's probably a farefly!

This item can be transmuted.

Daily Challenge

Place in the top three of the **Mutant Kitchen!** Guild Daily Challenge, only if the player had contributed points to the challenge.
The **Riding Firefly** is an unsplicable feet item which was added as part of the Mutant Kitchen update.
##  Function
Look at the Glow... way you go Growtopians!

Back to Non-glowing human legs

When equipped, the **Riding Firefly** grants the _Speedy: Firefly_ mod, which allows the player to move faster on land and emit light in dark areas.
