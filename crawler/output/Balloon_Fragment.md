# Balloon Fragment

This is a broken piece of a war balloon. If you feed enough of these into a Balloon-O-Matic, you're bound to get something good...
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **4 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Balloon-O-Matic

**1** has a chance to be obtained from throwing a War Balloon at a player during Balloon/Brr-lloon Warz.
The **Balloon Fragment** is an unsplicable consumable which was added as part of Balloon Warz 2017.
##  Function     _Main article:Balloon-O-Matic Rewards_
Using Balloon Fragments on a Balloon-O-Matic will guarantee a single prize; attempting to drop more fragments at once will increase the chance of getting a better reward.
