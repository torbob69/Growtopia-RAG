# Catch-of-the-Day Bait

This is bait for fishing. Equip a fishing rod and then use this bait on water that you are standing next to in order to start fishing. This bait won't catch anything but the Catch of the Day, which changes each day. Fish have a chance to escape, though! Bonus: Fish caught this way can be larger than the normal maximum size!

This item never drops any seeds.

The **Catch-of-the-Day Bait** is an unsplicable consumable which was added as part of the Gone Crabby! update on March 3, 2016.
##  Function
Players can catch the Catch of the Day with this bait. The Catch of the Day changes everyday (random) and during some events they give specific event fish. The bait can catch fish over perfect size, giving it the _Massive_ status.
###  Catch-of-the-Day–Specific Fishes
A COTD fish may be caught during its respective event using a Catch-of-the-Day Bait. All fish caught using a Catch-of-the-Day Bait have a max perfect size of 150lb, but the bait's extra effect may allow the player to catch even bigger fish, causing them to be labeled "Massive". The maximum massive fish size is 186lb.

### Axolotl Scarf
An  Axolotl Scarf has an extremely small chance to be caught by using a Catch-of-the-Day Bait. The Axolotl Scarf is known to be the rarest item obtainable from fishing.
