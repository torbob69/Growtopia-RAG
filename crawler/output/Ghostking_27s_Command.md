# Ghostking's Command

A rod of command stripped from the forces of the Other Side! This spectral scepter won't necessarily make ghosts any happier to see you, but it WILL decrease the odds that a Spirit Storage Unit will detonate at lower, less-lucrative levels in worlds you own!
Properties
This item never drops any seeds.

Daily Challenge

Place in the top three of the **BOO Blast** Daily Challenge.
The **Ghostking's Command** is an unsplicable hand item which was added as part of the Challengers Approach! update.
##  Function
Command the spirits.

Run!!! Don't look back, just run.

When equipped, the **Ghostking's Command** grants the _Explosion Chance Reduction: Ghostking's Command_ mod, which allows the player to decrease the odds of Spirit Storage Units exploding in a world they own.
