# Untrade-a-Box

This amazing box can store all those pesky untradeable items! Only the World Lock owner can use it, and the World Lock can't be traded or destroyed while an Untrade-a-Box is in the world.
Untrade-a-Box (Rarity: 249)
Properties
This item has special properties you can adjust with the Wrench.
This item never drops any seeds.
This item can only be used in World-Locked worlds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item cannot be dropped or traded.
This item can be placed in two directions, depending on the direction you're facing.

The **Untrade-a-Box** is an unsplicable storage box block which was added as part of the Night Of The Chemicals update on March 2, 2017.
##  Function
When placed, the Untrade-a-Box can store up to 20 stacks of any untradeable item. An Untrade-a-Box can only be accessed by the owner of the world it is placed in.
##  Trivia
  * The Untrade-a-Box cannot be traded after it has been picked up.
