The **Castle Sewage Pipe** is a non-solid foreground block which was added as part of the Summer Clash 2018 on June 1, 2018.
##  Function
Being a type of vertical one side collision block, the Castle Sewage Pipe allows players to pass through the block downwards but blocks them from passing the block upwards.
