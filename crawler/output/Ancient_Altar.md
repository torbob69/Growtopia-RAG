# Ancient Altar

A celestial seat of crafting power - use this to make your artifacts even better. Who knew you could improve on perfection?
Properties
This item never drops any seeds.
This item can only be used in World-Locked worlds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item has special properties you can adjust with the Wrench.

Combination

In any Chemical Combiner, mix together...
Ghost-In-A-Jar **(×75)** ,
Silver Idol **(×50)** and
Ancestor Mooncake **(×1)**.
This recipe will yield **1** item.
The **Ancient Altar** is a non-solid foreground block which was added as part of the Ancestral Power update.
##  Function
When wrenched, an Ancient Altar allows the player to upgrade artifacts in return of certain items as communicated through a riddle. Upgrading artifacts will not destroy the altar.
For riddle answers, see this page.
##  Trivia
  * The Ancient Altar was originally not a permanent block. It was updated to be one during an unknown update.
