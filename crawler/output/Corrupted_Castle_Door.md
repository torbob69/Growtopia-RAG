# Corrupted Castle Door

Corrupted by the spells of an evil witch, the entrance to the castle is cracked with a purple glow of an unknown substance. Be cautious!
Properties
This item has special properties you can adjust with the Wrench.
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

The **Corrupted Castle Door** is an unsplicable door foreground block which was added as part of Halloween Week 2021 on October 21, 2021.
##  Function
As a door, the Corrupted Castle Door can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
