The **Stuffins' Support Package** is an unsplicable consumable which was added as part of Thanksgiving Week 2024 on November 21, 2024.
##  Function
When consumed, the player will randomly obtain one of the following items:
  * Groovy Van Block
  * Groovy Wallpaper
  * Organic Turkey Feather
  * Pvt. Stuffins' Pet
  * Riding Turkey
  * Stuffins' Helmet
  * Stuffins' Poster
  * Thanksgiving Frame (×5)
  * Turkey Feather
  * Vintage Jukebox (×3)
