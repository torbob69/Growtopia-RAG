# Weather Machine - Guild

Proud of your guild and its amazing mascot? Well, time to show it off in style! This machine will set your world of choice spinning with weather based on YOUR special mascot! Now that's guild power!

The **Weather Machine - Guild** is a weather machine that was released as part of Summer Season Events. It is given to the owner of a Guild that places 1st in any Grow Event.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on it will display your Guild Mascot falling similar to the Weather Machine - Stuff. When wrenched the Weather Machine - Guild has additional settings that can be adjusted. Please note: this item can only be placed in a Guild Locked world.
##  Trivia
  * Unlike the Weather Machine - Stuff you may not change the sprite displayed in the weather, it will only display your Guild's mascot.
  * The item sprite displayed in the Weather Machine - Guild can overlap blocks placed in the world.
