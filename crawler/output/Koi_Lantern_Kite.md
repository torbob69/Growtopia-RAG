# Koi Lantern Kite

Light the darkness with this friendly looking lantern.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hand – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Koi Fish Leash **(×1)** ,
Balance Mooncake Hat **(×1)** and
Sky Lantern **(×50)**.
This recipe will yield **1** item.
The **Koi Lantern Kite** is an unsplicable hand item which was added as part of Harvest Festival 2023 on September 21, 2023.
##  Function
Light the path to good fortune!

Stumbling in the darkness!

When equipped, the **Koi Lantern Kite** grants the _Lightsource: Koi Lantern Kite_ mod, which allows the player to emit light in dark areas.
