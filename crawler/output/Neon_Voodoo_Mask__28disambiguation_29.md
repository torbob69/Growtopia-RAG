# Neon Voodoo Mask (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
The **Neon Voodoo Mask** is an unsplicable face item that was added as part of the Halloween Week 2017 on October 30, 2017. There are 4 different color in Growtopia:
