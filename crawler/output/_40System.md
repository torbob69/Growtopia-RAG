# @System

This is an **NPC** , or a non-player character.
**@System** is a program written on Growtopia to help the developers tell about something that has happened in the System (i.e. sending messages, duct taping, banning, etc). One way to get a private message from **@System** is to use the command /renderworld. Once the world has been rendered, the player will receive a message from **@System** containing the World Render.
