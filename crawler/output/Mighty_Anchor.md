The **Mighty Anchor** is an unsplicable hand item which was added as July 2023's Item Of The Season on July 1, 2023.
##  Function

Get over it!

When equipped, the **Mighty Anchor** grants the _Punch Range: Mighty Anchor_ mod, which allows the player to punch one tile further. When pressed on a block, it will cling onto the block for a certain amount of time.
