The **Toasted Village Door** is a splicable non-solid door foreground block which was added as part of the Dragon Invasion update.
##  Function
As a door, the Toasted Village Door can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
