# Taco Door

A door made of tacos, cooked using an old family recipe. The secret ingredient is... well, that would be telling!
Properties
This item never drops any seeds.
This item has special properties you can adjust with the Wrench.

Pinata Bash

Participate in successfully smashing an  Ultra Pinata with a  Lucky Pinata Hat equipped during the **Pinata Bash!** event.
May give **1** item each time.
The **Taco Door** is an unsplicable non-solid door foreground block which was added as part of Cinco De Mayo Week 2021 on May 5, 2021.
##  Function
As a door, the Taco Door can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
