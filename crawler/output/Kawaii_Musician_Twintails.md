The **Kawaii Musician Twintails** is an unsplicable hair item which was added on June 6, 2024.
##  Function
When equipped, the Kawaii Musician Twintails serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Kawaii Musician set, which consists of the following items:

    * Kawaii Musician Twintails (Hair)

    * Kawaii Musician Shirt (Shirt)

    * Kawaii Musician Skirt (Pants)

    * Kawaii Musician Sleeves (Hand)
  * The Kawaii Musician set appears to be heavily based on Vocaloid character Hatsune Miku.
