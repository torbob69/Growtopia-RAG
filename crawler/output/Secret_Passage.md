The **Secret Passage** is a splicable entrance foreground block which has been added since Growtopia's launch.
##  Function
Being an entrance, a Secret Passage allows players with access to walk through it, or, when its property is changed, allowing any player to walk through it. When placed in a public area, it is impossible to be closed for anyone.
