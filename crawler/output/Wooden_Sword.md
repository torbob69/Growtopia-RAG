The **Wooden Sword** is a hand item which was added during the Systems Update. It is used to obtain Code Block: Kappa. The block can be obtained by breaking a jellyfish above the white door while facing leftward with this sword.
##  Function
When placed, the Wooden Sword serves a fully aesthetic purpose.
