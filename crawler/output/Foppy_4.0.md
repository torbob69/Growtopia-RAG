The **Foppy 4.0** is an unsplicable hat item which was added as March 2019's Monthly Subscriber's Item on March 1, 2019.
##  Function
When equipped, the Foppy 4.0 serves a purely cosmetic purpose.
##  Trivia
  * The Foppy 4.0 was the first Monthly Subscriber's Item released in Growtopia.
  * The Foppy 4.0 is the only Monthly Subscriber's Item that incorporates translucent pixels.
