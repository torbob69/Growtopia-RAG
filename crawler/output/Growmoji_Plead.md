# Growmoji Plead

Feeling like asking for something? Plead with this growmoji! Just consume to add it to your available growmojis!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Growtopia Store

Purchase the **Growmoji Mystery Box** for **15 ** in the Growtopia Store.
"Express yourself! This mysterious box contains one of six fun growmojis you can use to spice up your chat! Which will you get?"
Every purchase has a chance of giving **1** item.
The **Growmoji Plead** is an unsplicable growmoji consumable which was added as part of Player Appreciation Week 2022 Day 3 on August 17, 2022.
##  Function
When consumed, the player will be able to use the (plead) Growmoji.
