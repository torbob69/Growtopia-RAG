# Tangram Block

Draw black and white pictures with the wondrous power of the tangram!
Tangram Block A (Rarity: 15)
Properties
A tree of this type can bear surprising fruit!
Data: Paint PreviewType — Foreground Block – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single

Hardness: **7 Hits** **6 Hits** – Restores after **8s** of inactivity

**Tangram Block A** is a splicable solid foreground block which was added alongside St. Patrick's Week 2013 on March 13, 2013.
