The **Rickety Window** is an unsplicable background block which was added as part of Halloween Week 2016.
##  Function
When placed, the Rickety Window serves a purely aesthetic purpose.
This item, alongside several other Halloween Week blocks, are considered derivatives of the Haunted House block, which was added in 2013.
