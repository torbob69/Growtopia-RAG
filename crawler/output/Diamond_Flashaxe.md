The **Diamond Flashaxe** is an unsplicable hand item which was added as part of Harvest Festival 2014 on September 5, 2014.
##  Function
You can smash bricks more quickly.

Smash time is over.

When equipped, the **Diamond Flashaxe** grants the _Enhanced Digging_ mod, which allows the player to break blocks faster.
