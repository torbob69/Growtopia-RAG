# Extractium Ore

This mysterious element has strange properties which seem to make DNA extraction more successful!
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: No Collision
Hardness: **6 Hits** **5 Hits** – Restores after **5s** of inactivity
Gems Drop: **N/A**
**1h**
Consumption

Consume a(n)  Extractium Shard **(x10)**.
May yield **1** item each.

**Extractium Ore** is an item which was added during the Growassic Park update.
##  Function
It can be used in a DNA Extractor with another item to always get a DNA Strand.
