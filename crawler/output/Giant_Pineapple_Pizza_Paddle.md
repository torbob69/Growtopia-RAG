The **Giant Pineapple Pizza Paddle** is an unsplicable hand item which was added part of Super Pineapple Party Week 2021 on June 3, 2021.
##  Function
Make them know the joys of Pineapple on Pizza!

This concludes the argument!

When equipped, the **Giant Pineapple Pizza Paddle** grants the _Punch Damage: Giant Pineapple Pizza Paddle!_ mod, which allows the player to break blocks faster. It also replaces the player's punch animation with a slice of pizza being thrown; if it hits a block, a pizza splat particle will appear. Any other player nearby will show a /yes emote.
##  Trivia
  * The Giant Pineapple Pizza Paddle is based on the Hawaiian pizza, which traditionally uses pineapple chunks as its main topping. The paddle is based on a classic wooden peel, which has historically been used by cooks to retrieve pizza dough and place it in an oven.[[1]](https://growtopiawiki.com/w/Giant_Pineapple_Pizza_Paddle#cite_note-1)
  * The item's description, as well as its equip and unequip messages, reference a common humorous argument in which people debate on whether pineapple does belong as a pizza topping.[[2]](https://growtopiawiki.com/w/Giant_Pineapple_Pizza_Paddle#cite_note-2)
