# Spiezels' Galactic Scarf

A cosmic scarf that bleeds the energy of the galaxy itself! Sponsored by Spiezels for completing all epic quests!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Chest – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Special Event

Found in the _Hidden In Plain Sight!_ special event.
One has 90 seconds to locate a randomly spawned block and punch it for a prize.
##  Function
Behold!

Out of space!

When equipped, the **Spiezels' Galactic Scarf** grants the _Double Jump + Slow Fall: Spiezels' Galactic Scarf_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * This item is sponsored by Spiezels for completing all the Epic Quests.
  * This item was originally intended to feature RGB (Red, Green, Blue) color customization, similar to Rift Cape, but this feature was later discontinued during the final stages of development.
