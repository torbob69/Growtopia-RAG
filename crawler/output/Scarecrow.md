# Scarecrow

Notice how there are NO crows around? This thing is working!
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.
Data: Paint PreviewType — Foreground Block – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single
Collision Type: No Collision
Hardness: **4 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Combination

In any Chemical Combiner, mix together...
Harmony Mooncake **(×5)** ,
Longevity Mooncake **(×5)** and
Peace Mooncake **(×5)**.
This recipe will yield **1** item.
Mooncake Offering

1 may be received as a common reward from offering mooncakes using an Offering Table.
The **Scarecrow** is an unsplicable non-solid foreground block which was added on Harvest Festival 2013 on September 18, 2013.
##  Function
When placed, the Scarecrow serves a fully aesthetic purpose.
