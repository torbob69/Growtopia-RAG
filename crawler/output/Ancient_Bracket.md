# Ancient Bracket

Superb craftmanship has kept this pristine across the ages. Once part of some grand design, it can be again... if you can figure out what it will make!
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: Full Collision
Hardness: **9 Hits** **7 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Earth Asteroid **(×2)** ,
Water Asteroid **(×2)** and
Earth Essence **(×5)**.
This recipe will yield **1** item.
The **Ancient Bracket** is an unsplicable component which was added as part of the Hidden Riches update on September 1, 2017.
