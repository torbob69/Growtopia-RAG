The **Ezio's Boots** is an unsplicable feet item which was added as part of Ezio update on October 14, 2018.
##  Function
When equipped, the **Ezio's Boots** grants the _Wall Climbing_ mod, which allows the player to cling onto Climbing Walls by pressing the jump button.
##  Trivia
  * This item is considered a part of the Ezio set, which consists of the following items:

    * Ezio's Hood (hat)

    * Ezio's Hair (hair)

    * Ezio's Beard (face)

    * Ezio's Vest (shirt)
