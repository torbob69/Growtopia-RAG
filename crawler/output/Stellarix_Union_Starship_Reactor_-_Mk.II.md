The **Stellarix Union Starship Reactor - Mk.II** is an unsplicable non-solid foreground block which was added as part of the Startopia update on July 1, 2018.
##  Function
When placed in a Starship Blast, the Stellarix Union Starship Reactor - Mk.II can be used to fuel the ship with Star Fuel. Additionally, it increases the ships rating by 900.
