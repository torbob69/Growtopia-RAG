##  Function
Quick! Run to the fridge for more dip!

All outta dip!

When equipped, the **Chip-and-Dip** grants the _Speedy: Chip and Dip_ mod, which allows the player to move faster on land. Additionally, this item can stack with up to two other Speedy clothing items.
