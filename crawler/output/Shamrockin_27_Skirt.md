# Shamrockin' Skirt

A skirt perfect for visiting new lands!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Pants – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Aqua.
Sew a  Silk Bolt - Green to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **Shamrockin' Skirt** is an unsplicable pants item which was added as part of St. Patrick's Week 2025 on March 14, 2025.
##  Function
When equipped, the Shamrockin' Skirt serves a purely aesthetic purpose.
