The **Table Lamp** is a splicable non-solid toggleable animated foreground block which has been added since Growtopia's launch.
##  Function
Being a toggleable animated foreground block, a Table Lamp can be toggled on or off via punching. When toggled on, a Table Lamp will change its appearance, showing a 2-framed animation of itself providing light to its surrounding. As a light source, a Table Lamp emits light in dark areas.
