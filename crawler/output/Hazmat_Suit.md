The **Hazmat Suit** is an unsplicable shirt item which was added as part of the Geiger Day update on May 5, 2017, the same day Cinco De Mayo Week 2017 was released.
##  Function
Equipping the Hazmat Helmet, Hazmat Suit, Hazmat Pants, and Hazmat Boots allows the player to create Uranium Glowing Lures from Radioactive Bits.
##  Trivia
  * This item is considered a part of the hazmat set, which consists of the following items:

    * Hazmat Helmet (hair)

    * Hazmat Suit (shirt)

    * Hazmat Pants (pants)

    * Hazmat Boots (feet)
