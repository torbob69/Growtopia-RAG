# Turkey Feather

A Turkey Feather, thats about it really. Not really too useful on it's own.
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: No Collision
Hardness: **10 Hits** **8 Hits** – Restores after **15s** of inactivity
Gems Drop: **N/A**
**1h**
Turkey Sucker

| A Turkey Sucker has a 10% chance to explode after capturing a Thanksgiving Turkey, which will give:
•  Organic Turkey ×1 (slightly rare)
•  Roasted Turkey ×6–11 (common)   |
There is also a small chance that a  Turkey Feather will be left behind when a Turkey is caught, regardless if the sucker explodes or not.
Consumption

Consume a(n)  Stuffins' Support Package **(x1)**.
May yield **1** item each.

The **Turkey Feather** is an unsplicable component that was added as part of Thanksgiving Week 2020.
##  Function
This item serves no purpose by itself.
