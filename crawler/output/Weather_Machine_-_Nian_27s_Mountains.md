The **Weather Machine - Nian's Mountains** is an unsplicable non-solid weather machine foreground block which was added as part of Lunar New Year 2023 on January 21, 2023.
##  Function
As a weather machine, the Weather Machine - Nian's Mountains can be toggled on or off via punching. When toggled on, it will change its appearance, transforming the world's background weather into a scenery of a floating mountain with animated clouds.
