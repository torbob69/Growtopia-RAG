The **Weather Machine - Sunny** is an unsplicable non-solid weather machine foreground block which was added as part of the Rise of the Desert Dragons update on August 3, 2013.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into the default mountainous day scenery.
##  Trivia
  * Two other weather machines, Weather Machine - Night and Weather Machine - Arid, were released on the same day as Weather Machine - Sunny.
  * Unlike other weather machines, this weather machine can't be turned into Weather Machine - Spooky when sacrificed to the Growganoth.
