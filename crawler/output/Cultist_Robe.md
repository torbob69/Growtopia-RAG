The **Cultist Robe** is an unsplicable shirt item which was added as part of Halloween Week 2013 on October 28, 2013.
##  Function
When equipped, the Cultist Robe serves a fully cosmetic purpose.

##  Trivia
  * While equipping a Cultist Robe, the player's arms cannot be seen while doing various actions except punching which requires hand movement, such as the commands /fp, /idk, /yes, /no, etc.
  * The Cultist Robe also removes the player's arms while infected.
  * Wearing a Cultist Robe will render the player's hand items invisible.
  * This item is considered a part of the cultist set, which consists of the following items:

    * Cultist Hood (hair)

    * Cultist Robe (shirt)
