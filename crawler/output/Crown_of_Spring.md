# Crown of Spring

This wonderful crown will turn you into Spring Royalty!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Consumption

Consume a(n)  Equinox Box **(x1)**.
May yield **1** item each.

The **Crown of Spring** is an unsplicable hat item which was added as a part of the Equinox Weekend update on March 25, 2022.
##  Function
Blooming!

Whithered!

When equipped, the **Crown of Spring** grants the _Build Range : Crown of Spring_ mod, which allows the player to build one tile further.
##  Trivia
  * This item is considered a part of the Equinox Spring set, which consists of the following items:

    * Crown of Spring (hat)

    * Shirt of Spring (shirt)

    * Pants of Spring (pants)

    * Boots of Spring (shoes)
