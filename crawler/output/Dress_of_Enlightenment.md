# Dress of Enlightenment

A copper dress turned green with time! Symbolizes liberty and enlightenment... doesn't look like it would be too easy to move about in! Feels like it's part of a set somehow?
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Wool Bolt.
Sew a  Silk Bolt - Grey to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Silk Bolt - Green to the previous bolt using a(n) **Saddle Stitch**.
Each recipe gives **1** item.
The **Dress of Enlightenment** is an unsplicable shirt item that was added as part of Thanksgiving Week 2020.
##  Function
When equipped, the Dress of Enlightenment serves a fully cosmetic purpose.
##  Trivia
  * This item is considered a part of the Enlightenment set, which consists of the following items:

    * Crown of Enlightenment (hat)

    * Dress of Enlightenment (shirt)

    * Torch of Enlightenment (hand)
  * When the full set is worn, the player will leave behind trails of blue, white, and red stars when walking.
  * The full Enlightenment set is based on the Statue of Liberty, which is considered as a symbol of freedom of the United States.
