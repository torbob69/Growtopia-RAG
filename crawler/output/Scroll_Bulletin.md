The **Scroll Bulletin** is a non-solid bulletin board foreground block.
##  Function
This item acts like a Bulletin Board. When placed in a world, players are able to leave a message on the board that can be read by any player. Players with access to the board can edit the settings such as changing the option for the public to add messages (players without access), hide names, clear the board or manually remove individual messages. A bulletin board may contain up to 20 messages before the older messages start to get replaced.
