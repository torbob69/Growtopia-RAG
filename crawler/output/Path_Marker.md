# Path Marker

Use these sort of like Doors - They have IDs, so Doors can lead to them, though you can't travel from them. Use your wrench to set their ID.

The **Path Marker** is a splicable non-solid foreground block which was added alongside the Adventure Pack on June 14, 2014. It acts like a door with no destination.
##  Function
Players can set an ID, and have doors lead to them, however they cannot be entered into.
