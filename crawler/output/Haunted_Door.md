The **Haunted Door** is an unsplicable non-solid door foreground block which was added as part of Halloween Week 2016 on October 27, 2016.
##  Function
As a door, the Haunted Door can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
Similarly to the Password Door, a Haunted Door is different from normal doors in the sense that it requires a password which can be set by any player with access to the block. If any player inserts the correct password, they will be redirected to the set location. If an incorrect password is entered, though, the player will not pass through.
This item, alongside several other Halloween Week blocks, are considered derivatives of the Haunted House block, which was added in 2013.
