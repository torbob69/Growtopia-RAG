**Buddy's Block Head** is a hair item which was added as part of the Block Party 2 update.
##  Function
Buddy's Effortless Blocks...

Aw, no more bonus blocks from Buddy.

When equipped, the **Buddy's Block Head** grants the _Buddy's Extra Blocks..._ mod, which allows the player to get a 2% chance for a block to drop an extra of itself when broken.
