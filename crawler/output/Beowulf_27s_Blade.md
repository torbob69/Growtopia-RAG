**Beowulf's Blade** is an unsplicable hand item which was added as part of the All Howl's Eve monthly event update on July 19, 2021. The item was formally introduced on July 21, 2021, the date All Howl's Eve arrived.
##  Function
Dragon Flame!!

Drag-gone!

When equipped, the **Beowulf's Blade** grants the _Punch Damage : Beowulf's Blade_ mod, which allows the player to break blocks faster.
##  Trivia
  * This item is considered a part of the Beowulf set, which consists of the following items:

    * Beowulf's Helm (Hat)

    * Beowulf's Beard (Face)

    * Beowulf's Shirt (Shirt)

    * Beowulf's Pants (Pants)

    * Beowulf's Blade (Hand)
  * The Beowulf set is based on a legendary heroic figure of the same name.
  * Unlike all the other items in the set, Beowulf's Blade cannot be obtained from WOLFWORLD.
