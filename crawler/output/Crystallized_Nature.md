# Crystallized Nature

A fragment of Gaia's beating heart! The unstoppable life force surrounding it could certainly be used for something spectacular... or set on a shelf to look pretty!
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

Combination

In any Chemical Combiner, mix together...
Crystal Tree **(×30)** ,
Tidal Gate **(×4)** and
Water Essence **(×5)**.
This recipe will yield **1** item.
The **Crystallized Nature** is an unsplicable solid foreground block which was added as part of the Hidden Riches update.
##  Function
When placed, the Crystallized Nature serves a fully aesthetic purpose.

##  Trivia
  * There are currently five blocks in the crystallized series, all of which are primarily used to create and upgrade ancestral artifacts.
    * Crystallized Brilliance →  Ancestral Totem of Wisdom
    * Crystallized Nature →  Ancestral Seed of Life
    * Crystallized Reality →  Ancestral Tesseract of Dimensions
    * Crystallized Time →  Ancestral Orb of Time
    * Crystallized Wealth →  Ancestral Lens of Riches
  * The  Crystallized Nature's sprite features an  Ice Cube with the tree found in _Growtopia_ 's logo embedded inside.
