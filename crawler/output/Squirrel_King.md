The **Squirrel King** is an unsplicable back item which was added as part of Summer Clash 2018 on June 1, 2018.
##  Function
Nuts overload!

These acorns taste too good to throw away!

When equipped, the **Squirrel King** grants the _Acorns!_ mod, which allows the player to punch one tile further. It also changes the player's punching animation into acorns.
