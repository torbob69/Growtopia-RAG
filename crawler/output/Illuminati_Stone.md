**Illuminati Stone** is an unsplicable block which was added in the Systems Update. It is earned from solving the Discover The Truth ARG/Riddle.
It can be created by placing a Crystal Gate in a world that begins with letter Y, set the destination to **KILIMA:OKAVANGO** , enter it, the door will blow up and an Illuminati Stone will be added to the player's inventory.
##  Trivia
  * The Illuminati stone has no particular use except for decoration.
  * The item was created as a joke about the fact of the Illuminati running everything, and does not mean that Growtopia is part of the Illuminati.
  * Obtaining this block will complete an epic quest.
