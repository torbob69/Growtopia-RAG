The **Diamond Sparkling Sneakers** is an unsplicable feet item which was added as part of Pre-WinterFest 2024 on December 1, 2024.
##  Function
Light it up!

Lights out!

When equipped, the **Diamond Sparkling Sneakers** grants the _Speedy + Light Source: Diamond Sparkling Sneakers_ mod, which allows the player to move faster on land and emit light in dark areas.
##  Trivia
  * Diamond Sparkling Sneakers' glowing effect is a recolored version of  Superstar Sneakers' glowing effect.
