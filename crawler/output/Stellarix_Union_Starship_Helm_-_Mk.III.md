# Stellarix Union Starship Helm - Mk.III

Set course for knowledge and understanding of the cosmos with the Stellarix Union helm! Provides a Ship Rating of 1080. One of three components - Helm, Viewscreen, and Reactor - needed to fly a starship. Wrench this to start a Star Mission (but make sure you have enough Star Tools)!

The **Stellarix Union Starship Helm - Mk.III** is an unsplicable non-solid foreground block which was added as part of the Startopia update on July 1, 2018.
##  Function
When placed in a Starship Blast, the Stellarix Union Starship Helm - Mk.III acts as a console to start Startopia missions. Additionally, it increases the ships rating by 1080.
