# Lace A-Line Dress

Absolutely stunning! Oh, and MUCH nicer than those B- and C-Line dresses! Don't even get me started on the D-Lines... sheesh!
Properties
This item never drops any seeds.
This item can be transmuted.

Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - White.
Sew a  Silk Bolt - Black to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Wool Bolt to the previous bolt using a(n) **Locking Stitch**.
Each recipe gives **1** item.
The **Lace A-Line Dress** is an unsplicable shirt item which was added as part of Player Appreciation Week 2019 on August 21, 2019.
##  Function
When equipped, the Lace-A-Line Dress serves a purely cosmetic purpose.
