The **Weather Machine - Howling Sky** is a weather machine which was added as part of the Artsy April update on April 2, 2016.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into a mountainous nighttime scenery with howling wolves fading in and out on the background.
##  Trivia
  * This item's description refers to the Bark at the Moon song by Ozzy Osbourne.
