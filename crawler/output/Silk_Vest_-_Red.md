# Silk Vest - Red

A snappy vest suitable for any occasion.
Properties
This item never drops any seeds.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Red.
Sew a  Silk Bolt - White to the previous bolt using a(n) **Straight Stitch**.
Lastly, sew a  Silk Bolt - Red to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **Silk Vest - Red** is an unsplicable shirt item which was added as part of the Silkworm update on February 1, 2016.
##  Function
When equipped, the Silk Vest - Red serves as a purely cosmetic purpose.
##  Trivia
  * This is one of the six Silk Vest color variations available in the game, others include Silk Vest - Black, Silk Vest - Grey, Silk Vest - Blue, Silk Vest - Green, and Silk Vest - Purple.
