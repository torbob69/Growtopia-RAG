# Big Bunny Feet

A pair of big bunny feet perfect for the wilderness!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Feet – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Wool Bolt.
Sew a  Wool Bolt to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Wool Bolt to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **Big Bunny Feet** is an unsplicable feet item which was added as part of Easter Week 2025 on April 17, 2025.
##  Function
When equipped, the Big Bunny Feet serves a purely cosmetic purpose.
