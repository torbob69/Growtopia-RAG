The **Adobe Block** is an unsplicable solid foreground block which was added as part of Cinco De Mayo Week 2013 on May 3, 2013.
##  Function
When placed, the Adobe Block serves a purely aesthetic purpose.
##  Trivia
  * Adobe Block's in-game description is a reference to adobe, a building material and the multimedia software platform Adobe Flash.
