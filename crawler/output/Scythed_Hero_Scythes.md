The **Scythed Hero Scythes** is an unsplicable hand item which was added as part of the Garuda's Glory update on August 7, 2025.
##  Function
Scythes out!

Scythes down...

When equipped, the **Scythed Hero Scythes** grants the _Punch Range + Punch Damage: Scythed Hero Scythes_ mod, which allows the player to punch one tile further and break blocks faster.
##  Trivia
  * This item is considered a part of the Scythed Hero set, which consists of the following items:

    * Scythed Hero Hair (Hair)

    * Scythed Hero Scythes (Hands)

    * Scythed Hero Shirt (Shirt)

    * Scythed Hero Pants (Pants)

    * Scythed Hero Boots (Feet)
