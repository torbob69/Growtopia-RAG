The **Space Command Seat** is a splicable non-solid seat foreground block which was added as part of the original Night Of The Comet update on November 27, 2014.
##  Function
When a player stands in front of a seat such as the Space Command Seat for a few seconds, the player will automatically be seen "sitting" on it.
