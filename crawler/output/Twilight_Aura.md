# Twilight Aura

It's almost twilight, time for breaking dawn!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Back – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Brim **(×10)** ,
Courage Mooncake **(×30)** and
Unity Mooncake **(×20)**.
This recipe will yield **1** item.
The **Twilight Aura** is an unsplicable back item which was added as part of Harvest Festival 2024 on September 12, 2024.
##  Function
A new moon!

It's an eclipse!

When equipped, the **Twilight Aura** grants the _Double Jump : Twilight Aura!_ mod, which allows the player to jump a second time in mid-air.
