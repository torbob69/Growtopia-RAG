# Riding Fiesta Axolotl

What's this now? The cute little Mexican critter is wearing a sombrero? Well, things just got a whole lot more adorable, didn't they?
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Feet – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Fiesta Sombrero **(×1)** ,
Riding Axolotl **(×1)** and
Party Cactus **(×200)**.
This recipe will yield **1** item.
The **Riding Fiesta Axolotl** is an unsplicable feet item which was added as part of Cinco De Mayo Week 2018 on May 4, 2018.
##  Function
You can move faster!

You are slow again.

When equipped, this item grants the _Speedy_ mod which allows the player to move faster on land.
