# Balloon Launcher

With this launcher you can throw balloons farther. Not much good for anything else, though.
Properties

This item can be transmuted.

Use or blow up a  Balloon-O-Matic.
The **Balloon Launcher** is an unsplicable hand item which was added as part of Balloon Warz 2017 on August 2, 2017.
##  Function
Fling those balloons extra far!

Now you have to throw with your puny arms!

When equipped, the Balloon Launcher allows the player to throw War Balloons two tiles further.
