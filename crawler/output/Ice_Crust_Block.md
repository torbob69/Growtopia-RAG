The **Ice Crust Block** is a block which was added alongside the Gone Fishin'! update.
##  Function
If the block is drilled using a Hand Drill and there is a Water Bucket on top, players will be able to go ice fishing. In addition, being a slippery block, walking on an Ice Crust Block causes the player to slide.
