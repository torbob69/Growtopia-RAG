# Ancient Pin

Eons have not dulled the point of this pointy treasure. Careful! It's supernaturally pokey!
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: Full Collision
Hardness: **9 Hits** **7 Hits** – Restores after **4s** of inactivity

Combination

In any Chemical Combiner, mix together...
Water Asteroid **(×2)** ,
Fire Asteroid **(×2)** and
Water Essence **(×5)**.
This recipe will yield **1** item.
The **Ancient Pin** is an unsplicable component which was added as part of the Hidden Riches update on September 1, 2017.
