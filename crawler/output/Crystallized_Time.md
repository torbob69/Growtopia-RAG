# Crystallized Time

A raw chunk of frozen eternity, preserved forever! The glitched-out time eddies surrounding it could certainly be used for something spectacular... or set on a shelf to look pretty!
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

Combination

In any Chemical Combiner, mix together...
Atomic Gate **(×4)** ,
Earth Essence **(×5)** and
Hour Glass **(×200)**.
This recipe will yield **1** item.
The **Crystallized Time** is an unsplicable solid foreground block which was added as part of the Stuff! update on October 1, 2018.
##  Function
When placed, the Crystallized Time serves a fully aesthetic purpose.

##  Trivia
  * The Crystallized Time is currently the crystallized block which didn't make its debut in the Hidden Riches update.
  * There are currently five blocks in the crystallized series, all of which are primarily used to create and upgrade ancestral artifacts.
    * Crystallized Brilliance →  Ancestral Totem of Wisdom
    * Crystallized Nature →  Ancestral Seed of Life
    * Crystallized Reality →  Ancestral Tesseract of Dimensions
    * Crystallized Time →  Ancestral Orb of Time
    * Crystallized Wealth →  Ancestral Lens of Riches
  * The  Crystallized Time's sprite features an  Ice Cube with an  Hour Glass inside.
