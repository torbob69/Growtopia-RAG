# Neutron Focus Core

Insert this into your Neutron Pack to give it a little extra oomph. Will deal double damage for a short time before burning out, so use it wisely!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **2 Hits** **2 Hits** – Restores after **2s** of inactivity
Gems Drop: **N/A**
**1h**
Breaking

| May drop in sets of **2** from breaking:
•  Ghost Hunter's Crate  |
The **Neutron Focus Core** is an unsplicable consumable which was added as part of the B.O.O. Update on May 1, 2018.
##  Function
Power OVERWHELMING!

Now you are a wimp again.

When consumed, this item grants the player the _Ghost Double Damage_ mod, which allows the player to deal double damage towards Boss Ghosts.
