# Door (block category)

A **door** is a type of non-solid foreground block which can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.

##  Trivia
  * Entering a door with the world SYSTEM, HAMUMU, SETH, SATAN, HEROMAN, THEGODS, RTSOFT, GODS or GOD, MIKEHOMMEL, ADMIN, MODERATOR, or SKIDS selected as the target will make the door say: "_The door cannot open to such an awesome place!_ "
  * When a door's target is set to EXIT, players who enter the door will be sent to the world selection menu, similarly to how the Main Door works.
  * When players try to enter a door while they are cursed in HELL, it says: "_The door laughs at you._ "
  * When players try to edit a door while duct taped, it says: "_You can't do that while muted."_
  * Pressing the "_OK_ " button after editing a broken door will result in the message: "_I was looking at a door but now it's gone. Magic is real!_ "
  * Players are unable to place a door if the player's way to the tile intended for placement is blocked by something, or is located in a locked area.
  * Using a very short Door ID will display the warning: "_That Door ID is so easy to guess. People can use a Door ID to warp directly into this point from another world!_ "
