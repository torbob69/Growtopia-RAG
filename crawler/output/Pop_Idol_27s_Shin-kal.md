The **Pop Idol's Shin-kal** is an unsplicable hand item which was added as part of Wonder Week 2025 - Day 2 on October 7, 2025.
##  Function
Knives out!

Fit check for my napalm era!

When equipped, the **Pop Idol's Shin-kal** grants the _Punch Range + Punch Damage: Pop Idol's Shin-kal_ mod, which allows the player to punch one tile further and break blocks faster.
##  Trivia
  * The Pop Idol's set is based on the fictional character Zoey from K-Pop Demon Hunters.
  * This item is considered a part of the Pop Idol's set, which consists of the following items:

    * Pop Idol's Crop Top (Shirt)

    * Pop Idol's Pants (Pants)

    * Pop Idol's Shin-kal (Hand)
