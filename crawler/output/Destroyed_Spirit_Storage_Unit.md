The **Destroyed Spirit Storage Unit** is an unsplicable non-solid foreground block which was added as part of the Battlers Of the Otherworldly update on July 15, 2016.
##  Function
After the Spirit Storage Unit explodes, the Destroyed Spirit Storage Unit serves a purely aesthetic purpose.
##  Trivia
  * The Destroyed Spirit Storage Unit was able to be obtained by using a Flashback Flan on the item itself, but this has since been changed.
