**Armored WinterBot - Mail** is an unsplicable shirt item which was added as part of WinterFest 2019.
##  Function
When equipped, the **Armored WinterBot - Mail** serves a purely cosmetic purpose. However, equipping the entire Armored WinterBot set will transform the player into the Armored WinterBot.
##  Trivia
  * This item is considered a part of the Armored WinterBot set, which consists of the following items:

    * Armored WinterBot - Back (back)

    * Armored WinterBot - Mail (shirt)

    * Armored WinterBot - Greaves (pants)

    * Armored WinterBot - Feet (feet)

    * Armored WinterBot - Fists (hand)
