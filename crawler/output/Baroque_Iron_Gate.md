The **Baroque Iron Gate** is an unsplicable entrance foreground block which was added as part of Spring Clash 2019.
##  Function
Being an entrance, a Baroque Iron Gate allows players with access to walk through it, or, when its property is changed, allowing any player to walk through it. When placed in a public area, it is impossible to be closed for anyone.
##  Trivia
  * The description of this item contains a reference to the well-known phrase, "if it ain't broke, don't fix it,"[[1]](https://growtopiawiki.com/w/Baroque_Iron_Gate#cite_note-1) but with the word "broke" substituted by the word "baroque," which is pronounced rather identically.
