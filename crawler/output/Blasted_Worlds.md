# Blasted Worlds

**Blasts** are consumables used to create a certain kind of a new world. When using a blast, type in the name of the new world (that world mustn't be used before), and you will warp straight away to that world (it is recommended that you should place a lock immediately when you get there)
##  Blasts available anytime
  * Bountiful Blast
  * Cave Blast
  * Desert Blast
  * Greezak Starship Blast
  * HyperTech Starship Blast
  * Imperial Starship Blast
  * Jungle Blast
  * Mars Blast
  * Stellarix Starship Blast
  * SurgWorld Blast
  * Thermonuclear Blast
  * Treasure Blast
  * Undersea Blast

##  Blasts available during certain Events
Item: EventBeach Blast: SummerFest
Harvest Moon Blast: Harvest Festival
Monochrome Blast: Black Friday
