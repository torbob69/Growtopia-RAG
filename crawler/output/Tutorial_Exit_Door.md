The **Tutorial Exit Door** is an unobtainable and unsplicable non-solid foreground block which was added as part of the Growtopia's Tutorial update on August 16, 2018.
##  Function
The Tutorial Exit Door can be seen in the world TUTORIAL. As a door, the Tutorial Exit Door can be entered (via punching) by a player. Unlike the other door, it will take the player to the menu.
