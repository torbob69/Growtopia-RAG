# Growmoji Shamrock

Want to add some shamrock shenanigans in your chat? Just consume this to add it to your available growmojis!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Breaking

| May drop in sets of **1** from breaking:
•  Growmoji Chest  |
**Growmoji Shamrock** is an unsplicable growmoji consumable which was added alongside the first Spring Clash update on March 1, 2019.
##  Function
Upon consuming, the player will now be able to use the (shamrock) growmoji.
##  Trivia
  * As of Player Appreciation Week Day 6 on August 28, 2021, all growmoji consumables which were included as part of the Monthly Bundle IAPs now have a chance to be dropped from breaking a Growmoji Chest, which is purchasable from Locke for 150 World Locks.
