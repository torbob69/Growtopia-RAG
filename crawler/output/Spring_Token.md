The **Spring Token** is an unobtainable component that was added as part of Spring Clash 2019.
##  Function
The Spring Token item was added as a placeholder for Spring Clash's main currency, which can be obtained by reaching milestone points during a Grow Event while a Spring Clash is still ongoing. They can be used to purchase items on the Spring Clash Rewards Store.
This item cannot be obtained in the player's inventory by regular means, as collected Spring Tokens are stored in a separate entry in the player data.
