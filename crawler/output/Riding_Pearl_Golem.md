The **Riding Pearl Golem** is an unsplicable chest item which was added as part of Beach Party 2026 on August 20, 2026.
##  Function
Pearl wave attack!

Ridin' solo!

When equipped, the **Riding Pearl Golem** grants the _Punch Range + Punch Damage: Riding Pearl Golem_ mod, which allows the player to punch one tile further and break blocks faster.
