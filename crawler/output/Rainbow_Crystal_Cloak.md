# Rainbow Crystal Cloak

Rainbow cloth studded with shimmering crystals! The multicolored majesty of this cloak will carry you aloft, where all can gaze upon your prismatic wonder!

This item never drops any seeds.

Daily Challenge

Place in the top three of the **Crystal Crusher** Guild Daily Challenge, only if the player had contributed points to the challenge.
The **Rainbow Crystal Cloak** is an unsplicable back item which was added as part of the Challengers Approach! update.
##  Function
You're somewhere over the rainbow.

I guess dreams only come true for others, not you.

When equipped, the **Rainbow Crystal Cloak** grants the _Double Jump - Rainbow Crystal Cloak_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * This item's equip message is a reference to Hawaian singer Israel Kamakawiwo'ole's song Somewhere Over the Rainbow.
