The **Pocong Mask** is an unsplicable hair item which was added as part of the Garuda's Glory update on August 26, 2022.
##  Function
When equipped, the Pocong Mask serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Pocong set, which consists of the following items:

    * Pocong Mask (Hair)

    * Pocong Clothes (Shirt)
  * The Pocong set is a reference to a Javanese ghost of the same name that is said to be the soul of a dead person trapped in their shroud.
