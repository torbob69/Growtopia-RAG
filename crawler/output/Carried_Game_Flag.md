The **Carried Game Flag** is an unsplicable non-solid foreground block which was added alongside the Game Pack on July 25, 2014.
##  Function
It is seen during a game when the player has collected a flag and is holding it in their hand. If a player kills them while they are holding it, it will drop onto the ground for another player to collect, or for the player to return it back to their team.
##  Trivia
  * The Carried Game Flag can only be obtained in the backpack when players use an Extract-O-Snap on a dropped Carried Game Flag. Obtained Carried Game Flags can be placed in the world, but they cannot be traded.
  * The Carried Game Flag is possibly the only item in the game that cannot be painted in a Painting Easel.
  * Carried Game Flag uses the same sprite as the Game Flag.
