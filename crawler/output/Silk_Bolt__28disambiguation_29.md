# Silk Bolt (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.

Obtainable by using 100 Silk Threads on yourself. Can be used to sew in the Sewing Machine.
The silk bolts are:
  * Silk Bolt - Red
  * Silk Bolt - Green
  * Silk Bolt - Blue
  * Silk Bolt - Black
  * Silk Bolt - White
  * Silk Bolt - Grey
  * Silk Bolt - Yellow
  * Silk Bolt - Purple
  * Silk Bolt - Aqua
  * Silk Bolt - Floral
