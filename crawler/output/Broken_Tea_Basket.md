# Broken Tea Basket

Looks like this tea basket took on too many trees! Don't fret, though - maybe with a little work (and some more raw materials), you can fix it up!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **4 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
The Broken Tea Basket is an unsplicable consumable introduced during Harvest Festival 2019. It can be obtained after using the Tea Basket too much.
