# Summer Clash/2019/Rewards Store/2019

< Summer Clash | 2019
The **Summer Clash Rewards Store** is a store that can be accessed through the Dumb Leader. Players are able to purchase limited Summer Clash items for Summer Tokens that they earn by contributing towards Grow Events.
Items: RecipeLegendary Clash Key & Finale Ticket: Received after completing a branch for the first time.
Summer Clash Finale Ticket: Comes with the Legendary Clash Key & Finale Ticket.
Legendary Clash Key - Series 2: Comes with the Legendary Clash Key & Finale Ticket.
