# Dragon Block

This dragon is impossibly mighty! Easily the strongest, most deadly creature we've ever seen in all of Growtopia! It also happens to be very, VERY lazy, however, so it never moves or does anything... but trust us - it's an unstoppable terror when it wants to be!
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

##  Function
When placed, the Dragon Block serves a purely aesthetic purpose.
