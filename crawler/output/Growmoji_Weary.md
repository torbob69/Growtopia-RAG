# Growmoji Weary

Add some weary vibes to your chat! Just consume this to add it to your available growmojis!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Breaking

| May drop in sets of **1** from breaking:
•  Locke's Mystery Box  |
The **Growmoji Weary** is a consumable which was added on Day 7 of the Player Appreciation Week in 2020.
##  Function
When consumed, the player will be able to use the (weary) growmoji.
