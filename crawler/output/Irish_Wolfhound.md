The **Irish Wolfhound** is an unsplicable hand item which was added as part of St. Patrick's Week 2022 on March 11, 2022.
##  Function
When equipped, the player summons an Irish Wolfhound which follows the player around. The Irish Wolfhound serves a purely cosmetic purpose.
##  Trivia
  * The Irish Wolfhound is based on a real-life dog breed with the same name.
  * Cliff, as mentioned in the description of the item, is a reference to the children's book series _Clifford the Big Red Dog_ by Norman Bridwell.
