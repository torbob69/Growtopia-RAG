# Fluff

Lovely hat fluff! For making a special hat.
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: No Collision
Hardness: **10 Hits** **8 Hits** – Restores after **15s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Ancestor Mooncake Hat **(×1)** ,
Longevity Mooncake Hat **(×1)** and
Prosperity Mooncake Hat **(×1)**.
This recipe will yield **1** item.
The **Fluff** is an unsplicable component that was added as part of Harvest Festival 2020.
##  Function
This item serves no purpose by itself.
