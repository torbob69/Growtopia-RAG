The **Tars Lamora Miner Helmet** is an unsplicable hat item which was added as part of Star Trek Prodigy on June 27, 2022.
##  Function
When equipped, the Tars Lamora Miner Helmet serves a fully cosmetic purpose.
##  Trivia
  * This item is considered a part of the Tars Lamora Miner set, which consists of the following items:

    * Tars Lamora Miner Helmet (Hat)

    * Tars Lamora Miner Shirt (Shirt)

    * Tars Lamora Miner Pants (Pants)

    * Tars Lamora Miner Shoes (Feet)
