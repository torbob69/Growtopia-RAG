# Silk Bolt - White

Sew silk items by using this in a sewing machine. It takes 3 bolts of silk to craft an item.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **4 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Consumption

Consume a(n)  Silk Thread - White **(x100)**.
May yield **1** item each.

The **Silk Bolt - White** is an unsplicable consumable which was added as part of the Silkworm update on February 1, 2016.
