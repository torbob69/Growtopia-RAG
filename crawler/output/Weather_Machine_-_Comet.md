**Weather Machine - Comet** is a splicable non-solid weather machine foreground block which was added as part of the original Night Of The Comet update on November 27, 2014.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into the usual Night Of The Comet background, except with the green comet replaced with a blue one and positioned differently.
Geiger Counters also keep producing green signals everywhere when this weather machine is activated.
The comet in the background performs a cycle across the player's screen every 2 minutes.
##  Trivia
  * Splicing a Weather Machine - Comet for the first time will complete an Epic Quest.
  * Finding a radioactive item with a Geiger Counter with the Weather Machine - Comet enabled will unlock the _Atomic Luck_ Achievement.
