The **Lightning Lord's Boots** is an unsplicable feet item which was added as part of the Garuda's Glory update on August 8, 2024.
##  Function
When used, the Lightning Lord's Boots serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Lightning Lord's set, which consists of the following items:

    * Lightning Lord's Cap (Hat)

    * Lightning Lord's Mask (Face)

    * Lightning Lord's Suit (Shirt)

    * Lightning Lord's Trousers (Pants)

    * Lightning Lord's Boots (Feet)
  * The Lightning Lord's Set is a reference to a Gundala, which is a comic character created by Hasmi who first appeared in the comic "Gundala Putra Petir" in 1969.
