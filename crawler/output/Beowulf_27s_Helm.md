**Beowulf's Helm** is an unsplicable hat item which was added as part of the All Howl's Eve monthly event update on July 19, 2021. The item was formally introduced on July 21, 2021, the date All Howl's Eve arrived.
##  Function
When equipped, Beowulf's Helm serves a purely cosmetic purpose.
The  Myths and Legends : The Eye of the Heavens mission requires 2 of this item.
##  Trivia
  * This item is considered a part of the Beowulf set, which consists of the following items:

    * Beowulf's Helm (Hat)

    * Beowulf's Beard (Face)

    * Beowulf's Shirt (Shirt)

    * Beowulf's Pants (Pants)

    * Beowulf's Blade (Hand)
  * The Beowulf set is based on a legendary heroic figure of the same name.
