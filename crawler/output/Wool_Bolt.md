# Wool Bolt

This is the page for **Wool Bolt**.
You may be looking for **Silk Bolt - White** instead.
Sew wool items by using this in a sewing machine with silk bolts. It takes 3 bolts of silk or wool to craft an item.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **4 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Consumption

Consume a(n)  Wool **(x100)**.
May yield **1** item each.

The **Wool Bolt** is an unsplicable consumable which was added as part of Harvest Festival 2016 on September 15, 2016.
##  Function
This item serves no purpose by itself.
