The **Wholly Egg Grenades** is an unsplicable hand item which was added as part of Easter Week 2023 on April 7, 2023.
##  Function
Sunnyside Up!!

Sunnyside Down!

When equipped the Wholly Egg Greandes grants the _Punch Damage + Punch Range: Wholly Egg Grenades_ mod, which allows the player to break blocks faster as well as punch one tile further.
##  Trivia
  * This item is a reference to the _Holy Hand Grenade_ from the movie "Monty Python and the Holy Grail".
