# Synthetic Chemical

This chemical was created in a lab. Its properties are virtually untested!
Synthetic Chemical (Rarity: 100)
Properties
This item never drops any seeds.
This item has no use... by itself.

Chemsynth Reward

**1** is earned after successfully attempting chemsynth.
The **Synthetic Chemical** is an unsplicable component which was added as part of the Night Of The Chemicals update on March 2, 2017.
##  Function
Being a type of chemical, the Synthetic Chemical can be used for combining alongside two other types of chemicals in a Chemical Combiner to create certain items.
