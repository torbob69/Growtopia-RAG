The **Moon Greatsword Block** is an unsplicable foreground block which was added as part of the Dungeons update on December 9, 2024.
##  Function
When placed the Moon Greatsword Block serves a purely aesthetic purpose. When painted, the color of the Moon Greatsword Block flickers from light to dark.
##  Trivia
  * The  Moon Greatsword Block shares the same item description with  Moon Greatsword.
  * The Moon Greatsword is a reference to Dark Moon Greatsword, a weapon from action role-playing game Elden Ring.
