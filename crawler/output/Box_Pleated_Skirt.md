# Box Pleated Skirt

A red skirt that's box pleated!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Pants – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Red.
Sew a  Silk Bolt - Red to the previous bolt using a(n) **Overcasting Stitch**.
Lastly, sew a  Silk Bolt - Grey to the previous bolt using a(n) **Locking Stitch**.
Each recipe gives **1** item.
The **Box Pleated Skirt** is an unsplicable pants item which was added as part of Player Appreciation Week 2022 Day 7 on August 21, 2022.
##  Function
When equipped, the Box Pleated Skirt serves a purely cosmetic purpose.
