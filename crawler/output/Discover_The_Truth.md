# Discover The Truth

**Discover The Truth** is a mysterious riddle added with the Systems Update.
Solving it gets you a Illuminati Stone.
There are 4 clues scattered around Growtopia. Each one of them rewards you one of these blocks:
  * Code Block: Kappa
  * Code Block: Charlie
  * Code Block: Ouroboros
  * Code Block: Edamame

##  Kappa
The "Kappa" Block can be earned by calling 41100-41199 in a Telephone. Only one number out of the 100 will result in a "Mysterious Voice" on the phone instead of "The Warehouse" and is different for each person.

"ITS DANGEROUS TO GO ALONE TAKE THIS" is a reference to the first Legend of Zelda, where the old man gives you a Wooden Sword. You need to wear a Wooden Sword, place a jellyfish faced to the left above a white door and break it to get a Code Block: Kappa.

##  Charlie
Asking Locke about Old Gertie gives clues to getting Code Block: Charlie.
_"Woah, Old Gertie... that brings back memories! Hmm. What can I say... Well, there's a story about Old Gertie. The gist is that she was a bluecow, fit to burst with milk, and she flew over the moon, mooing. That'd be something to see, eh? Yeah. Old stories were pretty stupid."_
Clues: Meaning_...that she was a blue cow..._: A Cow is needed. It must be painted blue.
..._fit to burst with milk..._: The Cow needs to be harvested when ready.
..._she flew over the moon..._: A Weather Machine - Night is used. Since the moon on is the top left of the screen, the Cow is placed at the top left of the world.
  1. Place Cow in top left of world.
  2. Paint Cow blue.
  3. Place Weather Machine - Night and turn it on.
  4. Harvest Cow when ready.

The Cow will drop 1 Code Block: Charlie instead of Milk.

##  The Truth
In the old version, you would have found a mp3 file at <http://growtopiagame.com/images/directive_epsilon.mp3>. The web archive version no longer works, but you can still access the file via the current version of Antipode.
_**NOTE** : This page was not available during the Growtopia Official Website revamp on **5 September 2017** , but the link was made a redirect to this page. The file can also be played below._ <https://growtopiawiki.com/w/File:Directive_epsilon.ogg>
By reversing the soundtrack, the following message is heard:
**Directive Epsilon. Obedience is mandatory. You must place a Crystal Gate in a world that begins with the letter Y. Set the destination to the name of the point, colon, the name of the nearby outpost. Enter the gate to discover the truth**
The name of the point is KILIMA, and the nearby outpost in the map is OKAVANGO OUTPOST located in the African outpost area.
Place a Crystal Gate in a world that begins with letter Y and set the destination to **KILIMA:OKAVANGO**. Enter the gate. It will blow up and a Illuminati Stone will be spawned.
