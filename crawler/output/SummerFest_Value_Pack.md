# SummerFest Value Pack
Growtopia Store

Purchase the **SummerFest Value Pack** for **2.99 USD** in the Growtopia Store.
"A sweet deal to go with the event!"
Every purchase will give **1** item.
The **SummerFest Value Pack** is a Store-bought IAP which was added as part of the SummerFest 2023 update and only appears during the first day of SummerFest.
## Items
The pack includes:
  * Gems ×105,000
  * Summer Surprise ×3
  * Fireworks ×100
  * Summer Face Paint ×1
