# Staircase

Sometimes it's nice to climb a staircase instead of hopping up platforms. Unfortunately, you'll also have to hop up the staircase - Growtopians can't climb.

The **Staircase** is a splicable foreground platform block which was added as part of the Mystery Update on November 11, 2013.
##  Function
A Staircase behaves as a platform, thus a player can jump pass through it from underneath.
