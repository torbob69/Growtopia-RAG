**Ezio's Armguards** is an unsplicable hand item which was added as part of Ezio update on October 14, 2018.
##  Function
Ezios armguards: Silent Killer!

Blade concealed!

When equipped, the **Ezio's Armguards** grants the _Punch Range: Blade!_ mod, which allows the player to punch one tile further. It will also replace the player's punching animation with blade-like projectiles.
##  Trivia
  * This item is based on the Hidden Blade, a type of concealable weapon found in the _Assassin's Creed_ franchise. As its name implies, the Hidden Blade features a narrow blade set into a channel on the underside of the wearer's gauntlet. The protagonist Ezio Auditore da Firenze is typically depicted with this weapon equipped.
  * This item is considered a part of the Ezio set, which consists of the following items:

    * Ezio's Hood (hat)

    * Ezio's Hair (hair)

    * Ezio's Beard (face)

    * Ezio's Vest (shirt)

    * Ezio's Cape (back)

    * Ezio's Armguards (hand)

    * Ezio's Trousers (pants)

    * Ezio's Boots (shoes)
