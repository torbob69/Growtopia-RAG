The **Greezak Horde - Warrior Armor** is an unsplicable shirt item which was added as part of the Startopia update on July 1, 2018.
##  Function
When equipped, the Greezak Horde - Warrior Armor serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Greezak Horde - Warrior set, which consists of the following items:

    * Greezak Horde - Warrior Helmet (Hat)

    * Greezak Horde - Warrior Armor (Shirt)

    * Greezak Horde - Warrior Leg Armor (Pants)
