# Balrog Wings

Born of fire and shadow. These wings burn but somehow are never consumed.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Back – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Mining

1 has a chance to be dropped from exploding  Pure Magic Ore using  Mining Explosives, which are naturally generated in mines.
The **Balrog Wings** is a back item which was added as a part of the Spelunkorama Strikes Back! update on February 6, 2020.
##  Function
Rise on fire and shadow!

Return from whence you came!

When equipped, the **Balrog Wings** grants the _Double Jump: Balrog Wings_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * This item is a reference to the wings of a fictional monster with the same name from the film and book series The Lord of the Rings.
