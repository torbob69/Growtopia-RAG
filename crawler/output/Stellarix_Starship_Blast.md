# Stellarix Starship Blast

Command your very own Starship and explore the cosmos! This blast contains one of 3 possible Stellarix Union ship types - which will you get? Note: Each Starship comes with a full tank of gas, an Imperial Helm - Mk. I, Imperial Reactor - Mk. I and an Imperial Viewscreen - Mk. I, so you'll be all set for your adventure among the stars! Extra Note: A Starship also comes with an assortment of space-age blocks!

The **Stellarix Starship Blast** is a blast that was released as part of the Startopia Update. One can be obtained from successfully performing a Star Voyage.
##  Function
When consumed, it will create a Stellarix-starship-blasted world, which is required in order for the player to perform Star Voyages.
