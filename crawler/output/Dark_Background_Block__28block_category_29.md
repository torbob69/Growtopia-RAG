# Dark Background Block (block category)

A **dark background block** is a type of non-solid background block which enshrouds the tile it is placed on in darkness.
Light source blocks may provide light to neighboring tiles when placed. In a similar manner, a player can illuminate their surroundings by equipping certain light source clothes. The Night Vision Goggles disregards darkness completely.
