The **Monochrome Blast** is a consumable introduced during Black Friday 2018 which creates a new world with monochromatic features. The background resembles a black-and-white version of Weather Machine - Sunny, and the blocks are monochromatic as well. Like any other blasts, the player can only create the world if it has not been created before.
The **Monochrome Blast** can only be purchased from the Growtopia Store for 25,000 Gems during the Black Friday event.
In a newly-generated **Monochromatic** world, the following blocks can be found:
  * Monochromatic Dirt
  * Monochromatic Cave Background
  * Monochromatic Lava
  * Monochromatic Bedrock
  * Rock
  * Onyx Block

##  Trivia
  * During the Black Friday 2021 update on November 26, 2021, the item's name was changed from Monochromatic Blast to Monochrome Blast.
