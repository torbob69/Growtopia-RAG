# EXIT

**EXIT** is a special world for players that are not currently in a world. When you are in the EXIT world, world selection screen is displayed instead.
Players can navigate to other worlds by typing the name of the world they want to go in the input box and press Enter World, or by pressing buttons that are displayed under the input box.
##  Trivia
  * Trying to enter EXIT world in the world selection screen will display the following message: "Exit from what? Press back if you're done playing.
  * Trying to enter a door that lead to EXIT world will send you to the world selection screen.
  * It is possible to send Private Message or Broadcast from EXIT world if you managed to get a popup opened at the same time you exit the world.
