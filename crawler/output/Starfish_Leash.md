The **Starfish Leash** is an unsplicable pet hand item which was added as part of SummerFest 2020 on July 3, 2020.
##  Function
Stars ready shine!!!

Time to put the stars to bed!

When equipped, the **Starfish Leash** grants the _Punch Damage: Starfish Leash_ mod, which allows the player to break blocks faster. Additionally, it throws tiny starfish projectiles while punching.
The  Myths and Legends : Here come the Shady Agents mission requires 1 of this item.
