# Growtopia/Unused Content

< Growtopia
Since the development of _Growtopia_ began, there has been a lot of content added to the game that cannot be accessed by regular gameplay.
This page documents only **unused content** that can currently still be found in the game and its files.
##  Tree Behavior
The game actually supports up to 5 fruits to be displayed on a single tree. The fifth fruit is never available in the real game although it can be achieved via cheats. The fifth fruit is a little bit further away from the fourth one than the fourth one is from the third one. If the player cheats in more than 5 fruits for a tree, it will draw every fruit beyond the fifth in the same spot. This can be seen by planting a transparent item's seed.

##  Textures
### Crystal Block     _Main article:Crystal Block_
A tile found in `tiles_page1.rttex` appears to be an unused version of the **Crystal Block**. Interestingly, this isn't the only scrapped design of the Crystal Block, as there were four different designs of the item, two of which went unused. Moreover, the  Emerald Block appears to be based on this sprite.

###  World Cup Winner's Jersey     _Main article:World Cup Winner's Jersey 2018_
The **World Cup Winner's Jersey 2018** is an unsplicable shirt item which was added as part of the Startopia update on July 1, 2018.
Before France was announced as the winner of the 2018 World Cup,[[1]](https://growtopiawiki.com/w/Growtopia/Unused_Content#cite_note-1) the developers added this item as a component item under the name of "World Cup Winner Jersey".[[2]](https://growtopiawiki.com/w/Growtopia/Unused_Content#cite_note-2) A sprite of a black-and-white box was used as the item's icon; it can currently still be found in `tiles_page11.rttex`.
