The **Moon Greatsword** is an unsplicable hand item which was added as part of the Dungeons update on December 9, 2024.
##  Function
The night is long...

...but cold and dark

When equipped, the **Moon Greatsword** grants the _Punch Damage + Punch Range: Moon Greatsword_ mod, which allows the player to break blocks faster and punch one tile further.
##  Trivia
  * Moon Greatsword shares the same item description with  Moon Greatsword Block.
  * The Moon Greatsword is a reference to the Moonlight Greatsword, a reoccurring weapon from the many action role-playing games developed and published by Fromsoftware, such as King's Field, Dark Souls and Elden Ring.
