# Outback Hat

G'day! Barbie! Shrimp! That's not a knife, it's a hat! These hats are popular among paleontologists and other desert dwellers.

Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Grey.
Sew a  Silk Bolt - Red to the previous bolt using a(n) **Saddle Stitch**.
Lastly, sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Blind Stitch**.
Each recipe gives **1** item.
The **Outback Hat** is an unsplicable hat item which was added as part of the Growassic Park update on October 7, 2016.
##  Function
When equipped, the Outback Hat serves a purely cosmetic purpose.
