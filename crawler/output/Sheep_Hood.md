# Sheep Hood

If you've been wishing for a sheep hood, then you're in luck, as this is a sheep hood! Perfect when combined with a Sheep Onesie!
Properties
This item never drops any seeds.
This item can be transmuted.

In any Chemical Combiner, mix together...
Easter Egg - Wooly **(×50)** ,

Bunny Mask **(×10)**.
This recipe will yield **1** item.
The **Sheep Hood** is an unsplicable hair item which was added as part of Easter Week 2021 on April 1, 2021.
##  Function
When equipped, the Sheep Hood serves a fully cosmetic purpose.
##  Trivia

    * Sheep Hood (hair)

    * Sheep Onesie (shirt)
