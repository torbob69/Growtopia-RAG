# Guild Chest

Loaded with guildy goodness (and other things)! Pop this chest open for a surprise item!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **2 Hits** **2 Hits** – Restores after **2s** of inactivity
Gems Drop: **N/A**
**1h**
NPC Trading

Buy 1 of this item from ** Locke The Salesman or  Lock-Bot** for  World Lock **(x1)**.
"A chest with Guild Items. Locke likey likey!"
The **Guild Chest** is an unsplicable consumable which was added alongside the Guilds update on April 1, 2018.
##  Function
Upon consumption, the player will receive one of the items below:
  * Guild Banner - Normal (Horizontal)
  * Guild Banner - Normal (Vertical)
  * Guild Banner - Ornate (Horizontal)
  * Guild Banner - Ornate (Vertical)
  * Guild Entrance - Normal
  * Guild Entrance - Ornate
  * Guild Flag Pole - Spear
  * Guild Flag Pole - Wings
  * Guild Flag - Arrow
  * Guild Flag - Peak
  * Guild Flag - Shield
  * Guild Flag - Tatters
  * Guild Flag - Wave
  * Guild Potion: Black Mixer
  * Guild Potion: White Mixer

##  Trivia
  * As of Player Appreciation Week 2021 Day 6, Guild Chests are now purchased from Locke or Lock-Bot for 1 World Lock each.
    * The Guild Chest Pack has since been removed.
  * The Guild Chest Pack's store description used to be _"A 10-pack of Guild Chests! Loaded with guildy goodness - pop a chest open for a surprise item!"_.
