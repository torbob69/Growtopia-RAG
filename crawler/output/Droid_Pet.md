The **Droid Pet** is a hand item which was added as part of the Time-Tossed! update on September 5, 2019.
##  Function
When equipped, a droid pet appears and follows the player around. The Droid Pet serves a purely cosmetic purpose.
##  Trivia
  * The item's description is written in binary and it means "droid loves you".
