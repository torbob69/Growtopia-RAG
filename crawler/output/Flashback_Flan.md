The **Flashback Flan** is an unsplicable consumable which was added as part of the Role Up! update.
##  Function
When used on an eligible block, the block will be removed from the world and placed into the player's inventory. However, a Flashback Flan is unable to be used on certain kinds of blocks. These are the block categories that cannot be Flashback Flan:
  * Mannequin
  * Event Mystery Blocks
  * Display Shelf
  * Donation Box
  * Unbreakable Block
  * NPCs
  * Provider
  * Cooking Oven
  * Fish Mount
  * Untradeable Block
  * Portrait
  * Game Block
  * Door
  * Crystal
  * Portal
  * Chest
  * Mailbox
  * Chemical Combiner
  * Public Blocks

Blocks that are not in the category:
  * Geiger Charger
  * DNA Extractor
  * Containment Field Power Node
  * Spirit Storage Unit
  * Painting Easel
  * Inviso-Block
  * Lobster Trap
  * Giving Tree
  * Battle Pet Cage
  * Bunny Egg
  * Phone Booth
  * Silkworm
  * Display Block
  * Challenge Timer
  * Balloon-O-Matic
  * Auto Surgeon Station
  * Forge
  * Sewing Machine
  * Chemsynth Tank
  * Challenge Start Flag
  * Challenge End Flag
  * Kranken's Galactic Block

##  Trivia
  * Flashback Flan can only be used by the world's owner.
  * When a Flashback Flan is successfully used on a block the following message will be generated: "[item name] Flashed Back to a time when it was still in your inventory."
