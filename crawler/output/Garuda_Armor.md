The **Garuda Armor** is an unsplicable shirt item which was added as part of the Garuda's Glory update on August 26, 2022.
##  Function
When equipped, the Garuda Armor serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Garuda set, which consists of the following items:

    * Garuda Mask (Hair)

    * Garuda Armor (Shirt)

    * Garuda Legs (Pants)

    * Garuda Boots (Feet)

    * Garuda Wings (Back)

    * Garuda Battle Axe (Hand)
  * The Garuda set is a reference to a Hindu demigod of the same name described as the king of the birds known as the state insignia of India, Indonesia, and Thailand.
