**Galactic Destructor - Red** is an unsplicable hand item which was added on June 1, 2019. One has a chance to be obtained from purchasing a Galactic Destructor from the Store for 200,000 Gems as June 2019's Item Of The Month.
##  Function
Galactic Code THX1137... Destruction protocol: initiate!

Take a break!

When equipped, the **Galactic Destructor - Red** grants the _Punch Range + Punch Damage: Destructor!_ mod, which allows the player to punch one tile further and break blocks faster. It also replaces the player's punching animation with red laser blasts.
