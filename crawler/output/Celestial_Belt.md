# Celestial Belt

Decide whether you should use your skills for good or evil with the Celestial Belt!

This item can be transmuted.

Consume a(n)  Golden Garuda Chest **(x1)**.

The **Celestial Belt** is an unsplicable chest item which was added as part of the Garuda's Glory update on August 8, 2024.
##  Function
Immortal Rising!

Mortal Falling!

When equipped, the **Celestial Belt** grants the _Speedy & Build Range: Celestial Belt!_ mod, which allows the player to move faster on land and build one tile further.
##  Trivia
  * This item is considered a part of the Celestial set, which consists of the following items:

    * Celestial Circlet (Hat)

    * Celestial Hair (Hair)

    * Celestial Belt (Chest)

    * Celestial Shirt (Shirt)

    * Celestial Trousers (Pants)

    * Celestial Boots (Feet)
