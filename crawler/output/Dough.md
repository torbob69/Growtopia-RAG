# Dough

D'oh! This is raw! What can we do with it?
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: No Collision
Hardness: **4 Hits** **3 Hits** – Restores after **5s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Wheat **(×4)** ,
Egg **(×1)** and
Sugar Cane **(×1)**.
This recipe will yield **1** item.
Breaking

| May drop in sets of **1** from breaking:
•  Cooking Supply Crate  |
The **Dough** is an unsplicable component item which was added as part of the Rise of the Desert Dragons update on August 3, 2013.
