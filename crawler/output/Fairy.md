# Fairy

A mighty magical sprite! You might think it's odd that it took over six years for an actual fairy to show up in Growtopia, but just remember, Fairy Wings were the VERY FIRST wing to be added to the game, and it took the Fairy Union a long time to get over it! Only found in Blarney 1 and 4.
Properties
This item never drops any seeds.

The **Fairy** is an unsplicable hand item which was added as part of St. Patrick's Week 2019 on March 15, 2019.
##  Function
When equipped, a fairy pet appears and follows the player around. The Fairy serves a purely cosmetic purpose.
