# Pilgrim's Shoes

There are all kinds of things to be thankful for during the holidays, but maybe one of the most important is just how dang awesome those pilgrims looked! Complete your ensemble with these traditional shoes and join the fun!
Properties
This item never drops any seeds.

The **Pilgrim's Shoes** that was added as part of the Thanksgiving Week 2018 update on November 22, 2018.
##  Function
When equipped, Pilgrim's Shoes serves a fully cosmetic purpose.
##  Trivia
  * This item is considered a part of the pilgrim (male) set, which consists of the following items:

    * Pilgrim's Hat (hat)

    * Pilgrim's Coat (shirt)

    * Pilgrim's Shoes (feet)
  * This item is considered a part of the pilgrim (female) set, which consists of the following items:

    * Pilgrim's Bonnet (hat)

    * Pilgrim's Dress (shirt)

    * Pilgrim's Shoes (feet)
