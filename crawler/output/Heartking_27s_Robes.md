The **Heartking's Robes** is an unsplicable shirt item which was added as part of the Valentine's Week 2019 update on February 8, 2019.
##  Function
When equipped, the Heartking's Robes serves a purely cosmetic purpose.
##  Trivia

    * Heartking's Crown (Hat)

    * Heartking's Robes (Shirt)
