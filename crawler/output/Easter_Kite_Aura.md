# Easter Kite Aura

Soar into the skies with this kite that spins round and round!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Chest – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**

Combination

In any Chemical Combiner, mix together...
Easter Egg - Rainbow **(×1)** ,
Rainbow Kite **(×1)** and
Sun Block **(×10)**.
This recipe will yield **1** item.
The **Easter Kite Aura** is an unsplicable chest item which was added as part of Easter Week 2022 on April 15, 2022.
##  Function
Spinning Around

Stopped Spinning!

When equipped, the **Easter Kite Aura** grants the _Double Jump: Easter Kite Aura!_ mod, which allows the player to jump a second time in mid-air.
