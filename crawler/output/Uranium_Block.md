The **Uranium Block** is an unsplicable solid foreground block which was added as part of the Geiger Day update on May 5, 2017, the same day Cinco De Mayo Week 2017 was released.
##  Function
Placing a Water Bucket on a Uranium Block and using a Nuclear Detonator on it can let players fish exclusive radioactive items from it.

##  Trivia
  * The game does not count the Uranium Block as an actual radioactive item, and thus, it won't remove the Geiger Counter's alive status.
    * Additionally, obtaining an Uranium Block doesn't count toward any goal revolving around finding items with the Geiger Counter.
  * The fact that a Water Bucket and a Nuclear Detonator can be used on it for radioactive fishing is referenced by the description of the Uranium Block.
