# Insect Glue Wallpaper

The only problem with laying down a sticky trap to catch bugs is that you wind up with a writhing wall of gross bugs. Ew.

The **Insect Glue Wallpaper** is an unsplicable non-solid background block which was added as part of the Gross-Out update on May 1, 2019.
##  Function
When placed, the Insect Glue Wallpaper serves a purely aesthetic purpose.
