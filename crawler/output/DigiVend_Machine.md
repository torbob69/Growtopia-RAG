**DigiVend Machine** is a foreground vending machine that was added on January 2, 2020 as part of the Store Wars update.
##  Function
It serves the same basic functionality as a Vending Machine. Additionally, it displays an estimate average price of an item with data coming from all trades across the game. A row of DigiVend Machines can all be connected using a Vending Hub - Checkout Counter, through which the player can access the whole row/column of DigiVend Machines without wrenching one-by-one.
