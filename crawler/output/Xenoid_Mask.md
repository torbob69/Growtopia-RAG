The **Xenoid Mask** is an unsplicable face item which was added as part of the Geiger Day update on May 5, 2017, the same day Cinco De Mayo Week 2017 was released.
##  Function
When equipped, the Xenoid Mask serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Xenoid set, which consists of the following items:

    * Xenoid Mask (Face)

    * Xenoid Suit (Shirt)

    * Xenoid Leggings (Pants)

    * Xenoid Shoes (Feet)

    * Xenoid Claws (Hand)
  * Supervillain  H.R. Geiger can be seen wearing this item.
  * The full Xenoid set is a reference to Xenomorph, a fictional character in the Alien franchise.
