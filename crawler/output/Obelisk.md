The **Obelisk** is an unsplicable non-solid SFX foreground block which was added as part of the Rise of the Desert Dragons update update on August 3, 2013.
##  Function
As it is an SFX foreground block, punching an Obelisk lights it up for 15 seconds and a sound effect. If a Sungate is present in the world, 7 Obelisks need to be activated for the gate to function as a portal. The Sungate will keep working as long as the Obelisks are still activated.
