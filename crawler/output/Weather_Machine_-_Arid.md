The **Weather Machine - Arid** is an unsplicable non-solid weather machine foreground block which was added as part of the Rise of the Desert Dragons update on August 3, 2013.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into a dry desert scenery.
##  Trivia
  * Two other weather machines, Weather Machine - Sunny and Weather Machine - Night, were released on the same day as Weather Machine - Arid.
  * A Desert Blasted world has the same background as Weather Machine - Arid.
