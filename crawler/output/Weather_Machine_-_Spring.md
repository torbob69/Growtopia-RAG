# Weather Machine - Spring

Punch this to enjoy springtime weather, anytime! This sensitive technology will not function while damaged.
Properties
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item never drops any seeds.
Data: Paint PreviewType — Weather Machine – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single
Collision Type: No Collision
Hardness: **10 Hits** **8 Hits** – Restores after **2s** of inactivity
Gems Drop: **N/A**
**1h**

Combination

In any Chemical Combiner, mix together...
Easter Egg - Polka Dots **(×1)** ,
Easter Egg - Rainbow **(×1)** and
Easter Egg - Striped **(×1)**.
This recipe will yield **1** item.
The **Weather Machine - Spring** is a weather machine that was added as part of 2016's Easter Week. When active, the sky will become a light blue color and the mountains will become green.
