The **Locke's Mystery Box** is a box which was added as part of the Locke The Traveling Salesman update on March 22, 2015.
##  Function
When broken, a Locke's Mystery Box may drop one of the following rewards.
  * Pink Suitcoat
  * Pink Fedora
  * Fancy Pants
  * Pencil Mustache
  * Distinguished Grey Hair
  * Growmoji Weary
  * B.O.O. Sign
  * Fade Hair
  * Mysterious Detective's Hair
  * Prisoner Cap
  * Prisoner Suit
  * A random block with rarity
  * A random seed with rarity
  * A random clothing item with rarity
