# Riding Silkworm (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.

The **Riding Silkworm** comes in 9 different colours. It can be made by using a Silkworm Saddle on a Silkworm.
The list of different **Riding Silkworms** are:
  * Riding Silkworm - Red
  * Riding Silkworm - Green
  * Riding Silkworm - Blue
  * Riding Silkworm - Black
  * Riding Silkworm - White
  * Riding Silkworm - Grey
  * Riding Silkworm - Purple
  * Riding Silkworm - Yellow
  * Riding Silkworm - Aqua
