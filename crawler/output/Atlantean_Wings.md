# Atlantean Wings

These pair of wings once belonged to an ancient sea monster from the underwater city of Atlantis!
Properties
This item cannot be dropped or traded.
This item never drops any seeds.
This item can be transmuted.
Data

Type: Back – Clothes
Render Type: Single

Marvelous Missions

Complete the **The Seven Seas : The Wings of Atlantis!** mission by submitting:
Partydactyl Wings **(×2)**
Aquamarine Stone **(×200)**
Goldfish Bowler Hat **(×10)**
Poseidon's Trident **(×1)**
Aqua Cave Crystal **(×200)**

The **The Seven Seas : The Crust of the Crab!** mission needs to be unlocked first before accessing this mission.
The **Atlantean Wings** is an unsplicable back item which was added as part of Player Appreciation Week 2022 Day 3 on August 17, 2022.
##  Function
For Atlantis!

Washed Away!

When equipped, the **Atlantean Wings** grants the _Double-Jump: Atlantean Wings_ mod, which allows the player to jump a second time in mid-air.
