# Wizard's Wand

You're a wizard buddy! Charm the world with the mystic wand.
Properties

This item can be transmuted.

Consume a(n)  Halloween Special Gift Box **(x1)**.
May yield **1** item each.

The **Wizard's Wand** is an unsplicable hand item which was added as part of Halloween Week 2022 on October 22, 2022.
##  Function
Abra Kadabra!

Houdini!

When equipped, the **Wizard's Wand** grants the _Punch Range : Wizard's Wand_ mod, which allows the player to punch one tile further.
##  Trivia
  * This item is considered a part of the Wicked Wizard set, which consists of the following items:

    * Wicked Wizard Hair (hair)

    * Wicked Wizard Scar (face)

    * Wicked Wizard Robes (shirt)

    * Wicked Wizard Pants (pants)

    * Wicked Wizard Shoes (feet)

    * Wizard's Wand (hand)
