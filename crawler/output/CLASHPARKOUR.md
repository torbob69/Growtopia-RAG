# CLASHPARKOUR

**CLASHPARKOUR** is a world introduced during Summer Clash 2019. It can only be entered by consuming a Summer Clash Finale Ticket, Winter Clash Finale Ticket, or Spring Clash Finale Ticket obtainable at the end of each clash rewards branch. A player can not use a finale ticket along with the other seasonal clash finale tickets when there is no clash event running. When a ticket is consumed, the player has 25 minutes to complete the parkour. There are a total of nine Finale Claims wherein the further the players reach, the better the rewards are. A player can only claim one Finale Claim and will force them to exit the world few seconds after claiming.
The following are the drop chances and prizes for each Finale Claim:
  * Spring Clash
  * Summer Clash
  * Winter Clash
