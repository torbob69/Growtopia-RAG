The **Dark Purple Block** is a splicable solid foreground block which was added on November 14, 2014.
##  Function
When placed, the Dark Purple Block serves a purely aesthetic purpose.

##  Trivia
  * The Dark Purple Block is one of the 9 dark color block variations in _Growtopia_ , all of which are farmable. They are:
    * Dark Aqua Block
    * Dark Blue Block
    * Dark Brown Block
    * Dark Green Block
    * Dark Grey Block
    * Dark Orange Block
    * Dark Purple Block
    * Dark Red Block
    * Dark Yellow Block
    * Note that the basic  Black Block and  White Block do not have a dark variant.
