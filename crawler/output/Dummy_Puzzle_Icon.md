The **Dummy Puzzle Icon** is an unobtainable icon which was added as part of the ReCAPTCHA System update on May 17, 2022.
##  Function
The Dummy Puzzle Icon is used as an icon for the CAPTCHA Window that verifies players by allowing them to slide to position the Puzzle Piece in the missing space. Currently, this feature is only available on Windows; other platforms still use the math CAPTCHA.
