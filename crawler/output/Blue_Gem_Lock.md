# Blue Gem Lock

Locks an entire world - and looks dazzling while it does it! Tap on it in your inventory to break it down into 100 Diamond Locks (if you have room in your inventory).
Properties
This item never drops any seeds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item has special properties you can adjust with the Wrench.
A lock makes it so only you (and designated friends) can edit an area.

The **Blue Gem Lock** is an unsplicable solid lock foreground block which was added as part of the Stuff! update on October 1, 2018.
##  Function
As a type of world lock, a Blue Gem Lock has all the basic properties of a regular World Lock.
Blue Gem Locks are often used to store and trade Diamond Locks in a compact fashion, as it can be shattered back into 100 Diamond Locks when its inventory icon is double-tapped.

##  Trivia
  * A duplication glitch occurred shortly after the Blue Gem Lock's release, allowing players to duplicate the lock when purchasing items from a Vending Machine.
  * Locking a world with the lock would give the player the  _Big Showoff_ achievement, granting the player 5,000 gems and 100 XP. A stealth update released later in October removed the gem prize; earning the achievement now only awards 100 XP to the player.[[1]](https://growtopiawiki.com/w/Blue_Gem_Lock#cite_note-1) This was seemingly done in order to prevent potential abuse involving alternate accounts.
    * A special message with an unknown purpose is displayed when a player earns the achievement after the prize change, stating that "To mark this momentous occasion and in recognition of your incredible wealth, 5,000 Gems have been donated to the International Growtopian Emergency Fund to help needy Growtopians everywhere!"
  * As of Anniversary Week 2026, Blue Gem Locks now recycle for 0 Gems, while they previously recycled for 2,000,000.
