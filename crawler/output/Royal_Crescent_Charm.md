The **Royal Crescent Charm** is an unsplicable chest item which was added as Aprils 2022's Item Of The Season on April 1, 2022.
##  Function
Shiming, Shimmering, Splendid!

Sun's up!

When equipped, the **Royal Crescent Charm** grants the _Build Range + High Jump: Royal Crescent Charm_ mod, which allows the player to build one tile further and jump one tile higher.
