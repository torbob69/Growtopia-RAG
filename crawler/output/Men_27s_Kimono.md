# Men's Kimono

Wear this traditional Japanese garment.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Black.
Sew a  Silk Bolt - Grey to the previous bolt using a(n) **Overcasting Stitch**.
Lastly, sew a  Silk Bolt - Black to the previous bolt using a(n) **Locking Stitch**.
Each recipe gives **1** item.
The **Men's Kimono** is an unsplicable shirt item which was added as part of Player Appreciation Week 2022 Day 2 on August 16, 2022.
##  Function
When equipped, the Men's Kimono serves a purely cosmetic purpose.
