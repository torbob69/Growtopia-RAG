**The Varlaak** is an unsplicable solid deadly foreground block which was added as part of the Startopia update.
##  Function
Being a deadly block, The Varlaak kills players upon contact.
##  Trivia
  * This item's name, description and appearance is a reference to the sarlacc, a fictional carnivorous animal from the science-fiction franchise Star Wars.
