# Good Witch's Dress

Popular! With this magical dress, you're going to be popular!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Purple.
Sew a  Silk Bolt - White to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Silk Bolt - White to the previous bolt using a(n) **Blind Stitch**.
Each recipe gives **1** item.
The **Good Witch's Dress** is an unsplicable shirt item which was added added as a part of Valentine's Week 2025 on February 13, 2025.
##  Function
When equipped, the Good Witch's Dress serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Good Witch set, which consists of the following items:

    * Good Witch's Crown (hat)

    * Good Witch's Dress (shirt)

    * Good Witch's Wand (hand)
  * The full Good Witch set is a reference to a fictional character called Glinda Upland from the theatrical play and movie Wicked.
