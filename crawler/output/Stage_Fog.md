The **Stage Fog** is an unsplicable non-solid toggleable multi-framed animated foreground block which was added as part of Grow4Good Week 2024 on April 26, 2024.
##  Function
When toggled, the Stage Fog emits smoke five blocks wide. Additionally, the fog's color changes based on the paint of the Stage Fog.
