# Seductive Rose

Sticking a rose in your mouth seems to make your voice so much more attactive when you sing.
Properties
This item never drops any seeds.
Data

Type: Face – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**

Crimefighting Reward

Defeat  El Peligro in crimefighting.
May give **1** item each time.
The **Seductive Rose** is an unsplicable face item which was added as part of Cinco De Mayo 2017 on May 5, 2017.
##  Function
When equipped, the Seductive Rose serves a fully cosmetic purpose.
##  Trivia
  * The Seductive Rose is based on an incorrect stereotype in which a tango dancer would put a red rose between his teeth in order to symbolize passion.[[1]](https://growtopiawiki.com/w/Seductive_Rose#cite_note-1)[[2]](https://growtopiawiki.com/w/Seductive_Rose#cite_note-2)
