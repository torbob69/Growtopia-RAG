The **Jail Door** is a splicable foreground entrance block which was added alongside the Dungeon Pack on April 19, 2013.
##  Function
Being an entrance, a Jail Door allows players with access to walk through it, or, when its property is changed, allowing any player to walk through it. When placed in a public area, it is impossible to be closed for anyone.

##  Trivia
  * The Jail Door's description is a reference to the Alcatraz escape of 1962, where four inmates escaped by digging a hole in the walls of their cells by using spoons and discarded saw blades.
