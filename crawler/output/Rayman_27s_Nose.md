The **Rayman's Nose** is an unsplicable face item which was added as part of the Rayman update on January 1, 2018.
##  Function
When equipped, the **Rayman's Nose** serves a purely cosmetic purpose. However, equipping the entire Rayman set will transform the player into the Rayman.
