# Bunny Beanie

Look at this hippin' hoppin' beanie!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - White.
Sew a  Silk Bolt - Purple to the previous bolt using a(n) **Overcasting Stitch**.
Lastly, sew a  Silk Bolt - Purple to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **Bunny Beanie** is an unspliceable hat item which was added as part of Easter Week 2023 on April 7, 2023.
##  Function
When equipped, the Bunny Beanie serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Bunny set, which consists of the following items:
