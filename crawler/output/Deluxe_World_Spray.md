# Deluxe World Spray

Spray in a world to instantly grow all trees by 24 hours!
Properties
This item can only be used in World-Locked worlds.
This item cannot be dropped or traded.
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision

Growtopia Store

Purchase the **Deluxe World Spray** for **5 Grow Voucher** in the Growtopia Store.
"Spray in a world to instantly grow all trees by 24 hours!"
Every purchase will give **1** item.
Royal Grow Pass

• Royal Grow Pass users who gain **5400 Grow Pass Points** earn **1** of this item.
The **Deluxe World Spray** is an unsplicable consumable which was added as part of Voucher Dayz on May 26. 2023.
##  Function
When consumed in a world, the Deluxe World Spray will speed up the time required to grow for all trees in the world by 24 hours.
