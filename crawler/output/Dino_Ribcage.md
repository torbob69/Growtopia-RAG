It's a bit grisly, but these enormous bones make kind of a fun set of monkey bars...

The Dino Ribcage is a platform which was added on the Growassic Park Update. It is a possible drop from a Fossil Prep Station. Dino ribcage can be used in DNA Extractor for a chance to extract random DNA strand.
##  Function
A Dino Ribcage behaves as a platform, thus a player can jump pass through it from underneath.
