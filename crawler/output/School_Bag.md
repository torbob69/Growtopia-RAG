The **School Bag** is an unsplicable back item which was added as part of Player Appreciation Week 2023 Day 6 on September 2, 2023.
##  Function
School's Out!

Time to study!

When equipped, the **School Bag** grants the _Punch Damage + Punch Range: School Bag_ mod, which allows the player to break blocks faster and punch one tile further.
##  Trivia
  * The School Bag's appearance is a reference to the Fully Loaded Backpack, an item from an online game platform and game creation system Roblox.
