The **Ultra Spring Flinger Frog Mask** is an unsplicable hat item which was added as part of Spring Clash 2019 on March 1, 2019.
##  Function
When equipped, Ultra Spring Flinger Frog Mask serves a fully cosmetic purpose. This item features an item animation, unlike the Spring Flinger Frog Mask.
##  Trivia
  * On 6 March 2019, the name of this item was changed from Ultra Spring Frog Mask to its current one.
  * This item is considered a part of the ultra spring flinger frog set, which consists of the following items:

    * Ultra Spring Flinger Frog Mask (hat)

    * Ultra Spring Flinger Frog Suit (shirt)
