**Rose Rifle** is an unsplicable hand item which was added as part of Valentine's Week 2021 on February 13, 2021.
##  Function
Scope up: It's time go long!

Scope down: Time to get close!

When equipped, the **Rose Rifle** grants the _Punch Range: Snipeshot_ mod, which allows the player to punch one tile further.
