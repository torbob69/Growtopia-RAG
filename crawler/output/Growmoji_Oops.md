# Growmoji Oops

Feeling nervous and a little awesome? Grin and bear it with this growmoji! Just consume to add it to your available growmojis!
Properties
A tree of this type can bear surprising fruit!
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
The **Growmoji Oops** is a Growmoji that was released as part of the March Update. One is obtained through a special event.
##  Function
When consumed, the player will be able to use the (oops) Growmoji.
