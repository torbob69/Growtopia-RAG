# Arrow Placard

This sign includes a bit of added information - an arrow! The arrow points whichever direction you are facing when you place the sign.
Arrow Placard (Rarity: 17)
Properties
This item has special properties you can adjust with the Wrench.
This item can be placed in two directions, depending on the direction you're facing.

The **Arrow Placard** is a splicable non-solid sign foreground block which was added as part of the Artsy April update.
##  Function
Being a sign, an Arrow Placard allows players with access to it to edit its message for other players to view.
