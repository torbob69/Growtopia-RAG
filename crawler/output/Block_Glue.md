# Block Glue

Squirt some of this on a block, and neighboring blocks will attach to it, visually. For example, if you glue a block, and there's a Dirt Block below it, the dirt block won't have a green top, because it will think there's Dirt above it! Use glue again to remove it.

The **Block Glue** is an unsplicable consumable that was added as part of the Growladies update on September 20, 2014.
##  Function

When used on a block, other blocks around it will connect to the block as if it is one of their own.

When used on a tile without a block, it will create a glued spot which slows down passing players instead. Gluing wallpapers together removes the slowdown effect.
A Block Glue can be used to remove placed glue without consuming the former.
##  Trivia
  * The Gazette announcement that introduced Block Glue said, "_STICK ON THIS: Today we introduce Block Glue. It's sort of tricky to understand (for pro builders only!), but it also allows you to control how borders work on blocks that have auto-filling._ "
  * Prior to Player Appreciation Week 2020 Day 4, removing a placed Block Glue would consume a Block Glue.
  * As part of the Quality of Life Changes update on May 20, 2022, the quantity of Block Glue obtained from combining is increased from 2 to 10.
