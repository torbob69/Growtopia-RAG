# CyBlocks Command Pack
Growtopia Store

Purchase the **CyBlocks Command Pack** for **2,000 ** in the Growtopia Store.
"Grants 10 random CyBlock Commands to help control your Cybots!"
Every purchase will give **1** item.
The **Cyblocks Command Pack** is a pack which was released alongside the March Update on March 1, 2018. Upon purchasing this pack, 10 random Cyblock Commands are given to the player.
##  Items
The following items can be obtained by purchasing the Cyblock Command Pack:
  * Command - Move Right
  * Command - Move Left
  * Command - Move Up
  * Command - Move Down
  * Command - Pause
  * Command - Basic Shot Right
  * Command - Basic Shot Left
  * Command - Basic Shot Up
  * Command - Basic Shot Down
  * Command - Improved Shot Right
  * Command - Improved Shot Left
  * Command - Improved Shot Up
  * Command - Improved Shot Down
  * Command - Long Shot Right
  * Command - Long Shot Left
  * Command - Long Shot Up
  * Command - Long Shot Down
