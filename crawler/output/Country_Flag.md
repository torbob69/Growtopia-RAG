# Country Flag

Place this anywhere to proudly display your country's flag!
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.
Data: Paint PreviewType — Country Flag – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single
Collision Type: No Collision
Hardness: **7 Hits** **6 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Aqua.
Sew a  Silk Bolt - Purple to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Overcasting Stitch**.
Each recipe gives **1** item.
The **Country Flag** is an unsplicable non-solid foreground block which was added as part of the Silkworm update.
##  Function
When placed, the Country Flag serves a purely aesthetic purpose. The Country Flag will display the national or regional flag of the player who placed it. It is impossible to change the national/regional flag once the Country Flag has been placed.

##  Trivia
  * When placed in a Display Block, the Country Flag shows the respective national or regional flags of the players seeing it rather than the national/regional flag of the player who placed the Country Flag into the Display Block.
  * There is a rendering bug involving the RTSoft flag, which causes the flag to show a blank one.
  * The item's recipe was disabled on the Artsy April update due to a world rendering glitch, but then re-enabled on 3 May, alongside Cinco De Mayo Week 2016.
