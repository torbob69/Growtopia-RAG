# Pueblock

Este es un bloque de construccion muy tradicional!

**1h**

Pinata Bash

Participate in successfully smashing an  Ultra Pinata during the **Pinata Bash!** event.
May give **2-5** items each time.
The **Pueblock** is an unsplicable solid foreground block which was added as part of Cinco De Mayo Week 2019 on May 3, 2019.
##  Function
The item has four different textures and when placed, a random one will appear. The four textures are:
  * A blue polka-dot textured block.
  * A green polka-dot textured block.
  * An orange polka-dot textured block.
  * A pink polka-dot textured block.
