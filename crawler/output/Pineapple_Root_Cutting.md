# Pineapple Root Cutting

A great thing has grown. Your attention and care has paid off, the bounty of the roots is all yours! Now, what could it be used for?
Properties
This item never drops any seeds.
Data

Type: Root Cutting – Component
Render Type: Single
Collision Type: No Collision
Hardness: **6 Hits** **5 Hits** – Restores after **5s** of inactivity
Gems Drop: **N/A**
**1h**
Mature Pineapple Roots

A single **Pineapple Root Cutting** has a 10% chance of dropping when harvesting Mature Pineapple Roots.
The **Pineapple Root Cutting** is an unsplicable root cutting which was added as part of Super Pineapple Party 2020 on June 4, 2020.
##  Function
As a root cutting, this item serves no purpose by itself.
