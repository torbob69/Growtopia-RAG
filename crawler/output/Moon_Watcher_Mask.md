# Moon Watcher Mask

Watch the Moon in style with this mask which also makes you look a little like an awesome super hero!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Face – Clothes
Render Type: Single
Collision Type: Full Collision

Combination

In any Chemical Combiner, mix together...
Purity Mooncake **(×2)** ,
Songpyeon **(×1)** and
Prosperity Mooncake **(×2)**.
This recipe will yield **1** item.
The **Moon Watcher Mask** is an unsplicable face item which was added as part of Harvest Festival 2020.
##  Function
When equipped, the Moon Watcher Mask serves a purely cosmetic purpose.
The  Myths and Legends : The Eye of the Heavens mission requires 10 of this item.
