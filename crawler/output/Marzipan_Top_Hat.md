# Marzipan Top Hat

This traditional sweet for Easter makes a sweet top hat!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Aqua.
Sew a  Silk Bolt - White to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Silk Bolt - Purple to the previous bolt using a(n) **Blind Stitch**.
Each recipe gives **1** item.
The **Marzipan Top Hat** is an unsplicable Hat item which was added as part of Easter Week 2024 on April 7, 2024.
##  Function
When equipped, the Marzipan Top Hat serves a purely cosmetic purpose.
