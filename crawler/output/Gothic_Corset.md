Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Black.
Sew a  Silk Bolt - Black to the previous bolt using a(n) **Locking Stitch**.
Lastly, sew a  Silk Bolt - Grey to the previous bolt using a(n) **Zigzag Stitch**.
Each recipe gives **1** item.
The **Gothic Corset** is an unsplicable shirt item which was added as part of Player Appreciation Week 2017 Day 7 on August 23, 2017.
##  Function
When equipped, the Gothic Corset serves a purely cosmetic purpose.
