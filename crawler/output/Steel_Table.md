The **Steel Table** is an unsplicable platform foreground block which was added alongside the Mad Science Kit on July 20, 2013.
##  Function
A Steel Table behaves as a platform, thus a player can jump pass through it from underneath.
##  Trivia
  * The Steel Table's appearance is a recolor of Wooden Table's.
