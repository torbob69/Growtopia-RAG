The Lembuswana Trident is a symbol of power and nobility of a King, protecting citizens from harm and creating a prosperous city!

The **Lembuswana Trident** is an unsplicable hand item which was added as part of Garuda's Glory 2023 on August 17, 2023.
##  Function
Channeling the power of the Lembuswana!

Connection to the power of Lembuswana has been severed!

When equipped, the **Lembuswana Trident** grants the _Punch Damage + Punch Range: Lembuswana Trident!_ mod, which allows the player to break blocks faster and punch one tile further.
##  Trivia
  * This item is considered a part of the Lembuswana set, which consists of the following items:

    * Lembuswana Crown (Hat)

    * Lembuswana Mask (Face)

    * Lembuswana Chestplate (Shirt)

    * Lembuswana Tunic (Pants)

    * Lembuswana Feet (Feet)

    * Mythical Lembuswana (Feet)

    * Lembuswana Trident (Hand)
  * The Lembuswana set is a reference to a legendary creature of the same name described as a lion-headed horse with an adorning crown, having an elephant-like trunk, a pair of Garuda wings, and fish-like scales.
