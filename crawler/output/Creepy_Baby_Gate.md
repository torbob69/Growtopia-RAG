The **Creepy Baby Gate** is an unsplicable toggleable foreground block which was added as part of Player Appreciation Week 2020.
##  Function
Being a toggleable foreground block, a Creepy Baby Gate works like a Fissure, allowing player to open and close the Creepy Baby Gate by punching it. When toggled on, the item acts as a solid block which players cannot pass while killing all players trapped inside it. When toggled off, it opens and acts as a non-solid block which players can walk through. It can be wrenched to be made public or not.
