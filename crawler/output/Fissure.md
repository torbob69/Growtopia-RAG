The **Fissure** is an unsplicable toggleable foreground block which was added as part of the Hidden Riches update on September 1, 2017.
##  Function
Being a toggleable foreground block, a Fissure works like a Dragon Gate, allowing eligible players to open and close the Fissure by punching it. When toggled on, the item acts as a solid block which players cannot pass while killing all players trapped inside it. When toggled off, it opens and acts as a non-solid block which players can walk through. It can be wrenched to be made public or not.
##  Trivia
  * Before WinterFest, the green layer of Fissure turns white, as if snow has covered the grass. This change is merely visual, the Fissure still retains the same properties as before.
    * This change will be reversed once WinterFest is over.
