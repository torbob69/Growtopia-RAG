# Trash

As seen from the backpack
The **Trash tool** is used to trash items from a player's inventory for clearing it out of unneeded items. There are no other gains from trashing items. It can be upgraded with the Recycle Tool when player gets Supporter status, which allows a player to get gems for recycled items.
