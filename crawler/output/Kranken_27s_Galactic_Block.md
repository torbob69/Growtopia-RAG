The **Kranken's Galactic Block** is an unsplicable non-solid foreground block which was added as part of Voucher Dayz 2021 on July 29, 2021. The item was formally introduced on July 30, 2021, the date when the event arrived.
##  Function
When placed, the Kranken's Galactic Block serves a purely aesthetic purpose.
This block features several special customization functions. To set the color for the block, the player needs to enter an RGB (Red, Green, Blue) value. Moreover, the player can pick one of the 12 different patterns, as well as set the pattern as the default when placing more blocks in the world. The types of patterns are as follows:
  * Krankens Pattern 1
  * Krankens Pattern 2
  * Krankens Pattern 3
  * Krankens Pattern 4
  * Krankens Pattern 5
  * Krankens Pattern 6
  * Krankens Pattern 7

  * Krankens Pattern 9

  * Krankens Pattern 11
  * Krankens Pattern 12

##  Trivia
  * This item is sponsored by Kranken for completing all the Epic Quests.
  * Hours after the block's release, a small group of players managed to find an exploit involving the block to illegitimately duplicate items. No rollback was administered due to the successful retrieval of most of the duplicated items.[[1]](https://growtopiawiki.com/w/Kranken's_Galactic_Block#cite_note-1)
