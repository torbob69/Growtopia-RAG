# Growmoji Bunny

Pop a bunny into your chat and get your hop on! Just consume this to add it to your available growmojis!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Egg Rescue

Chance to be rewarded from the **Egg Rescue** mini-game in the EGGRESCUE world.
|
This item can only be obtained during Easter Week.   |
1 of this item is given out each time.
**Growmoji Bunny** is an unsplicable consumable which was added as part of Easter Week 2018.
##  Function
When consumed, this item unlocks the (bunny) Growmoji.
