The Code Block: Ouroboros is an unsplicable foreground block which was added as part of the Discover The Truth riddle of the Systems Update on September 2, 2016.
It is created by having three people (all on each other's friend's list) climb to Legendary Mountain, one wearing a Yeti Hat, one wearing Zombie-Stompin' Boots and one wearing X-Ray Specs. All three players must execute the command /furious next to the orb.
##  Function
When placed, the Code Block: Ouroboros serves a purely cosmetic purpose.
