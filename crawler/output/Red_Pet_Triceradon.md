The **Red Pet Triceradon** is an unsplicable hand item which was added as part of Growassic Park on October 7, 2016.
##  Function
When equipped, the Red Pet Triceradon serves a purely cosmetic purpose and summons a Red Pet Tyranotops which follows the player around.
