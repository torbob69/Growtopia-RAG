# Dogfish

This is a 1 lb. Dogfish. Dogfish are a type of shark, and they are so named because they hunt in packs, like dogs do. It has nothing to do with their appearance, which is entirely fishlike and not canine at all.
Properties
This item never drops any seeds.
This is a fish. It can only be placed in a Fish Tank. You can't divide fish into pieces.
