# World Architect

Need help planning your next great creation? The World Architect will project a numbered grid over your entire world, scaling as you zoom in and out to let you pinpoint blocks and locations for tweaking!
Properties
This item can only be used in World-Locked worlds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item never drops any seeds.

The **World Architect** is an unsplicable solid foreground block which was added as part of Summer Clash 2018. When added, one had a chance to be obtained from the Summer Awards. This was changed to be a possible CLASHPARKOUR reward instead from Summer Clash 2019 onwards.
##  Function
When active, it will display the X and Y axis of every tile in the world to the owner and admins of the world.
##  Trivia
  * Prior to Player Appreciation Week 2020 Day 2, the grids created by a World Architect can be seen by everyone in the world.
  * There was a bug involved on the World Architect, allowing players to put multiple copies of them in a world, corrupting the Data Bedrock. Then, if anybody tries to stand on top of a bugged World Architect block while inside a water block, the system will automatically ban them for 60 days.
