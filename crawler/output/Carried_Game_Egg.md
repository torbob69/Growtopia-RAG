This item does not have any recipe because it is no longer, or was never obtainable.
The **Carried Game Egg** is an unobtainable non-solid foreground block which was added as part of Easter Week 2018 on April 5, 2018.
##  Function
It is seen during a game in the world EGGRESCUE when the player has collected an egg and is holding it in their hand. If a player kills them while they are holding it, it will drop onto the ground for another player to collect, or for the player to return it back to their team.
