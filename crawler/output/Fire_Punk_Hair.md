# Fire Punk Hair

Are you fed up with the status quo? Want to burn the system and start anew? Then start with your hair! This sizzling style will show you're not just a thorn in the system - you're making anarchy look GOOD. Whoever snagged this hairdo had to be quick so the flames wouldn't go out and super-hot so they'd stay bright, all to bring it to you!
