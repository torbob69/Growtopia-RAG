# Boots of Spring

Turn footloose with these spring shoes!
Properties
This item never drops any seeds.
This item can be transmuted.

Type: Feet – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**

Consumption

Consume a(n)  Equinox Box **(x1)**.
May yield **1** item each.

The **Boots of Spring** is an unsplicable feet item that was added as part of Equinox Weekend on March 25, 2022.
##  Function
Trippin' Around!

Skippin' Around!

When equipped, the **Boots of Spring** grants the _Speedy: Boots of Spring_ mod, which allows the player to move faster on land.
##  Trivia
  * This item is considered a part of the Equinox Spring set, which consists of the following items:

    * Crown of Spring (hat)

    * Shirt of Spring (shirt)

    * Pants of Spring (pants)

    * Boots of Spring (shoes)
