The **Growing Guardian Armor** is an unsplicable shirt item which was added as part of Grow4Good Week 2022 on April 22, 2022.
##  Function
Let it Grow! Let it Grow! Let it Grow!

Withered Away!

When equipped, the **Growing Guardian Armor** grants the _Build Range : Growing Guardian Armor_ mod, which allows the player to build one tile further.
##  Trivia
  * This item is considered a part of the Growing Guardian set, which consists of the following items:

    * Growing Guardian Armor (shirt)

    * Growing Guardian Gauntlets (hand)

  * When equipped together with the Growing Guardian Gauntlets, a green glow will appear behind the player.
