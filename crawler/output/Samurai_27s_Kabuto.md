The **Samurai's Kabuto** is an unsplicable hat item which was added as part of Player Appreciation Week 2019 on August 22, 2019.
##  Function
When equipped, the Samurai's Kabuto serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Samurai set, which consists of the following items:

    * Samurai's Kabuto (Hat)

    * Samurai's Do Armor (Shirt)
