# Sunflower Pants

These pants will make you feel like you're walking on sunshine!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Pants – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Wool Bolt.
Sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Blind Stitch**.
Lastly, sew a  Silk Bolt - Black to the previous bolt using a(n) **Zigzag Stitch**.
Each recipe gives **1** item.
The **Sunflower Pants** is an unsplicable pants item added as part of Harvest Festival 2021 on September 16, 2021.
##  Function
When equipped, the Sunflower Pants serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the masculine sunflower set, which consists of the following items:

    * Masculine Sunflower Hair (hair)

    * Masculine Sunflower Shirt (shirt)

    * Sunflower Pants (pants)
