# WinterFest Royal Shoes

A pair of shoes fit for a prince of the northern isles!

This item can be transmuted.

The **WinterFest Royal Shoes** is an unsplicable feet item was added as part of WinterFest 2023 on December 15, 2023.
##  Function
When equipped, the WinterFest Royal Shoes serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the WinterFest Royal Prince set, which consists of the following items:

    * WinterFest Royal Hair (Hair)

    * WinterFest Royal Suit (Shirt)

    * WinterFest Royal Pants (Pants)

    * WinterFest Royal Shoes (Feet)
  * The full Winterfest Royal Prince set is a reference to a fictional character named Hans Westergaard from a Disney movie called Frozen.
