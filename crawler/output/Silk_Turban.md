# Silk Turban

Cover up that hair!
Properties
This item never drops any seeds.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Yellow.
Sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Triple Stretch Stitch**.
Lastly, sew a  Silk Bolt - Grey to the previous bolt using a(n) **Blind Stitch**.
Each recipe gives **1** item.
The **Silk Turban** is an unsplicable hat item which was added in the Silkworm Update. One can be obtained from sewing.
##  Trivia
  * The player seen on the banner of the Silkworm update wears a Silk Turban.
