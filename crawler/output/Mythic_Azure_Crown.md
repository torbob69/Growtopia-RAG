The **Mythic Azure Crown** is an unsplicable hat item which was added as part of Lunar New Year 2024 on February 1, 2024.
##  Function

You've lost the power!

When equipped, the **Mythic Azure Crown** grants the _Punch Damage + Punch Power: Mythic Azure Crown_ mod, which allows the player to break blocks faster and knock back other players further.
