The **Ceiling Fan** is an unsplicable non-solid toggeable 4-framed animated foreground block which was added as part of the Block Party 2 update on April 1, 2019.
##  Function
When placed, the Ceiling Fan serves a purely aesthetic purpose. As a 4-frame animated foreground block, a Ceiling Fan features an automatic 4-frame animation.
