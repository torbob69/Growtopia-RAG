# Weather Machine - Stuff

It's rainin' stuff! This amazing new weather machine will let you choose any item you have to rain down from the sky! Wrench it to choose your item and adjust other settings. You can only have one of these per world.
Properties
This item never drops any seeds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item has special properties you can adjust with the Wrench.

Purchase the **Weather Machine - Stuff** for **50,000 ** in the Growtopia Store.
"This is the most fun weather imaginable - Choose any item from your inventory, adjust some settings, and watch it rain down from the sky! Or up, if you prefer reversing the gravity. Its a perma-item, is never lost when destroyed."
Every purchase will give **1** item.
The **Weather Machine - Stuff** is a toggleable weather machine which was released on Player Appreciation Week 2016.
##  Function
Upon wrenching this item, the weather of the world can be changed to any item sprite in one's inventory, and toggled to fall down or rise in any chosen speed.
