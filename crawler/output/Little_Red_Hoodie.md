# Little Red Hoodie

My, what fine fashion you have! This hoodie will keep you warm and, more importantly, looking great in all kinds of weather!
Properties
This item never drops any seeds.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Red.
Sew a  Silk Bolt - Red to the previous bolt using a(n) **Straight Stitch**.
Lastly, sew a  Silk Bolt - Red to the previous bolt using a(n) **Overcasting Stitch**.
Each recipe gives **1** item.
The **Little Red Hoodie** is an unsplicable shirt item which was added as part of Player Appreciation Week 2018 Day 1 on August 6, 2018.
##  Function
When equipped, the Little Red Hoodie serves a purely cosmetic purpose.
##  Trivia
  * The **Little Red Hoodie** is one of the three hoodies released on the same day, the other two are Big Bad Blue Hoodie and Punk Purple Hoodie.
  * The **Little Red Hoodie** and Big Bad Blue Hoodie are references to the fairy tale _Little Red Riding Hood._
