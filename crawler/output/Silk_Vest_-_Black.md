# Silk Vest - Black

A snappy vest suitable for any occasion.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Black.
Sew a  Silk Bolt - White to the previous bolt using a(n) **Straight Stitch**.
Lastly, sew a  Silk Bolt - Black to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **Silk Vest - Black** is an unsplicable shirt item which was added as part of the Silkworm update on February 1, 2016.
##  Function
When equipped, the Silk Vest - Black serves as a purely cosmetic purpose.
##  Trivia
  * This is one of the six Silk Vest color variations available in the game, others include Silk Vest - Green, Silk Vest - Grey, Silk Vest - Blue, Silk Vest - Red, and Silk Vest - Purple.
