**Weather Machine - Stargazing** is a weather machine that was added as part of Player Appreciation Week 2019 Day 2 on August 20, 2019.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into a stargazing scenery similar to the Weather Machine - Warp Speed, but with immovable stars.
