# Teeny Tiny Skull

This skull is so small! It would probably take 10 of these to do anything useful.
Properties
This item never drops any seeds.

Render Type: Single
Collision Type: No Collision

**Teeny Tiny Skull** is an unsplicable consumable which was added as part of Halloween Week 2014 on October 30, 2014.
##  Function
This item serves no purpose by itself.
