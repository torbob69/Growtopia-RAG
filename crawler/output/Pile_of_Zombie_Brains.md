# Pile of Zombie Brains

Ew, these are all brains that popped out of zombies' heads! Maybe Sales-Man wants them. You sure don't. Double-tap this in your inventory to split it up into 100 Zombie Brains.
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: No Collision
Hardness: **4 Hits** **3 Hits** – Restores after **5s** of inactivity
Gems Drop: **N/A**
**1h**
Double Tap/Click in Inventory

Made by double-tapping/clicking  Zombie Brain **(×100)** in one's inventory.
Always creates **1** item each.
The **Pile of Zombie Brains** is an unsplicable component which was added as part of the Night of the Sewing Dead update. One can be obtained from double-tapping 100 Zombie Brains in one's inventory.
##  Function
A Pile of Zombie Brains, which has the same value as 100 Zombie Brains, can be exchanged for items with the Sales-Man.
