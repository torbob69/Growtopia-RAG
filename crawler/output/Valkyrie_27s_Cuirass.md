**Valkyrie's Cuirass** is an unsplicable shirt item which was added as part of Player Appreciation Week 2019 Day 4 on August 22, 2019.
##  Function
When equipped, the Valkyrie's Cuirass serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Valkyrie set, which consists of the following items:

    * Valkyrie's Helm (hat)

    * Valkyrie's Cuirass (shirt)

    * Valkyrie's Sandals (feet)

    * Valkyrie's Wings (back)
