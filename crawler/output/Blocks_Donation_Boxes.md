# Blocks/Donation Boxes

< Blocks
**Donation Boxes** are solid foreground blocks which when wrenched, players can donate any item that is tradeable or has a rarity higher than one. A donation box can fit up to 20 stack of items.
**Donation Boxes**

Item: Description
Donation Box: People can drop gifts into this box for you to pickup later!
Donut Donation Box: People can drop gifts into this box for you to pickup later!
Holiday Gift Box: People can drop gifts into this box for you to pickup later!
