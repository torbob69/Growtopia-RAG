The **Giant's Causeway Block** is an unsplicable solid foreground block which was added as part of St. Patrick's Week 2018.
##  Function
When placed, the Giant's Causeway Block serves a purely aesthetic purpose.
##  Trivia
  * The Giant's Causeway Block is based on the Giant's Causeway, an actual area in Northern Ireland.
