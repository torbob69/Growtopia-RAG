**Armored WinterBot - Fists** is an unsplicable hand item which was added as part of WinterFest 2019.
##  Function
Freezing fists!

Your hands slowly thaw!

When equipped, the **Armored WinterBot - Fists** grants the _Punch Damage: Armored WinterBot - Fists_ mod, which allows the player to break blocks faster and transform into the Armored WinterBot when the entire Armored WinterBot set is equipped.
##  Trivia
  * This item is considered a part of the Armored WinterBot set, which consists of the following items:

    * Armored WinterBot - Back (back)

    * Armored WinterBot - Mail (shirt)

    * Armored WinterBot - Greaves (pants)

    * Armored WinterBot - Feet (feet)

    * Armored WinterBot - Fists (hand)
