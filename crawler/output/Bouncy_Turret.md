# Bouncy Turret

Build your own bouncy obstacle course with these inflatable turrets.
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.
Data: Paint PreviewType — Bouncy Block – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Vertical
Collision Type: Collision on top
Hardness: **6 Hits** **5 Hits** – Restores after **3s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Combination

In any Chemical Combiner, mix together...
Deck Chair **(×5)** ,
Water Bucket **(×5)** and
Beach Blast **(×1)**.
This recipe will yield **3** items.
The **Bouncy Turret** is an unsplicable solid bouncy foreground block which was added as part of SummerFest 2023 on July 13, 2023.
##  Function
Being a type of bouncy block, a Bouncy Turret will actively push away any player it collides with.
