# Ghost Charm

When activated (punch to activate), this horrific face terrifies even ghosts, preventing new ghosts from appearing in your world. Ghosts that are already in your world still need to be captured by B.O.O. professionals, however. The poor ghosts are trapped on this earthly plane!
Properties
This item never drops any seeds.
This item can only be used in World-Locked worlds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item has special properties you can adjust with the Wrench.

The **Ghost Charm** is an unsplicable solid jammer foreground block which was added as part of the Battlers Of the Otherworldly update on July 15, 2016.
##  Function
When turned on, it blocks ghosts from spawning due to world inactivity, prevents players using Ghost-In-A-Jars in the world and blocks ghosts from spawning in while harvesting tree's during Harvest Festival. It does not remove existing ghosts.
##  Trivia
  * Obtaining a Ghost Charm from a Spirit Storage Unit for the first time will complete an Epic Quest.
