# Rotten Woodland Tree

A venerable giant of the forest has fallen! This once-towering tree took a tumble some time ago, and has already begun its return to the earth. Take a tour inside to see the cycle of life up close!
Properties

The **Rotten Woodland Tree** is an unsplicable platform foreground block which was added as part of Winter Clash 2018.
##  Function
A Rotten Woodland Tree behaves as a platform, thus a player can jump pass through it from underneath.
