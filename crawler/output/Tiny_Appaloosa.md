# Tiny Appaloosa

It's possible this is actually a dalmation, but you can still ride it! It's faster than walking.
Properties
This item never drops any seeds.
Data

Type: Feet – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Tiny Horsie **(×1)** ,
Polka Dot Block **(×20)** and
Transmog Crystal **(×1)**.
This recipe will yield **1** item.
The **Tiny Appaloosa** is an unsplicable feet item.
##  Function
You can move fast!

You are slow again.

When equipped, the **Tiny Appaloosa** grants the _Speedy_ mod, which allows the player to move faster on land.
