# Mega-Pellet Bait

Attract frosty fish! Equip a fishing rod and then use this bait in nearby ice water to start fishing. The icy shimmer of this bait will catch unique fish that other lures can't entice!

The **Mega-Pellet Bait** is an unsplicable consumable which was added as part of the Gone Fishin'! update.
##  Function
The Mega-Pellet Bait can only be used in a hand-drilled Ice Crust Block with water on top. Items which can be caught with one include:
  * Aqua Cave Crystal
  * Alpha Great White Shark
  * Cooler Box
  * Cuttlefish
  * Absolutely Real Elephant Fish
  * Davy Jones' Chest
  * Fancy Fish Wall Mount
  * Ice Crust Block
  * Mega-Pellet Bait
  * Puffer Fish Block
  * Sea Urchin
  * Super Duper Ice Cream Scooper (SummerFest only)
  * Queen Conch Shell
  * Whizmo Gizmo
