# Legendary Clash Key - Series 5

A key to a mysterious treasure! This key is for Clash Series 5, running from Summer Clash 2022 through Spring Clash 2023. After three seasons, those who collect at least 10 of these keys will be able to open a special treasure chest. Make sure you have enough - just one won't do it!
Properties
This item cannot be dropped or traded.
This item never drops any seeds.
This item has no use... by itself.

**1h**
**Legendary Clash Key - Series 5** is an unsplicable component that was added on July 7, 2022. It can be obtained after completing a branch which can be found by tapping on the Leaderboard Button and tapping on "Summer/Winter/Spring Clash Rewards". The player needs to buy everything in the branch before receiving the Legendary Clash Key & Finale Ticket in the event span from Summer 2022 to Spring 2023.
##  Function
One needs to collect 10 **Legendary Clash Key - Series 5** throughout all the Seasonal Clashes to be able to claim Oldsock's Old Mate Ricky during Spring Clash 2023.
