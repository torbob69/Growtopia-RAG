The **Steam Revolver** is a non-solid block which was added as part of the Artsy April update on April 2, 2016.
##  Function
The Steam Revolver automatically generates steam inside Steam Tubes (or any Steam Block which steam can travel through) which are connected to it after a player passes through it.
