The **Scarabslushie Suit** is an unsplicable shirt item which was added as part of Halloween Week 2024 on October 24, 2023.
##  Function
When equipped, the Scarabslushie Suit serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Scarabslushie set, which consists of the following items:

    * Scarabslushie Face Paint (face)

    * Scarabslushie Hair (hair)

    * Scarabslushie Suit (shirt)
  * The full Scarabslushie set is a reference to a fictional character called Beetlejuice, from a movie of the same name.
