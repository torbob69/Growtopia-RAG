# DNA Processor

This advanced device from Growtech can take in strands of ancient DNA and combine them to create real living creatures. It has terrifying ethical implications.

This item can be placed in two directions, depending on the direction you're facing.

The **DNA Processor** is an unsplicable non-solid foreground block which was added in the Growassic Park update.
##  Function
A player can use a DNA Processor to create various types of dinosaurs and prehistoric plants. Each item made using a DNA Processor requires a specific combination of three DNA strands.
##  Trivia
  * As part of the Quality of Life Changes update on May 20, 2022, the DNA Processor is no longer placeable in public worlds or worlds the player is only an admin in.
