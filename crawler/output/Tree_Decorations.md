# Tree Decorations

All sorts of baubles and gewgaws to adorn your Giving Tree in true Winterfest style! One decoration won't do much, but you can toss up to 100 decorations on each tree! More decorations will logically result in better gifts, but taking the gift will remove all the decorations with it!

The **Tree Decorations** is an unsplicable consumable which was added as part of WinterFest 2015.
##  Function
Tree Decorations can be obtained by performing any of the following activities:
  * 1-4 can be obtained by successfully performing surgery.
  * 1-3 can be obtained from crimefighting:
    * 1 is obtained from defeating villains.
    * 2 is obtained from defeating masterminds.
    * 3 is obtained from defeating supervillains.
  * 1 can be obtained from Fishing.
  * Up to 20 can be obtained from completing a WOLFWORLD.
  * 1 can be obtained using a Geiger Counter.
  * 5 can be obtained from consuming a Winterfest Cracker.

Tree Decorations are used on Giving Trees. Using one on a Giving Tree will raise the decorated percentage of the Giving Tree by 1. Different amounts of decorations can give different rewards.
