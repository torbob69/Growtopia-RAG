The **Cute Bonnet** is an unsplicable hat item which was added as August 2024's Monthly Subscriber's Item on August 1, 2023.
##  Function
When equipped, the Cute Bonnet serves a fully cosmetic purpose.
##  Trivia
  * The Cute Bonnet is a reference to a mob cap worn by Remilia Scarlet and Flandre Scarlet, characters from a bullet hell shoot 'em up video game series, Touhou Project.
