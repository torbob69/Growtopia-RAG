# Dark King's Offering

An offering fit for a king or a demon!
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: No Collision
Hardness: **10 Hits** **8 Hits** – Restores after **15s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Spooky Box **(×1)** ,
Spooky Gift **(×1)** and
Spooky Rags **(×1)**.
This recipe will yield **1** item.
The **Dark King's Offering** is an unsplicable component which was added as part of Halloween Week 2020 on October 22, 2020.
##  Function
When dropped into the Maw of Growganoth, it will award the player any new and existing dark conversion item. A system message will be broadcast which can be seen by all players if the player gets a rare conversion item which says _Growganoth honors <player's name> with a Rare <item name> for their Dark King's Offering_.      _Main article:Growganoth_
As of Halloween Week 2021, it also drops exclusive items, they include:
  * Zombie Horse
  * Dark King's Crown (During Frightening Fridays only!)
  * Pumpkin Carriage (During Frightening Fridays only!)

##  Gallery

Broadcast when a player gets a rare item from sacrificing a Dark King's Offering.
