# Chemical Combiner (block category)

A **Chemical Combiner** is a type of foreground block which can be punched to be opened or closed. When opened, the chemical combiner will act as a non-solid block, and sets of three ingredients can be dropped and punching it will create a new item if the recipe is valid. When closed, nobody can see or access the items, and the chemical combiner will become a solid block.
##  List of Chemical Combiners
Items: Special FunctionBarbecue Grill: Cooking a Cheeseburger in a Barbecue Grill will grant you the _Summer Grillin'_ Achievement.
E-Z Cook Oven: It's used to create the S'mores Block.
Laboratory: It's used to create Jelly Blocks.
Microwave: It's used to create the Chocolate Sprinkles Block.
Vehicle Replicator: It's used to create The Runaway and the Class D Loader.
