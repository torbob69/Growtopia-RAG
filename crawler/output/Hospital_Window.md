The **Hospital Window** is an unsplicable background block which was added as part of the Growtopia General Hospital update on November 22, 2013.
##  Function
When placed, the Hospital Window serves a purely aesthetic purpose.
##  Trivia
  * As part of the Block Party 2 update, the quantity of Hospital Windows obtained from surgery was increased from 1 to 5.
