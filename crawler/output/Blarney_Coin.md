The **Blarney Coin** is an unsplicable component which was added as part of St. Patrick's Week 2025 on March 14, 2025.
##  Function
Blarney Coin can be used to create Blarney Bonanza items by combining 10 of itself with an Emerald Shard and a random colored block, which is specific to each Blarney Bonanza item.
