# Wool

This is just a blob of wool. Not too useful. Get 100 of these to weave a bolt together!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **4 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Provider

| Drops in sets of **1-3** from harvesting a/an:
Sheep
Using a  Sheep Shears doubles the drop.   |
**Wool** is a consumable which was added as part of Harvest Festival 2016 on September 15, 2016.
##  Function
Consuming 100 of this item will make a Wool Bolt, which is used in sewing.
