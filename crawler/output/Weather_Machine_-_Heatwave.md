# Weather Machine - Heatwave

This amazing new weather machine emits a vortex of howling flame, but if you wrench it, you'll find adjustable settings to control the color of the flames! You can only have one of these per world.
Properties
This item never drops any seeds.

The **Weather Machine - Heatwave** is an unsplicable non-solid weather machine foreground block which was added as part of SummerFest 2016 on June 30, 2016.
##  Function
A Weather Machine - Heatwave features a hazy weather whose RGB values can be customized by any player with access to the tile it is placed on.
##  Trivia
  * Around 16,581,375 (255x255x255) combinations of colors are possible to be created with a Weather Machine - Heatwave.
    * It is impossible to make a completely black color with one.
  * When starting the Startopia voyage "Weird Contraption", the weather will change into a vibrant pink heatwave. After the mission ends, the weather will go back to normal.
