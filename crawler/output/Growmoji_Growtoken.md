# Growmoji Growtoken

Brighten up your chat with a rare and wonderful Growtoken! Just consume this to add it to your available growmojis!
Properties
A tree of this type can bear surprising fruit!
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Growtopia Store

Purchase the **Growmojis** for **15 ** in the Growtopia Store.
"Express yourself! This mysterious box contains one of five fun growmojis you can use to spice up your chat! Which will you get?"
Every purchase has a chance of giving **1** item.
The **Growmoji Growtoken** is an unsplicable Growmoji item which was added as part of March Update on March 1, 2018.
##  Function
When consumed, the player will be able to use the (gtoken) Growmoji.
