The **Ultra Spring Flinger Frog Suit** is an unsplicable shirt item which was added as part of Spring Clash 2019 on March 1, 2019.
##  Function
When equipped, the Ultra Spring Flinger Frog Suit serves a fully aesthetic purpose. This item features an item animation, unlike the Spring Flinger Frog Suit.
