The **Phlogiston** is an unsplicable hand item which was added as part of the Pet Battles update on June 11, 2016.
##  Function
You're fired!

You're cooling off

When equipped, the **Phlogiston** grants the _Flame On!_ mod, which allows the player to punch one tile further. It will also summon a pet Phlogiston which replaces the player's punching animation with rainbow flames fired from the pet.
