# Missing Game Flag

This flag has been taken. It will return when the Game is over.
Properties
This item never drops any seeds.
This item cannot be dropped or traded.
This item has special properties you can adjust with the Wrench.

This item does not have any recipe because it is no longer, or was never obtainable.
The **Missing Game Flag** is an unobtainable non-solid foreground block which was added alongside the Game Pack on July 25, 2014.
##  Function
It is seen when a player collects the flag during the game and what is left behind is the Missing Game Flag.
