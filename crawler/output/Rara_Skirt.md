# Rara Skirt

You'll be a "rara" beauty when you don this skirt! Who can resist those colors?
Properties
This item never drops any seeds.
Data

Type: Pants – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Blue.
Sew a  Silk Bolt - Blue to the previous bolt using a(n) **Saddle Stitch**.
Lastly, sew a  Silk Bolt - Purple to the previous bolt using a(n) **Blind Stitch**.
Each recipe gives **1** item.
The **Rara Skirt** is an unsplicable pants item which was added as part of Player Appreciation Week 2018 Day 3 on August 8, 2018.
##  Function
When equipped, the Rara Skirt serves a fully cosmetic purpose.
