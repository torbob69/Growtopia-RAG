The **Freedom Fighter Uniform** is an unsplicable shirt item which was added as part of Thanksgiving Week 2025 on November 20, 2025.
##  Function
When equipped, the **Freedom Fighter Uniform** serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Freedom Fighter set, which consists of the following items:

    * Freedom Fighter Helmet (hat)

    * Freedom Fighter Uniform (shirt)
  * The Freedom Fighter Uniform is a reference to the clothing worn by the fictional superhero Captain America.
