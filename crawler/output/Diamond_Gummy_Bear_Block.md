The **Diamond Gummy Bear Block** is an unsplicable solid foreground block which was added as part of Pre-WinterFest 2025 on December 1, 2025.
##  Function
When placed, the Diamond Gummy Bear Block serves a purely aesthetic purpose.
##  Trivia
  * The  Diamond Gummy Bear Block is a recolor of the  Gummy Bear Block - Red,  Gummy Bear Block - Yellow, and  Gummy Bear Block - Green.
