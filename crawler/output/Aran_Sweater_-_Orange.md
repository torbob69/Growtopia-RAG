# Aran Sweater - Orange

Wear this traditional orange sweater.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Red.
Sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Overcasting Stitch**.
Lastly, sew a  Silk Bolt - White to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **Aran Sweater - Orange** is an unsplicable shirt item which was added as part of St. Patrick's Week 2023 on March 17, 2023
##  Function
When equipped, the Aran Sweater - Orange serves a purely cosmetic purpose.
