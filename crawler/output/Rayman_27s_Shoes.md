The **Rayman's Shoes** is an unsplicable feet item which was added as part of the Rayman update on January 1, 2018.
##  Function
When equipped, the **Rayman's Shoes** serves a purely cosmetic purpose. However, equipping the entire Rayman set will transform the player into the Rayman.
##  Trivia
  * This item is considered a part of the Rayman set, which consists of the following items:

    * Rayman's Hair (Hair)

    * Rayman's Nose (Face)

    * Rayman's Hoodie (Shirt)

    * Rayman's Shoes (Feet)

    * Rayman's Fist (Hand)
