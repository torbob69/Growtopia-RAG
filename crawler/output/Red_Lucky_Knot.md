# Red Lucky Knot

Add luck around you with this Red Lucky Knot, a beautifully woven symbol of good fortune and harmony.
Properties
This item never drops any seeds.
Data: Paint PreviewType — Foreground Block – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **3s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Red.
Sew a  Silk Bolt - Black to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Blind Stitch**.
Each recipe gives **15** items.
The **Red Lucky Knot** is an unsplicable foreground block which was added as part of Lunar New Year 2025 on January 23, 2025.
##  Function
When placed, the Red Lucky Knot serves a purely aesthetic purpose.
