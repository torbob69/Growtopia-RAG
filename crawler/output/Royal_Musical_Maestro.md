The **Royal Musical Maestro** is an unsplicable chest item which was added as November 2024's Item Of The Season on November 1st, 2024.
##  Function
Precise DJ!

How the turntables...

When equipped, the **Royal Musical Maestro** grants the _Punch Range: Royal Musical Maestro_ mod, which allows the player to punch one tile further.
The Royal Musical Maestro features special customizable functions. The player can set a music by wrenching oneself. To set the music for the Royal Musical Maestro, the player can select any musical block from the inventory and punching or dancing would play the selected music on loop. However, only the player themselves can hear the music being played.
