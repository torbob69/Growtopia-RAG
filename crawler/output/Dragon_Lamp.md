# Dragon Lamp

The only safe way to light up a room with a dragon (all other ways seem to involve fire - lots and lots and lots and lots of fire)!
Properties
This item has special properties you can adjust with the Wrench.
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

This recipe will yield **1** item.
The **Dragon Lamp** is an unsplicable non-solid toggleable foreground block which was added in the Dragon Invasion update.
##  Function
When placed, being a toggleable animated foreground block, a _Dragon Lamp_ can be toggled on or off via punching. When toggled on, a Moon Lamp will change its appearance, showing the _Dragon Lamp_ lit up. It also functions as a light source, emitting light in dark areas.
