# Cactus Cannon

A cactoid cannon! Probably best to use this with some very thick gloves otherwise you might end up covered in spiky cactus spines!

The **Cactus Cannon** is an unsplicable hand item which was added as part of Cinco De Mayo Week 2021 on May 5, 2021.
##  Function
Get ready to get spiky!

Much less chance of a splinter now!

When equipped, the **Cactus Cannon** grants the _Punch Range : Cactus Cannon_ mod, which allows the player to punch one tile further. Additionally, punching another player/block with the item equipped will cause the target to be wrapped around with prickly thorns.
##  Trivia
  * This item is considered a part of the Cactus set, which consists of the following items:

    * Cactus Hat (Hair)

    * Cactus Onesie (Shirt)

    * Cactus Cannon (Hand)
