The**Challenge Board** is an unsplicable non-solid foreground block which was added as part of the Daily Challenges update on November 18, 2015.
##  Function
The Challenge Board can be accessed by using the Wrench.
The information that a Challenge Board provides once wrenched
Upon wrenching, the player will be able to see:
  * **The timing of the next Daily Challenge.**
  * **The last Daily Challenge that took place.**
  * **Top 5 players of the last Daily Challenge.**

While a challenge is in progress, the Challenge Board will display information about the current challenge such as how it is scored, and be updated every 20 seconds to show how many points the top 5 players have.
