The **Weather Machine - Celebrity Hills** is an unsplicable non-solid weather machine foreground block which was added as part of Thanksgiving Week 2020.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, transforming the world's background weather into a Hollywood-like scenery.
##  Trivia
  * As of Thanksgiving Week 2022, the Weather Machine - Celebrity Hills can no longer be purchased from the Store for 30,000 gems each and became a prize from breaking Organic Turkeys.
  * The Weather Machine - Celebrity Hills' store description used to be "_It's Thanksgiving in Growtopia! Celebrate in Celebrity Hills where dreams are made! This weather machine will let everyone know how glamorous you are! It's a perma-item, is never lost when destroyed._ "
  * The Weather Machine - Celebrity Hills' appearance is based on the Hollywood Sign located at Los Angeles, California, U.S.A.
