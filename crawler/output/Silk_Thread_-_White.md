# Silk Thread - White

A single thread isn't very useful. Get 100 of these to stitch a bolt together!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **4 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**

Silkworm **(**white**)**  |
**Silk Thread - White** is an unsplicable consumable which was added as part of the Silkworms! update on February 1, 2016.
