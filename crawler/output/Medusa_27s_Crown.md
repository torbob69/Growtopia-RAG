The **Medusa's Crown** is a hat item which was introduced as February's Item Of The Month for 2020.
##  Function
Medusa's Crown effect: On

Medusa's Crown effect: Off

When equipped, the **Medusa's Crown** grants the _Medusas's Gaze_ mod, which allows the player to turn punched players into Pet Rocks. This effect will only work if there is no active Punch Jammer present in the world.
##  Trivia
  * Medusa's Crown is a reference to Medusa who is an iconic figure from the Greek Mythology.
