The **Operating Theater Lamp** is an unsplicable toggleable animated foreground block which was added as part of the Role Up! update.
##  Function
Being a toggleable animated foreground block, an Operating Theater Lamp can be toggled on or off via punching. When toggled on, an Operating Theater Lamp will change its appearance, showing the lamp being lit up. As a light source, an Operating Theater Lamp emits light in dark areas.
