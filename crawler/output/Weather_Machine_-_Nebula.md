The **Weather Machine - Nebula** in an unsplicable non-solid weather machine foreground block which was added as part of Star Trek Prodigy on June 27, 2022.
##  Function
As a weather machine, this item can be can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into a galactic scenery.
