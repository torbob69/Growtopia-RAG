# Blue Rose Bowler Hat

Eradicate that jinx of yours with the Blue Rose Bowler Hat.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Aqua.
Sew a  Silk Bolt - Blue to the previous bolt using a(n) **Straight Stitch**.
Lastly, sew a  Silk Bolt - Red to the previous bolt using a(n) **Zigzag Stitch**.
Each recipe gives **1** item.
The **Blue Rose Bowler Hat** is an unsplicable hat item which was added as part of Player Appreciation Week/2026 on August 24, 2026.
##  Function
When equipped, the **Blue Rose Bowler Hat** serves a purely cosmetic purpose.
##  Trivia
  * The Blue Rose Bowler Hat is based on the character Rice Shower from the Japanese multimedia franchise Umamusume: Pretty Derby.
    * The item description also references the character supposedly bringing misfortune on others, when it's really bad timing.
