# WOLFWORLD Rewards

This page contains an updated list of all **WOLFWORLD rewards**. The list is sorted by rarity.
##  Wolf Ticket
Upon completing any WOLFWORLD, the player will receive a Wolf Ticket. These Wolf Tickets can be traded in with the Sales-Man for various WOLFWORLD rewards. 100 Wolf Tickets can be compressed into an Enchanted Wolf Ticket.
