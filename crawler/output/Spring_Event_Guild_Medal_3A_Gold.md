# Spring Event Guild Medal: Gold

Awarded for achieving FIRST PLACE in the Guild Leaderboards during the Spring season. Show off your victory by placing this medal in your world, and congratulations!
Properties
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item cannot be dropped or traded.
This item never drops any seeds.

Spring Event Guild Medal: Gold

1 is awarded to the Guild Leader for the Guild being the first in a Spring Grow Event
The **Spring Event Guild Medal: Gold** is an unsplicable platform foreground block which was added as part of Spring Clash 2019. It is given to the Guild Leader for achieving 1st place in a Spring Grow Event.
##  Function
A Spring Event Guild Medal: Gold behaves as a platform, thus a player can jump pass through it from underneath.
