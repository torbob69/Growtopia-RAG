# Harmony Mooncake

This pastry is filled with a sweet bean paste. "Harmony" is imprinted on the top in ancient Growtopian script. Mix this with other Mooncakes in a Laboratory or E-Z Cook Oven to create special Harvest Festival items.
Properties
This item never drops any seeds.

The **Harmony Mooncake** is an unsplicable Mooncake consumable which was added as part of Harvest Festival 2013 on September 18, 2013.
##  Function
When consumed, the player will say "YUM!" and do the :D ⦅⦆ emote.

### Silkworm Food     _Main article:Guide:Silkworm Care_
This consumable can be fed to a Silkworm to give it a yellow color, thus allowing it to produce 1–10  Silk Thread - Yellow per harvest.
##  Trivia
  * The higher a tree's rarity is, the more likely it is for the tree to drop a Mooncake.
