The **Heavy Artillery** is an unsplicable back item which was added as part of Wonder Week 2025 - Day 3 on October 8, 2025.
##  Function
Locked on target!

Mayday!

When equipped, the **Heavy Artillery** grants the _Double Jump + Punch Range : Heavy Artillery_ mod, which allows the player to jump a second time in mid-air and punch one tile further.
##  Trivia
  * This item is considered a part of the Heavy Artillery set, which consists of the following items:

    * Heavy Artillery (Back)

    * Heavy Artillery Armor (Shirt)
