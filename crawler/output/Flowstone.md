# Flowstone

Let it flow! Let it flow! Let it flow!
Properties
This item never drops any seeds.
Data: Paint PreviewType — Slippery Block – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single

Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Special Event

Found in the _Hidden In Plain Sight!_ special event.
One has 90 seconds to locate a randomly spawned block and punch it for a prize.
The **Flowstone** is an unsplicable foreground block which was added as a part of Player Appreciation Week 2025 on September 18, 2025.
##  Function
A Flowstone behaves as a platform, thus a player can jump pass through it from underneath. In addition, being a slippery block, walking on a Flowstone causes the player to slide.
