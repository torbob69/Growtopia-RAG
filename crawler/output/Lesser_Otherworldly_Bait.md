# Lesser Otherworldly Bait

This is bait for fishing. Equip a fishing rod and then use this bait on water that you are standing next to in order to start fishing. This bait actually travels through a wormhole into a dark dimension and catches things there, instead of in the water. Lesser bad things.
Properties
This item never drops any seeds.
