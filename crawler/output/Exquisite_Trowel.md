The **Exquisite Trowel** is an unsplicable hand item which was added in the Summer Clash update.
##  Function
Exquisite building skills.

Not so exquisite building skills anymore.

When equipped, it grants the _Build Range: Exquisite Trowel_ mod which allows the player to build one tile further.
