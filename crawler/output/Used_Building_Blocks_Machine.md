Created in the place of a  Building Blocks Machine which has reached its time limit of 10 days.
The **Used Building Blocks Machine** is an unsplicable non-solid foreground block which was added as part of the Block Party 2 update on April 1, 2019.
##  Function
When placed, the Used Building Blocks Machine serves a purely aesthetic purpose.
##  Trivia
  * Prior to the Pre-WinterFest 2020 update, the Used Building Blocks Machine was a permanent item which would always return to the player's inventory when broken.
    * The item's permanent status was revoked in order to prevent trade scams.
  * A Used Building Blocks Machine can now only be obtained by using a Flashback Flan on a Building Blocks Machine.
