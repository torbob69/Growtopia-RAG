# Stone Pagoda Roof Element

Stick this at the ends of your pagoda roofs. It doesn't serve any functional purpose, but it sure looks nice. Just make sure you put it the right way or it'll be floating in midair.
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.
