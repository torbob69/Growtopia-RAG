The **Golden Treasure Hoard** is an unsplicable non-solid treasure foreground block which was added as part of the Spelunkorama! update.
##  Function
When broken, a Golden Treasure Hoard may drop one of the following:
  * Gems (usually about 50-500)

  * Crystal Block
  * Eldritch Eyes
  * Emerald Block
  * Golden Apple
  * Golden Cave Crystal
  * Golden Cuff Beard
  * Old Rocker Hair ×1
  * Pet Moyaimorph ×1
  * Ruby Block
  * Sapphire Block
  * Spelunker's Headlamp
  * Topaz Block
