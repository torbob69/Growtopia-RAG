# Enchanted Spatula

This mythical artifact, possibly from the future, has an unparalleled magical power: you can slap objects with it to turn them around. Use it on chairs, beds, whatever you find facing the wrong way! Note: Because the spatula is crystal, it shatters when used.
Properties
This item never drops any seeds.

The **Enchanted Spatula** is an unsplicable consumable which was added Player Appreciation Week 2015 Day 1.
##  Function
When used on an eligible block, it flips the direction the item is facing. Unlike the Superb Chef's Super Spatula, it breaks upon usage.
