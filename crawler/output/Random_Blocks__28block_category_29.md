# Random Blocks (block category)

A **random block** is a type of solid foreground block which yields a random result when punched.
##  List of Random Blocks
Items: Special FunctionDice Block: When punched, it will randomly display numbers from 1-6.
Roshambo Block: When punched, it will randomly display a rock, paper, or scissors icon.
