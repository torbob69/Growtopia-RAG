The **Scarlet Rider's Bike** is an unsplicable feet item which was added as part of Garuda's Glory 2023 on August 17, 2023.
##  Function
Henshin!

Powered Down!

When equipped, the **Scarlet Rider's Bike** grants the _Speedy : Scarlet Rider's Bike_ mod, which allows the player to move faster on land.
##  Trivia
  * This item is considered a part of the Scarlet Rider set, which consists of the following items:

    * Scarlet Rider's Mask (Hat)

    * Scarlet Rider's Armor (Shirt)

    * Scarlet Rider's Pants (Pants)

    * Scarlet Rider's Boots (Shoes)

    * Scarlet Rider's Bike (Feet)
  * The Scarlet Rider set is a reference to Kuuga, a superhero character from the Japanese television series Kamen Rider.
