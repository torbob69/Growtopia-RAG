# Magical Captain's Compass

Use this magical compass on yourself to command your ship to change form!
Properties
This item cannot be dropped or traded.
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **2 Hits** **2 Hits** – Restores after **2s** of inactivity
Gems Drop: **N/A**
**1h**
**Magical Captain's Compass** is an unsplicable consumable that was added on February 1, 2021, it comes with equipping the Perilous Pirate Ship.
##  Function
When consumed, the player will be wearing the Perilous Pirate Ship. Consume again to turn back the Perilous Pirate Ship into a flying ship that follows the player around.
