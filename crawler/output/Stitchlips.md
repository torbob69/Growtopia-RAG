The **Stitchlips** is an unsplicable face item that was added as part of the Blocktor's Orders! update.
##  Function
Lips stitched! No talking!

Ahh... Lips unstitched!

When equipped, this item grants the _Muted by stitches!_ mod to the player, which will mute the player, changing the player's text to _mfmfffm_ s similar to Duct Tape.
