# Smoke Machine

Have you ever wanted to cover the world in grey? well now you can with this fancy Smoke Machine!
Properties
This item has special properties you can adjust with the Wrench.
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

Mining

1 has a chance to be dropped from exploding  Pure Magic Ore using  Mining Explosives, which are naturally generated in mines.
Player Appreciation Week Bingo

**1** may be obtained upon completing a row or column on a Player Appreciation Week Bingo card.
The **Smoke Machine** is an unsplicable non-solid foreground block which was added as part of Player Appreciation Week 2021 Day 1 on August 23, 2021.
##  Function
When placed, being a toggleable animated foreground block, a _Smoke Machine_ can be toggled on or off via punching. When toggled on, a _Smoke Machine_ will change its appearance, showing smoke being created by the machine.
