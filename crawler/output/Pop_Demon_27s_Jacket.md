The **Pop Demon's Jacket** is an unsplicable shirt item which was added as part of Halloween Week 2025 on October 23, 2025.
##  Function
When equipped, the **Pop Demon's Jacket** serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Pop Demon's set, which consists of the following items:

    * Pop Demon's Hair (hair)

    * Pop Demon's Face Patterns (face)

    * Pop Demon's Jacket (shirt)

    * Pop Demon's Shorts (pants)

    * Pop Demon's Riding Tiger (feet)

    * Pop Demon's Arm Patterns (hand)
  * The full Pop Demon set is a reference to a fictional character called Rumi, from the movie KPop Demon Hunters.
