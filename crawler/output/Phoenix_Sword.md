The **Phoenix Sword** is an unsplicable hand item which was added as part of SummerFest 2018 on July 6, 2018.
##  Function
Flaming blades of fury!

The flames subside, but it will live again!

When equipped, the **Phoenix Sword** grants the _Phoenix Sword_ mod, which allows the player to break blocks faster.
##  Trivia
  * Phoenix Sword is the fifth Summerfest Phoenix item to be added in Growtopia, with Phoenix Crown, Riding Phoenix, Phoenix Pacifier, and Phoenix Wings as the previous ones.
