The **Minecart** is an unsplicable feet item which was added as part of The Adventure Pack Strikes Back! update on June 1, 2017.
##  Function
You can move faster!

You are slow again.

When equipped, the **Minecart** grants the _Speedy_ mod, which allows the player to move faster on land.
