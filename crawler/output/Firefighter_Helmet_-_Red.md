The **Firefighter Helmet - Red** is an unsplicable head item that was added alongside Firefighter Pack on October 8, 2015.
##  Function
When equipped, the Firefighter Helmet - Red serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the red firefighter set, which consists of the following items:

    * Firefighter Helmet - Red (hat)

    * Oxygen Mask (face)

    * Firefighter Jacket - Red (shirt)

    * Firefighter Pants - Red (pants)

    * Fire Hose (hand)

    * Fire Ax (hand)

    * Firefighter Boots (feet)
  * The  Firefighter Helmet - Red is a recolor of  Firefighter Helmet - Yellow.
