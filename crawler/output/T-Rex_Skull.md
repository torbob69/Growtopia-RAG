Process  Fossils or  Polished Fossils in a  Fossil Prep Station.
The **T-Rex Skull** is an unsplicable platform foreground block item which was added in the Growassic Park update. One has a chance to be obtained from processing a Fossil in a Fossil Prep Station.
##  Function
A T-Rex Skull behaves as a platform, thus a player can jump pass through it from underneath.
A T-Rex Skull can be used in a DNA Extractor in order to obtain a DNA Strand.
