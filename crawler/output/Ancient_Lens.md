# Ancient Lens

Forged with long-lost sorceries, this glass remains unscratched after untold centuries! What could it reflect? Peer through it and into a time long past...
Properties
This item never drops any seeds.
This item has no use... by itself.

Combination

In any Chemical Combiner, mix together...
Wind Asteroid **(×2)** ,
Earth Asteroid **(×2)** and
Wind Essence **(×5)**.
This recipe will yield **1** item.
The **Ancient Lens** is an unsplicable component which was added as part of the Hidden Riches update on September 1, 2017.
