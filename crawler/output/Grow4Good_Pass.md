# Grow4Good Pass

The **Grow4Good Pass** is a store pack which was added as part of Grow4Good Week on April 15, 2021. It will give the player a Grow4Good Pass that gives access to earn exclusive rewards.
Growtopia Store

Purchase the **Grow4Good Pass** for **14.99 USD** in the Growtopia Store.
"Grow4Good Pass gives access to earn exclusive rewards when you progress in the Grow4Good Global Milestones. Grow4Good Pass Members will also receive bonus rewards to be claimed when earning Grow4Good Points for all Personal Contributions. Also includes a Rare Gumball Machine that dishes out Bubble Gum once a day is very nice!"
Every purchase will give **1** item.

The 2026 version of the Grow4Good Pass contains the following items:
