# One Side Collision Block (block category)

A **one side collision block** is a type of foreground which restricts the player from passing the block in a certain direction.
##  List of Horizontal One Side Collision Blocks
Items: Special FunctionOne-Way Block: This item can be placed in two directions.
##  List of Vertical One Side Collision Blocks
