# Engineer's Goggles

A pair of goggles made for engineers!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Face – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Mining

1 has a chance to be dropped from exploding  Pure Magic Ore using  Mining Explosives, which are naturally generated in mines.
The **Engineer's Goggles** is an unsplicable face item which was added as part of Player Appreciation Week 2023 Day 5 on September 1, 2023.
##  Function
When equipped, the Engineer's Goggles serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Engineer set, which consists of the following items:

    * Engineer's Helmet (hat)

    * Engineer's Goggles (face)
  * The full Engineer set is a reference to the Engineer, whose real name is Dell Conagher, from Valve's first-person shooter game Team Fortress 2.
