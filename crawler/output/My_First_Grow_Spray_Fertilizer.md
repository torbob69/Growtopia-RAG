The **My First Grow Spray Fertilizer** is an unsplicable consumable which was added on January 31, 2021.
##  Function
My First Grow Spray Fertilizer has the appearance and function of a Grow Spray Fertilizer, except that it is untradable to prevent players from creating multiple accounts to obtain them. Unlike the latter, My First Grow Spray Fertilizer cannot be used in Vending Machines.
