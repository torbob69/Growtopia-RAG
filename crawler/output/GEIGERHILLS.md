# GEIGERHILLS

##  Overview
The world GEIGERHILLS is a world used for finding Uranium Blocks using a Geiger Counter. This world was added during Cinco De Mayo Week 2017. The world is owned by @Hamumu, and like CARNIVAL, there are many worlds. (GEIGERHILLS_2, GEIGERHILLS_3, etc.) This world is also the area for the Radiation Race, a Daily Challenge, where the top three players who finds the most Uranium Blocks in GEIGERHILLS wins a Uranium Necklace. The world has an arid background, clouds, tree-like structures, and wooden-hill-like structures. Note that finding Uranium Blocks here uses the same technique of finding items with a Geiger Counter, but upon finding a Uranium Block, the Geiger Counter does not need to be recharged.
##  Trivia
  * Using the Geiger Counter in GEIGERHILLS will not count towards challenges, quests, Cazy Jim, and so on. A quest like "Find __ radioactive items with a Geiger Counter" will not progress as you find Uranium Blocks in the world.
