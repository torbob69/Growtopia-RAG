The **Wujing's Beads** is an unsplicable chest item which was added as part of Lunar New Year 2023 on January 21, 2023.
##  Function
Focused Minds!

Distractions!

When equipped, the **Wujing's Beads** grants the _Build Range: Wujing's Beads_ mod, which allows the player to build one tile further.
