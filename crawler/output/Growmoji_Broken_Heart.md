# Growmoji Broken Heart

Oh no! If something's gone wrong at heart, you can let your friends know with this growmoji - and we hope things get better soon! Just consume this to add it to your available growmojis!
Properties
A tree of this type can bear surprising fruit!
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
The **Growmoji Broken Heart** is a Growmoji that was released as part of the March Update. One is obtained through a special event.
##  Trivia
  * This item also serves as an image placeholder for the Broken Heart malady on Auto Surgeon Stations.
