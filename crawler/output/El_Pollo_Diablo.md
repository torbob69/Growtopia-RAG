The **El Pollo Diablo** is an unsplicable feet item which was added as part of the Halloween Week 2017 update on October 30, 2017.
##  Function
You can move faster!

You are slow again.

When equipped, the **El Pollo Diablo** grants the _Speedy_ mod, which allows the player to move faster on land. When the player jumps while equipping one, a clucking sound can be heard.
