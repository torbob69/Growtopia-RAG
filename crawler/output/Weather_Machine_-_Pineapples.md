# Weather Machine - Pineapples

It's rare, but sometimes you'll see the little pineapple alert on your weather app. When you do, be sure to get under cover - an umbrella is not going to protect you! This sensitive technology will not function while damaged.
Properties
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item never drops any seeds.

The **Weather Machine - Pineapples** is an unsplicable non-solid weather machine foreground block which was added as part of Super Pineapple Party 2015 on May 30, 2015.
##  Function
When activated by punching, it turns a world's background into a sky with a yellow background with falling Pineapples.
