# Eldritch Crossbow

A mysterious Eldritch flame binds itself to each and every arrow loaded into this crossbow. Some say the flame will burn forever, some claim it's actually powered by AA batteries but who really knows!
Properties
This item can kill zombies during a Pandemic!
This item never drops any seeds.
This item can be transmuted.

The **Eldritch Crossbow** is an unsplicable hand item that was added as part of Player Appreciation Week 2020 Day 4.
##  Function
May the flame guide you oh fiery arrow

That's enough for now

When equipped, the **Eldritch Crossbow** grants the _Punch Range : Eldritch Crossbow_ mod, which allows the player to punch one tile further.
The  The Seven Seas : The Curse of the Ghost Pirate! mission requires 1 of this item.
