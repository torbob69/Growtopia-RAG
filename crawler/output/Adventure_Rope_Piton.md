The **Adventure Rope Piton** is a splicable non-solid foreground block which was added as part of The Adventure Pack Strikes Back! update on June 1, 2017.
##  Function
The Adventure Rope Piton works like a Climbing Wall, except the player must have an Adventure Item - Rope to climb the wall.
