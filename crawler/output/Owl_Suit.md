Get suited and "hooted" and dress like an owl! Feathery finery for the discerning owl-ficionado!

The **Owl Suit** is an unsplicable shirt item which was added as part of Harvest Festival 2020 on September 24, 2020.
##  Function
When equipped, the Owl Suit serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the owl set, which consists of the following items:
