# Radioactive Bit (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
**Radioactive Bits** are consumables added as part of the Gone Fishin'! update that are obtainable from fishing with any bait (excluding the Uranium Glowing Lure) in a nuclear-detonated Uranium Block with a Water on it.
##  Function
Consuming several of them while equipping a Hazmat Boots, Hazmat Helmet, Hazmat Pants, and Hazmat Suit will result in a Uranium Glowing Lure.
