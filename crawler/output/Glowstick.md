# Glowstick

This plastic tube of lethal radioactive elements is the perfect thing to swing around at a party! It also provides light.
Properties
This item never drops any seeds.
This item can be transmuted.

Type: Hand – Clothes

Hunting

1 may be obtained by using a  Geiger Counter.
The **Glowstick** is an unsplicable hand item which was added as part of Player Appreciation Week 2016.
##  Function
When equipped, the **Glowstick** grants the _Light Source_ mod, which allows the player to emit light in dark areas.
