The **Joyful Bun Hair** is an unsplicable hair item which was added as March 2022's Monthly Subscriber's Item on March 1, 2022.
##  Function
When equipped, the Joyful Bun Hair serves a purely cosmetic purpose.
##  Trivia
  * The item's sprite, name, and description alludes to Jolyne Cujoh, one of the main protagonists of JoJo's Bizarre Adventure.
