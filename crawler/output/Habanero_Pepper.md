# Habanero Pepper

Caution: This is one seriously hot pepper!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Pinata Bash

Participate in successfully smashing an  Ultra Pinata during the **Pinata Bash!** event.
May give **1** item each time.
The **Habanero Pepper** is an unsplicable consumable which was added as part of Cinco De Mayo Week 2013 on May 3, 2013.
##  Function
You are burning up!

The fire's out.

When consumed on a player, this item will grant the _ON FIRE!!!_ mod, which allows the player to move faster on land for five seconds. The player's skin will also turn red as if they are on fire.
