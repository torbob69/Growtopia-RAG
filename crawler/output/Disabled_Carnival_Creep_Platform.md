The **Disabled Carnival Creep Platform** is an unobtainable non-solid foreground block which was added as part of the Stuff! update.
##  Function
The Disabled Carnival Creep Platform is part of the Carnival's _Spiky Survivor_ game. Every several seconds while the game is on, a few of randomly-selected Disabled Carnival Creep Platforms will turn into Carnival Creep Platforms. Likewise, several Carnival Creep Platforms will also turn into Disabled Carnival Creep Platforms.
