# Bloom Aura

Celebrate spring in style, with this blooming good aura!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Back – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Easter Egg - Golden **(×1)** ,
Easter Egg - Pineapple **(×5)** and
Easter Egg - Ghost **(×5)**.
This recipe will yield **1** item.
The **Bloom Aura** is an unsplicable back item which was added as part of Easter Week 2021 on April 1, 2021.
##  Function
Spring is in the air and in bloom!

The season turned, turned, turned!

When equipped, the **Bloom Aura** grants the _Build Range : Bloom Aura_ mod, which allows the player to build one tile further.
The  Myths and Legends : Mothman Rising mission requires 1 of this item.
