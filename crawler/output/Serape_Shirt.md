# Serape Shirt

Wear this amazing striped shirt!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Blue.
Sew a  Silk Bolt - White to the previous bolt using a(n) **Overcasting Stitch**.
Lastly, sew a  Silk Bolt - White to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **Serape Shirt** is an unsplicable shirt item which was added as part of Cinco De Mayo Week 2023 on May 5, 2023.
##  Function
When equipped, the Serape Shirt serves a purely cosmetic purpose.
