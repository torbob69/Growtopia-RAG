The **Furious Eye** is an unsplicable face item which was added as January 2026's Item Of The Season on January 2, 2026.
##  Function
This eye is on fire!

Fire's put out!

When equipped, the **Furious Eye** grants the _Light Source + Punch Range: Furious Eye_ mod, which allows the player to emit light in dark areas and punch one tile further.
