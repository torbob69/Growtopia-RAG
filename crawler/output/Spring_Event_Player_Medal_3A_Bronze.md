# Spring Event Player Medal: Bronze

Awarded for achieving THIRD PLACE in the Player Leaderboards during the Spring season. Show off your victory by placing this medal in your world, and congratulations!

The **Spring Event Player Medal: Bronze** is an unsplicable platform foreground block which was added as part of Spring Clash 2019. It is awarded to the player who placed 3rd in the Player Leaderboard during a Spring Grow Event.
##  Function
A Spring Event Player Medal: Bronze behaves as a platform, thus a player can jump pass through it from underneath.
