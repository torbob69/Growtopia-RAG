The **Classy Comic's Smile** is an unsplicable face item which was added as part of Voucher Dayz 2024 on May 23, 2024.
##  Function
Why so serious?

Crime has no punchline!

When equipped, the **Classy Comic's Smile** grants the _Comic Makeup: Classy Comic's Smile_ mod, which allows the player to change their skin color to off-white.
##  Trivia
  * This item is considered a part of the Classy Comic's set, which consists of the following items:

    * Classy Comic's Hair (hair)

    * Classy Comic's Smile (face)

    * Classy Comic's Suit (shirt)

    * Classy Comic's Pants (pants)

    * Classy Comic's Shoes (shoes)

    * Classy Comic's Acid Flower (neck)
  * The full Classy Comic set is a reference to a fictional character called The Joker.
