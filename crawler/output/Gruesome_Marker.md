# Gruesome Marker

Use these sort of like Doors - They have IDs, so Doors can lead to them, though you can't travel from them. Use your wrench to set their ID.
Gruesome Marker (Rarity: 39)
Properties
This item has special properties you can adjust with the Wrench.
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

The **Gruesome Marker** is an splicable non-solid marker foreground block which was added as part of the Night of the Sewing Dead update on February 3, 2017.
##  Trivia
  * The Gruesome Marker is the fourth marker to be added in Growtopia, after Objective Marker, Carnival Landing, and Path Marker.
