# Treasure Block (block category)

**Treasure Block** s are blocks which drop a curated list of items which can be views on individual items' page when broken.
##  List of Treasure Blocks
Items: Special FunctionDeep Iron: Only drops Deep Iron Ore with 1-5 quantity.
Golden Treasure Hoard: None.
Hidden Treasure: None.
Locke's Mystery Box: None.
Mystery Block: Only drops Gems.
Pot O' Gold: None.
Pure Magic Ore: Only breakable using Mining Explosives.
