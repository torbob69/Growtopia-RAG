# Gauntlet of Elements

This incredibly strong gauntlet was designed for a single purpose: To hold the six Elemental Stones. While each stone is very powerful individually, combining their might in this gauntlet will grant the wearer the ability to manipulate the very building blocks of reality! Be warned, however, for adding a stone to this gauntlet requires the sacrifice of a soul in similar form. Doing so will bind the Elemental Stone to the guantlet and focus its power!

The **Gauntlet of Elements** is a hand item which was added as part of Summer Clash 2018 on September 3, 2018. It comes in seven different versions:
•  Raw Gauntlet of Elements
•  Gauntlet of Elements - Tier I
•  Gauntlet of Elements - Tier II
•  Gauntlet of Elements - Tier III
•  Gauntlet of Elements - Tier IV
•  Gauntlet of Elements - Tier V
•  Exquisite Gauntlet of Elements
##  Function
A Gauntlet of Elements can be used by the owner of a world in order to move blocks around without having to break and replace them. Each Gauntlet of Elements features a unique ability that corresponds to the stone consumed in order to achieve the item's current tier, while keeping the abilities of its lower-tiered variants.
The following table showcases the abilities of all seven gauntlet types.
Tier: AbilitiesRaw: _None_
Tier I: Moves blocks with the  Earth Chi
Tier II: Moves blocks with the  Earth or  Wind Chi
Tier III: Moves blocks with the  Earth,  Wind, or  Fire Chi

##  Trivia
  * The Gauntlet of Element is based on the fictional Infinity Gauntlet, in particular the version found in the Marvel Cinematic Universe.
  * When the Gauntlet of Elements was first released, players were able to swap the Data Bedrock with another block, causing the world data to be corrupted. This issue was fixed shortly afterwards.
  * An change implemented at an unknown date prohibited players from moving certain blocks, such as the Heart Monitor or Display Block. This was done as a precaution to a glitch.
    * This change had since been reverted by the developers.
  * A fix released at an unknown date prevented a world's co-owners from using the Gauntlet of Elements to swap blocks in the world.
