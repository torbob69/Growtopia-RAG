# Easter Witches Hood

Celebrate Easter the Finnish Way! Virvon, Varvon, for a fresh and healthy coming year!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hair – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Purple.
Sew a  Silk Bolt - White to the previous bolt using a(n) **Locking Stitch**.
Lastly, sew a  Silk Bolt - Floral to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **Easter Witches Hood** is an unsplicable hair item which was added as part of Easter Week 2021 on April 1, 2021.
##  Function
When equipped, the Easter Witches Hood serves a purely cosmetic purpose.
##  Trivia
  * The Easter Witches Hood and Cape are based on the customary appearance of an Easter witch.
    * The descriptions of the items reference the Virvonta tradition.
