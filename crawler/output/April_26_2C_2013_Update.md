# April 26, 2013 Update

Growtopia Gazette
> NEW: To show our appreciation for the excellent work the Growtopia moderators have done, we've decided to make a unique item for each one. Meow gets hers first, but the rest are coming!
> Check the forums, Meow usually has a contest or two going!
An update with an unknown name was introduced on April 26, 2013. The update introduced five new items and came with a significant increase in server capacity.[[1]](https://growtopiawiki.com/w/April_26,_2013_Update#cite_note-FB-1)[[2]](https://growtopiawiki.com/w/April_26,_2013_Update#cite_note-2)

##  Changes
###  Server Capacity
  * The developers of _Growtopia_ rewrote their backend in order to increase the server capacity,[[1]](https://growtopiawiki.com/w/April_26,_2013_Update#cite_note-FB-1) thus allowing more players to join in the game at the same time.

##  Trivia
  * The Meow Ears—introduced in this update—was the first among the batch of exclusive items given to moderators as a token of appreciation for their work.
