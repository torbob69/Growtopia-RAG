The **Super Cape - Autumn** is an unsplicable back item that was added as part of Harvest Festival 2016 on September 15, 2015.
##  Function
You can jump in mid-air! It's like flying, but less.

Gravity - it's the law.

When equipped, the **Super Cape - Autumn** grants the _Double Jump_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * The description of this item refers to the Heroman Cape.
