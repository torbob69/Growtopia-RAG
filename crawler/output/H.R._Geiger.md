# H.R. Geiger

_H.R. Geiger_ is a villain added during Cinco De Mayo 2017. It is an event-limited villain and can only be found during Geiger Day when using a Geiger Counter.
Cards he uses

Superpower - Alien Egg
Superpower - Liquify
Superpower - Regeneration
Superpower - Thunderstorm
Cosmic Power - Star Burst
Health: 15
Method: Bring Flame On!, Regeneration, Thunderstorm, Overcharge, Megawatt Pulse. Use Overcharge, then:
If he uses Regeneration, use Thunderstorm, if Thunderstorm is on cooldown then use Megawatt Pulse, if both are on cooldown use Overcharge.
If he uses Liquify, use Regeneration.
If he uses Alien Egg, use Flame On!.
If he uses Thunderstorm, use Thunderstorm.
If there is no Overcharge effect, use Overcharge when he uses Regeneration.
If he uses Alien Egg and have to repeat a Superpower element, Do Nothing instead.
Upon defeating, the possible rewards to receive are:
  * Henchman
  * Superpower - Alien Egg
  * Villain Portrait - H.R. Geiger
  * Xenoid Claws
  * Xenoid Leggings
  * Xenoid Mask
  * Xenoid Shoes
  * Xenoid Suit
  * Blue Geiger V-Neck
  * Green Geiger V-Neck
  * Orange Geiger V-Neck
  * Purple Geiger V-Neck

##  Trivia
  * H.R. Geiger is seen wearing the Xenoid Mask and Xenoid Suit.
  * H.R. Geiger's name is a reference to H.R. Giger and his Xenomorph.
