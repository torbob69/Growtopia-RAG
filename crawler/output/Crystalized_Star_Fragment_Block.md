The **Crystalized Star Fragment Block** is an unsplicable solid foreground block which was added as part of the Startopia 2.0 update on June 1, 2020.
##  Function
When placed, the Crystalized Star Fragment Block serves a fully aesthetic purpose.
The  Myths and Legends : The Eye of the Heavens mission requires 200 of this item.
