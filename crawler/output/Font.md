# Font

Growtopia uses the **Century Gothic** font using **bold**. It has been around since the beginning of the game. The first developers of the game, Seth and Hamumu, said that this font is a good option for reading text easily. Everywhere in the game, this font is used, including buttons, text, and screens.
**Please note** : The text in event banners, like SummerFest, Super Pineapple Party, and so on, don't use Century Gothic. Instead, they use different fonts for each event.
