# Slithering Slippers

Slippers that slither with snakes!
Properties
This item never drops any seeds.
Data

Type: Feet – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Daily Challenge

Place in the top three of the **Patrick's Prize** Guild Daily Challenge, only if the player had contributed points to the challenge.
The **Slithering Slippers** is an unsplicable feet item which was added as part of St. Patrick's Week 2020.
##  Function
I decided to go for a little run.

I'm pretty tired... I think I'll go home now.

When equipped, the **Slithering Slippers** grants the _Run: Slithering Slippers_ mod, which allows the player to keep on walking to whichever direction they are facing.
