# Moon Block

With this block, you too can yell at the moon like Buzz Aldrin.
Properties
This item never drops any seeds.
Data: Paint PreviewType — Foreground Block – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single
Collision Type: Full Collision
Hardness: **8 Hits** **6 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Combination

In any Chemical Combiner, mix together...
Harmony Mooncake **(×2)** ,
Longevity Mooncake **(×2)** and
Prosperity Mooncake **(×2)**.
This recipe will yield **3** items.
Mooncake Offering

1 may be received as a common reward from offering mooncakes using an Offering Table.
The **Moon Block** is an unsplicable solid foreground block which was added as part of Harvest Festival 2014 on September 5, 2014.
##  Function
When placed, the Moon Block serves a purely aesthetic purpose.
The  Myths and Legends : The Menace of the Mini Minokawa mission requires 100 of this item.
