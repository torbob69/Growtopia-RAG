The **Nano Nurse Bot** is an unsplicable hand item which was added as part of the Challengers Approach! update.
##  Function
The Nano Nurse provides everything a surgeon needs.

Back to your own skills.

When equipped, the **Nano Nurse Bot** grants the _Rebuild Tools: Nano Nurse Bot_ mod, which allows the player to reduce skill fails while increasing the odds of not using up a Surgical Tool when performing a surgery.
