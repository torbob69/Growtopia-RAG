# Orange Cat As A Hat

Oh, the places you'll go wearing this hat! You can wear it on the train, or in the rain, or... well, actually don't wear it in the rain, it'll shrink.
Properties
This item never drops any seeds.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Yellow.
Sew a  Wool Bolt to the previous bolt using a(n) **Blind Stitch**.
Lastly, sew a  Silk Bolt - Red to the previous bolt using a(n) **Saddle Stitch**.
Each recipe gives **1** item.
The **Orange Cat As A Hat** is an unsplicable hat item which was added as part of the Night of the Sewing Dead update on February 3, 2017.
##  Function
When equipped, the **Orange Cat As A Hat** serves a purely cosmetic purpose.
##  Trivia
  * The description of the Orange Cat As A Hat is a reference to _Oh, the Places You'll Go!_ , a book by author Dr. Seuss.
