# Cactus Onesie

The perfect onesie for blending in with the local flora and fauna when you visit the desert. Never look like a tourist again!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single

**1h**
Pinata Bash

Participate in successfully smashing an  Ultra Pinata during the **Pinata Bash!** event.
May give **1** item each time.
The **Cactus Onesie** is an unsplicable shirt item which was added as part of Cinco De Mayo Week 2021 on May 5, 2021.
##  Function
When equipped, the Cactus Onesie serves a fully cosmetic purpose.
##  Trivia
  * This item is considered a part of the Cactus set, which consists of the following items:

    * Cactus Hat (Hair)

    * Cactus Onesie (Shirt)

    * Cactus Cannon (Hand)
