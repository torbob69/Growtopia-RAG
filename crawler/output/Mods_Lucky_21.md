# Mods/Lucky!

< Mods
The **_Lucky!_** mod gives a 10% chance to multiply gem drops from breaking blocks by up to 5. It also provides a 10% chance for an extra block to be dropped.
**Consumable**

Item — In-game Label — Notes
Lucky Clover — _Lucky!_ — • Doesn't stack with Rabbit's Foot or Songpyeon, but stacks with Apology Weekend.
Rabbit's Foot — _Lucky!_ — • Doesn't stack with Lucky Clover or Songpyeon, but stacks with Apology Weekend.
Songpyeon — _Lucky!_ — • Doesn't stack with Lucky Clover or Rabbit's Foot, but stacks with Apology Weekend.
**Event**

Name — In-game Label — Notes
Apology Weekend — _N/A_ — • Stacks with Lucky Clover, Rabbit's Foot, or Songpyeon.
