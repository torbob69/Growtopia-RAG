The **Green Bowtie** is an unsplicable chest item which was added as part of St. Patrick's Week 2014 on March 14, 2014.
##  Function
When equipped, the Green Bowtie serves a fully cosmetic purpose.
##  Trivia
  * The item's description is a reference to the _Doctor Who_ television series, in which the Eleventh Doctor proclaims, "Bow ties are cool," as a running gag.
