# Dary Seed

Wait for it...
Dary (Rarity: 100)
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: No Collision
Hardness: **4 Hits** **3 Hits** – Restores after **5s** of inactivity
Gems Drop: **0 - 26**
**11d 14h 36m 40s**
Combination

In any Chemical Combiner, mix together...
Kerjigger **(×1)** ,
Thingamajig **(×1)** and
Thingamabob **(×1)**.
This recipe will yield **1** item.
The **Dary** is an unsplicable component which was added as part of the Legendary update on August 22, 2014.

##  Trivia
  * The words "Legen" and "Dary" makes the word "Legendary" when combined.
  * Legen tree and Dary tree requires the same time to fully grow.
  * Upon planting the seed, it will give back the seed when the tree is harvested.
  * As part of the Quality of Life Changes update on May 20, 2022, the Dary Seed is no longer placeable in public worlds and worlds the player is an admin in.
