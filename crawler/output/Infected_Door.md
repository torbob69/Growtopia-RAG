The **Infected Door** is a splicable non-solid door foreground block which was added as part of the Night of the Sewing Dead update on February 3, 2017.
##  Function
As a door, the Infected Door can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
An Infected Door is different from normal doors in the sense that it only allows players infected with the g-Virus to enter the door, while other players will be refused entry. If the non-infected player tries to enter the door, a message will appear, "Ew, I'm not touching that door!"
