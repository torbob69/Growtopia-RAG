# Mystery Update

Growtopia Gazette
> Nov 11th: NEW STUFF AND SPEED - No more lag! We've done some nice software and hardware improvements over the last few days that allow us to handle 8k+ players with ease. We've also added some new stuff today.
> NEW IN STORE: Zombie Jammer - By popular demand, you can now finally make your world immune, useful if those pesky walkers keeping running your parkour!
> NEW ITEMS: We've added TEN new items today. Figure 'em out yourself.
> TWEAK: An IMMUNE tag now shows when entering worlds where zombie infections (via punching) aren't possible.
> SYSTEM: Various optimisations have been done to improve server performances.
> - @Seth and @Hamumu
The **Mystery Update** was introduced on November 11, 2013. It notably added the Zombie Jammer and Thingamajig into the game.
