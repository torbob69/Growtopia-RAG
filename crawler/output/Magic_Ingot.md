# Magic Ingot

You've managed to process this ore into a pure, shining ingot, just by tossing it into a fire!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **9 Hits** **7 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Combustion

Burn a(n)  Magic Ore **(x1)** in a  Highly Combustible Box.
The **Magic Ingot** is an unsplicable consumable which was added as part of the Spelunkorama Strikes Back! update on February 6, 2020.
##  Function
This item serves no purpose by itself.
