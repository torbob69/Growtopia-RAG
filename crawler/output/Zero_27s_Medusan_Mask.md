The **Zero's Medusan Mask** is an unsplicable face item which was added as part of Star Trek Prodigy on June 27, 2022.
##  Function
When equipped, the Zero's Medusan Mask serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Zero set, which consists of the following items:

    * Zero's Containment Hood (Hair)

    * Zero's Medusan Mask (Face)

    * Zero's Arms (Hand)

    * Zero's Legs (Pants)

    * Zero's Shoes (Feet)
