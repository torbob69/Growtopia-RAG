The **Haunted Chemical** is an unsplicable component which was added as part of Halloween Week 2014 on October 30, 2014.
##  Function
Being a type of chemical, the Haunted Chemical can be used for combining alongside two other types of chemicals in a Chemical Combiner to create certain items.
