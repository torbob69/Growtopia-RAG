# Adventure Pedestal

When a player who has Adventure Item - Golden Idol steps on this, their idol is placed on the pedestal, opening all Adventure Idol Gates in the world (for them only), or shutting ones that are open.

The **Adventure Pedestal** is a splicable non-solid foreground block which was added as part of The Adventure Pack Strikes Back! update on June 1, 2017.
##  Function
When a player holding Adventure Item - Golden Idol steps on it all Adventure Idol Gates in the current world will be opened or shut if they are open. Note that gates will be opened only for the player who activated the pedestal.
