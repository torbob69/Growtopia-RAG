The **Hospital Door** is an unsplicable non-solid foreground door block which was added as part of the Growtopia General Hospital update on November 22, 2013.
##  Function
As a door, the Hospital Door can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
