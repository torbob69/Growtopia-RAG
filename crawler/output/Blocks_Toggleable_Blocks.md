# Blocks/Toggleable Blocks

< Blocks
**Toggeable Blocks** are blocks which allows eligible players to open and close the toggleable block by punching it. When toggled on, the item acts as a solid block which players cannot pass while killing all players trapped inside it. When toggled off, it opens and acts as a non-solid block which players can walk through. It can be wrenched to be made public or not.
