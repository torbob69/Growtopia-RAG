**My Pet Sputnik** is an unsplicable pet hand item which was added as part of the Startopia 2.0 update on June 1, 2020.
##  Function
Signal Lost!

Sending out a signal, is anyone there!

When equipped, the **My Pet Sputnik** grants the _Punch Damage: My Pet Sputnik!_ mod, which allows the player to break blocks faster. It also replaces the punching animation with green cosmic circles similar to the Cosmic Unicorn Bracelet.
##  Trivia
  * The item references the Sputnik satellites launched by the USSR circa 1957. Sputnik 1 was the first artificial satellite; moreover, it was the first to be placed in Earth's orbit.
