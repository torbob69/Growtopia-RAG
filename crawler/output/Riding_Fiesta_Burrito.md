# Riding Fiesta Burrito

This donkey likes to party.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Feet – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Fiesta Sombrero **(×1)** ,
Pet Burrito **(×1)** and
Party Cactus **(×200)**.
This recipe will yield **1** item.
The **Riding Fiesta Burrito** is an unsplicable feet item which was added as part of Cinco De Mayo Week 2017 on May 5, 2017.
##  Function
You can move faster!

You are slow again.

When equipped, the **Riding Fiesta Burrito** grants the _Speedy_ mod, which allows the player to move faster on land.
