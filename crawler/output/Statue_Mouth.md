The **Statue Mouth** is a splicable toggleable foreground block which was added as part of The Adventure Pack Strikes Back! update on June 1, 2017.
##  Function
Being a toggleable foreground block, a Statue Mouth works like a Dragon Gate, allowing eligible players to open and close the Statue Mouth by punching it. When toggled on, the item acts as a solid block which players cannot pass while killing all players trapped inside it. When toggled off, it opens and acts as a non-solid block which players can walk through. It can be wrenched to be made public or not.
