The **Monochromatic Bedrock** is an unsplicable and unobtainable solid bedrock foreground block that was added as part of the Black Friday 2018 on November 22, 2018. 600 of them can be found in Monochrome Blasted worlds.
##  Trivia
  * Trying to break Monochromatic Bedrock will display a message which reads: _"It's too strong to break."._
  * Monochromatic Bedrock can only be moved using a Door Mover, which moves the main door and the single Monochromatic Bedrock under it.
  * The sprite of Monochromatic Bedrock is a recolor of Bedrock.
