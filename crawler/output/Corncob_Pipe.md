# Corncob Pipe

This is a bad habit, you should stop it. Only found in Blarney 2 and 3.
Properties

The **Corncob Pipe** is an unsplicable face item which was added as part of St. Patrick's Week 2015 on March 13, 2015.
##  Function
When equipped, smoke particles come out of the pipe, which gives nearby people the _:p_ emote.
