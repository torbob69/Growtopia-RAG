# Growmoji Trophy

For the absolute GOATS! Just consume this to add it to your available growmojis!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Consumption

Consume a(n)  Voucher Dayz Growmoji Mystery Crate **(x1)**.
May yield **1** item each.

The **Growmoji Trophy** is an unsplicable growmoji consumable which was added as part of Voucher Dayz 2026 on August 27, 2026.
##  Function
Upon consuming, the player will now be able to use the (trophy) growmoji.
