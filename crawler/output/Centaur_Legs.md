The **Centaur Legs** is an unsplicable feet item which was added as part of Valentine's Week 2023 on February 10, 2023.
##  Function
Run like the wind!

Stop like the sign!

When equipped, the **Centaur Legs** grants the _Speedy: Centaur Legs_ mod, which allows the player to move faster on land.
