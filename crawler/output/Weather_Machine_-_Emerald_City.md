The **Weather Machine - Emerald City** is an unsplicable non-solid weather machine foreground block which was added as part of St. Patrick's Week 2025 on March 14, 2025.
##  Function
As a weather machine, the Weather Machine - Emerald City can be toggled on or off via punching. When toggled on, it will change its appearance, transforming the world's background.
