# Mysterious Chemical

This recently-discovered formulation is incredibly dangerous! Do not even LOOK AT IT. Place carefully in a Laboratory to combine with other chemicals and create amazing new things.
Mysterious Chemical (Rarity: 90)
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: No Collision
Hardness: **4 Hits** **3 Hits** – Restores after **5s** of inactivity
Gems Drop: **0 - 23**
**8d 11h 15m**
Combination

In any Chemical Combiner, mix together...
Chemical Y **(×20)** ,
Chemical B **(×10)** and
Chemical P **(×5)**.
This recipe will yield **1** item.
The **Mysterious Chemical** is an unsplicable component which was added alongside the Mad Science Kit on July 20, 2013.
##  Function
Being a type of chemical, the Mysterious Chemical can be used for combining alongside two other types of chemicals in a Chemical Combiner to create certain items.
