# Verdant Gate

These lush magical doors connect all the worlds in Growtopia. Place one and then use your Wrench on it to set the destination. Wow, tropical!

Combination

In any Chemical Combiner, mix together...
Earth Essence **(×20)** ,
Water Essence **(×5)** and
Crystal Gate **(×1)**.
This recipe will yield **1** item.
The **Verdant Gate** is an unsplicable non-solid door foreground block which was added as part of the Hidden Riches update.
##  Function
As a door, the Verdant Gate can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
