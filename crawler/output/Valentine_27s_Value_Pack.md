# Valentine's Value Pack
On 14 February, 2024

|
Growtopia Store

Purchase the **Valentine's Value Pack** for **2.99 USD** in the Growtopia Store.
"A sweet deal to go with the event!"
Every purchase will give **1** item.
The **Valentine's Value Pack** is a Store-bought IAP which was added as part of the Valentine's Week 2023 update and was only available on the first day.
The first incarnation of the Valentine's Value Pack contained the following:
  * Gems ×105,000
  * Corny Couple Shirt ×1
  * Golden Booty Chest ×20
  * Well of Love ×1
