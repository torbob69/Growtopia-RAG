# Red Crystal

This crystal is not yet in balance. Perhaps if you place it in the bosom of its Earth Mother, and then join it with 4 other crystals, it can achieve harmony.
Red Crystal (Rarity: 100)
Properties
This item never drops any seeds.
This item can only be used in World-Locked worlds.
This item has special properties you can adjust with the Wrench.

The **Red Crystal** is a crystal that was introduced in the Crystals update. It is one of the five Crystals: Green, Blue, Red, White, and Black.
##  Function
When placed, Red Crystal will act as a Crystal that you harmonize by adding other Crystals on it.
