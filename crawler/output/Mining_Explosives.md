# Mining Explosives

Use to blow apart even the most stuborn rocks. Great for mining deep ore deposits. Warning: stand back when using!
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

Mining

5 have a chance to be dropped from opening naturally generated chests in mines.
The **Mining Explosives** is an unsplicable non-solid foreground block which was added as part of the Spelunkorama Strikes Back! update.
##  Function
When punched by a player, the Mining Explosives will explode, breaking all foreground and background blocks in a 3×3 area and killing anyone in the range. Mining Explosives are primarily used to extract Magic Ores from Pure Magic Ores.
Mining Explosives are only usable in mines, and work as normal blocks otherwise.
##  Trivia
  * _Growtopia_ 's creator Seth once entertained the idea of adding TNT blocks, which would work in quite a similar manner to the Mining Explosives, being able to to demolish surrounding blocks.[[1]](https://growtopiawiki.com/w/Mining_Explosives#cite_note-1) This idea was scrapped at the time due to an unknown reason.
  * When the Spelunkorama Strikes Back! update was first released, permanent blocks such as weather machines could be duplicated by exploding them with Mining Explosives. This would cause the item to return to the player's backpack and drop itself at the same time.
