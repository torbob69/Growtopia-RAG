# Salmon Suit

It's not pink, it's salmon!
Properties
This item never drops any seeds.
This item can be transmuted.

Render Type: Single

Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Red.
Sew a  Silk Bolt - White to the previous bolt using a(n) **Straight Stitch**.
Lastly, sew a  Wool Bolt to the previous bolt using a(n) **Triple Stretch Stitch**.
Each recipe gives **1** item.
The **Salmon Suit** is an unsplicable shirt item which was added as part of Easter Week 2022 on April 15, 2022.
##  Function
When equipped, the Salmon Suit serves a purely cosmetic purpose.
