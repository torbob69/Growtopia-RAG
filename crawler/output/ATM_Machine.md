The **ATM Machine** is an unsplicable non-solid provider foreground block which was added alongside the City Pack on August 18, 2013.
##  Function
The ATM Machine is a type of provider. When an ATM Machine is harvested (by being punched), 1-100 gems will drop. On average, ATM Machines give 11 gems each. One can be harvested approximately every 22 hours.
