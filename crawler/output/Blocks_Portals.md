# Blocks/Portals

< Blocks
**Portals** are non-solid foreground blocks which immediately moves the player to another tile when touched. A block with an ID must first be placed on the tile for this to work.
**Portals**

Item: Description
Blue Portal: Step through it. There is cake on the other side.
Hellgate: It seems like the destination of this portal is obvious, but actually you can choose any place you like with your Wrench.
Love Portal: Be transported in love.
Lucky Portal: This portal isn't actually lucky unless you set a destination for it that is lucky. So it's really up to you!
Mystery Portal: Where will you be transported to? Who knows? It's a mystery. Wrench this to choose up to 5 destinations to randomly send players to.
Orange Portal: You monster!
Time-Space Rupture: Nobody knows where you will emerge when you fall into one of these! Except whoever set the destination using the Wrench.
