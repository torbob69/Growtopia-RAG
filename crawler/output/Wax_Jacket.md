# Wax Jacket

The perfect jacket for taking a stroll in the country. Either yomping over dale with your trusty companion or atop a hill surveying your land, this is the look for you.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Green.
Sew a  Wool Bolt to the previous bolt using a(n) **Saddle Stitch**.
Lastly, sew a  Silk Bolt - Green to the previous bolt using a(n) **Zigzag Stitch**.
Each recipe gives **1** item.
The **Wax Jacket** is an unsplicable shirt item which was added as part of the St. Patrick's Week 2021 update on March 11, 2021.
##  Function
When equipped, the Wax Jacket serves a fully cosmetic purpose.
