The **Candy Striper Cap** is an unsplicable hair item which was added as part of the Growtopia General Hospital update on November 22, 2013.
##  Function
When equipped, the Candy Striper Cap serves a fully cosmetic purpose.
##  Trivia
  * This item is considered a part of the Candy Striper set, which consists of the following items:

    * Candy Striper Cap (Hair)

    * Candy Striper Uniform (Shirt)

    * Candy Striper Skirt (Pants)
