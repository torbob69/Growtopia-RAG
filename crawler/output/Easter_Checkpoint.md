The **Easter Checkpoint** is an unsplicable non-solid checkpoint foreground block which was added as part of Easter Week 2019.
##  Function
Being a checkpoint block, the Easter Checkpoint acts as where the player respawns after dying.
After going through a Race Start Flag and then through a Race End Flag, all checkpoints will be reset and the player would respawn at the Main Door on death. The same goes with the Challenge Timer and /kick, /kickall command.
