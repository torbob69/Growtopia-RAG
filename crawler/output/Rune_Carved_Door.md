**Rune Carved Door** is a door that can be found in a cave-blasted world. A player needs to equip the Magic Stones to be able to locate the door.
##  Function
Entering a **Rune Carved Door** will send the player to the Mines.
##  Trivia
  * There is only one **Rune Carved Door** in each cave world.
  * There was a glitch when using a Door Mover on a cave world, instead of the player spawning at the Main Door, they will instead spawn at the **Rune Carved Door**. This glitch has been patched in the Quality of Life Changes update.
