# Diamond Mannequin

Dress up your sparkling diamond mannequin with clothes! Use your Wrench to change the sign on it.

This item never drops any seeds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item can be placed in two directions, depending on the direction you're facing.

The **Diamond Mannequin** is an unsplicable non-solid mannequin foreground block which was added as part of Pre-WinterFest 2025 on December 1, 2025.
##  Function
Being a mannequin, the Diamond Mannequin allows clothes to be put on it by a player with access. One can also edit its message for other players to view, as if it were a sign.
##  Trivia
  * The  Diamond Mannequin is a recolor of the  Mannequin.
