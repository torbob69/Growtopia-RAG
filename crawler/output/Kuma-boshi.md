This item was given to **Akiko** for their contributions as a voluntary moderator.
The **Kuma-boshi** is an unsplicable hat item which was added alongside the Game Pack on July 25, 2014.
##  Function
When equipped, the Kuma-boshi serves a purely cosmetic purpose.
##  Trivia
  * The name _Kuma-boshi_ is derived from the Japanese phrase _kuma bōshi_ (クマ帽子), which literally means "bear hat".
