The **Lembuswana Statue** is an unsplicable non-solid foreground block which was added as part of Garuda's Glory 2023 on August 17, 2023.
##  Function
When placed, the Lembuswana Statue serves a purely aesthetic purpose.
##  Trivia
  * The Lembuswana Statue is a reference to a legendary creature of the same name described as a lion-headed horse with an adorning crown, having an elephant-like trunk, a pair of Garuda wings, and fish-like scales.
