# Crawdad

This is a 1 lb. Crawdad. Whether you call them crawfish, crayfish, crawdads, or even mudbugs, it's really just a little tiny lobster.
Properties
This item never drops any seeds.
This is a fish. It can only be placed in a Fish Tank. You can't divide fish into pieces.
