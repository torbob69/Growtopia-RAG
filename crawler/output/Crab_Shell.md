The **Crab Shell** is an unsplicable back item which was added as part of SummerFest 2024 on July 11, 2024.
##  Function
Crab-tastic!

Crab-tastrophe!

When equipped, the **Crab Shell** grants the _Double Jump : Crab Shell_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * This item is considered a part of the Crab set, which consists of the following items:

    * Crab Hood (Hat)

    * Crab Shell (Back)

    * Crab Claws (Hand)
