The **Winter Token** is an unobtainable component that was added as part of Winter Clash 2018.
##  Function
The Winter Token item was added as a placeholder for Winter Clash's main currency, which can be obtained by reaching milestone points during a Grow Event while a Winter Clash is still ongoing. They can be used to purchase items on the Winter Clash Rewards Store.
This item cannot be obtained in the player's inventory by regular means, as collected Winter Tokens are stored in a separate entry in the player data.
