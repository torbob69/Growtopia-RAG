The **Shady Agent Shades** is an unsplicable face item which was added as part of Myths and Legends, the first set of Marvelous Missions, on March 18, 2021.
##  Function
Here come the "shady agents" in black!

There go the "shady agents" in black!

When equipped, the **Shady Agent Shades** grants the _Punch Damage: Shady Agent Shades!_ mod, which allows the player to break blocks faster. It also summons a U.F.O. following the player around and shooting green lasers when punching.
##  Trivia
  * The Shady Agent Shades' equip and unequip messages are a reference to Men in Black, a song by American rapper and actor Will Smith from the 1997 film Men in Black, in which he also starred.
