The **Bear That Cares** is an unsplicable hand item which was added as part of Valentine's Week 2023 on February 10, 2023.
##  Function
Free Hugs!

So lonely!

When equipped, the **Bear That Cares** grants the _Free Hugs : Bear That Cares_ mod, which allows the player to break blocks faster and punch one tile further.
