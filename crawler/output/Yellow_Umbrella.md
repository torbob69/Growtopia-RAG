# Yellow Umbrella

You can stand under this umbrella!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hand – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **1 Hits** **1 Hits** – Restores after **2s** of inactivity
Gems Drop: **N/A**
**1h**
Special Event

Found in the _Well, Well, Well_ special event.
One has 30 seconds to find 3 dropped Well and a small chance of a dropped Yellow Umbrella.
The **Yellow Umbrella** is an unsplicable hand item which was added as part of Player Appreciation Week 2023 Day 6 on September 2, 2023.
##  Function
It's raining!

It's ain't pouring!

When equipped, the **Yellow Umbrella** grants the _Slowfall: Yellow Umbrella_ mod, which allows the player to glide slowly to the ground when holding the jump button.
##  Trivia
  * The Yellow Umbrella's description is a reference to a line from Umbrella, a song by Barbadian singer Rihanna.
