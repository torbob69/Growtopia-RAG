The **Captain Laserhawk's Eye** is an unsplicable face item which was added as part of UbiWeek 2024 Day 5 on April 2, 2024.
##  Function
Target Selected!

Lost Target!

When equipped, the **Captain Laserhawk's Eye** grants the _Night Vision: Captain Laserhawk's Eye_ mod, which allows the player to eliminate the darkness effect created by dark background blocks.
##  Trivia
  * This item is considered a part of the Captain Laserhawk set, which consists of the following items:

    * Captain Laserhawk's Hair (Hair)

    * Captain Laserhawk's Eye (Face)

    * Captain Laserhawk's Shirt (Shirt)

    * Captain Laserhawk's Arm (Hand)
