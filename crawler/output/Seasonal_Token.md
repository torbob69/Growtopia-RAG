# Seasonal Token

**Seasonal Token** is an unsplicable component that was introduced in Seasonal Clashes. It can be obtained by reaching milestone points during a Grow Event while a clash is on-going. These cannot be obtained in the player's inventory, but it is stored in a separate entry in the player data. There are three types of seasonal tokens, which are, Winter, Spring, and Summer.
