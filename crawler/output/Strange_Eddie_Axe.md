##  Function
Making metal music!

I don't like this!

When equipped, the **Strange Eddie Axe** grants the _Punch Damage : Strange Eddie Axe!_ mod, which allows the player to break blocks faster. Additionally, it provides a slashing punch effect while punching.

    * Strange Eddie Jacket (shirt)

    * Strange Eddie Pants (pants)

    * Strange Eddie Axe (hand)
