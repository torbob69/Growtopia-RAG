##  Trivia
  * This item is considered a part of the Student Hero set, which consists of the following items:

    * Student Hero Hair (hair)

    * Student Hero Suit (shirt)

    * Student Hero Pants (pants)

    * Student Hero Shoes (shoes)

    * Student Hero Gloves (hand)
  * The full Student Hero Set is a reference to a character with name Izuku Midoriya (also known as Deku) from a Japanese manga series called My Hero Academia.
