The **Pencil Mustache** is an unsplicable face item that was added as part of the Locke The Traveling Salesman update on March 22, 2015.
##  Function
When equipped, the Pencil Mustache serves a fully cosmetic purpose.
##  Trivia
  * This item is considered a part of the Locke The Salesman set, which consists of the following items:

    * Pink Fedora (hat)

    * Distinguished Grey Hair (hair)

    * Pencil Mustache (face)

    * Pink Suitcoat (shirt)

    * Fancy Pants (pants) .
  * Equipping the set completes the _"Dress up asLocke The Salesman"_ Epic Quest.
  * Pencil Mustache is based on an actual mustache style with a similar name, the pencil mustache.
