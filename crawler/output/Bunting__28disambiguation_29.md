# Bunting (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
**Buntings** are decorative non-solid foreground blocks sporting the appearances of either strings of triangular flags or lengths of fabric gathered and draped into festoons.
##  Varieties
