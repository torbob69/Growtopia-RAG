The **bllade's Celestius** is an unsplicable hand item which was added as part of Beach Party 2022 on August 6, 2022.
##  Function
Unleash the power!

Sheathe the power!

When equipped, the **bllade's Celestius** grants the _Punch Damage : bllade's Celestius!_ mod, which allows the player to break blocks faster.
##  Trivia
  * This item is sponsored by bllade for completing all the Epic Quests.
  * This item's appearance is based on Star Wrath, a sword from an action-adventure sandbox game Terraria.
  * Since bllade's Celestius starts with a lower case letter, it is placed at the end of the player's inventory instead of being placed in alphabetical order like other items.
