# Valkyrie's Sandals

Nimble footwear for an agile Chooser of the Slain!
Properties
This item never drops any seeds.
Data

Type: Feet – Clothes
Render Type: Single
Collision Type: Full Collision

**1h**
Treasure Hunting

Has a chance to be obtained from completing a Treasure Map.
The **Valkyrie's Sandals** is an unsplicable feet item which was added as part of Player Appreciation Week 2019 Day 4 on August 22, 2019.
##  Function
Running into battle!

Give your feet a rest!

When equipped, the Valkyrie's Sandals grants the _Speedy: Valkyrie_ mod, which allows the player to move faster on land.
##  Trivia
  * This item is considered a part of the Valkyrie set, which consists of the following items:

    * Valkyrie's Helm (hat)

    * Valkyrie's Cuirass (shirt)

    * Valkyrie's Sandals (feet)

    * Valkyrie's Wings (back)
