# Kimono (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.

Men's Kimono: Sewing with a Silk Bolt - Black, then a Silk Bolt - Grey using an _Overcasting Stitch_ , then another Silk Bolt - Black using a _Locking Stitch_.
Kimono of Chang'e: Epic reward from an Offering Table when the offering contains a Balance Mooncake.
Kuchisake Kimono: One may be obtained by sacrificing a Pink, Blue, or Orange Kimono or a Dark King's Offering to Growganoth.
Greatest Swordsman's Kimono: One can be purchased in the Growtopia Store for 10 Grow Voucher during a Voucher Dayz that contains the item.
##  Trivia
