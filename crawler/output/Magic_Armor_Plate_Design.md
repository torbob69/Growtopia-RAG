# Magic Armor Plate Design

This paper details a method for forging a Magic Armor Plate. If you forge 100 Magic Ingots with this design in hand, you'll make a Magic Armor Plate. This consumes the design.
Properties
This item never drops any seeds.
This item has no use... by itself.

Mining

1 has a chance to be dropped from exploding  Pure Magic Ore using  Mining Explosives, which are naturally generated in mines.
The **Magic Armor Plate Design** is an unsplicable component which was added as part of the Spelunkorama Strikes Back! update on February 6, 2020.
##  Function
A Magic Armor Plate Design must be in a player's backpack with forging 100 Magic Ingots in order to create a Magic Armor Plate.
