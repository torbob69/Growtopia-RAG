# Solsascarf

Solsagann is tossing out yesterday's baguettes! They are quite stale.
Properties

This item never drops any seeds.

Exclusive Item

This item was given to **Solsagann** for their contributions as a voluntary moderator.
The **Solsascarf** is an unsplicable chest item which was added as part of The Grand Tournament update on December 1, 2016.
##  Function
Feed the birds!

Starve the birds!

When equipped, this item grants the _Mmm, Baguette!_ mod, which replaces the player's normal punch effect with baguettes being thrown by the player.
