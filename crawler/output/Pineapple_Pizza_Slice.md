The **Pineapple Pizza Slice** is an unsplicable consumable which was added as part of Super Pineapple Party Week 2021 on June 3, 2021.
##  Function
When consumed, the player will say "YUM!" and do the :D ⦅⦆ emote.

##  Trivia
  * The Pineapple Pizza Slice is based on the Hawaiian pizza, which traditionally uses pineapple chunks as its main topping.
    * The item's description references a common humorous argument in which people debate on whether pineapple does belong as a pizza topping.[[1]](https://growtopiawiki.com/w/Pineapple_Pizza_Slice#cite_note-1)
  * The description of the item also references the phone number 30912, which belongs to Growtopizza. Players can call this number in order to purchase the regular  Pizza.
