##  Function
Whoooooooaaaaaaaa...

Gravity - it's the law.

When consumed on any player, the player will have the _Floating!_ mod for 3 seconds, which makes their character float in the air.
The Bubble Gum also shares this ability.

##  Trivia
  * The in-game description of this item is a reference to the 1983 song 99 Luftballoons by German singer Nena. In particular, it is a reference to the English rendition of the song released the following year by the same singer, 99 Red Balloons.
  * A glitch which has been lasting since Halloween Week 2019 has been causing the Das Red Balloon's _Floating_ effect not to work.
  * Equipping a Pet Rock grants you immunity to the _Floating!_ mod.
