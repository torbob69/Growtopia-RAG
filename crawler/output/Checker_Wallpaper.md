##  Function

##  Trivia
  * The in-game description is a reference to the letter of Michael Jackson's song "Black or White".
  * In the early beta version of _Growtopia_ , both the Checker Wallpaper Tree and The Darkness Tree were accidentally given the same recipe, preventing players from splicing the latter. This mistake was fixed shortly thereafter.[[1]](https://growtopiawiki.com/w/Checker_Wallpaper#cite_note-1)
