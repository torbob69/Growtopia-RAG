The **Display Block** is a splicable foreground block which was added as part of Player Appreciation Week 2015 Day 4 on August 17, 2015.
##  Function
The Display Block lets players display an item in a block for everybody to see.

##  Trivia
  * Players cannot place Screen Doors in a **Display Block**. Trying to do so will generate the message: _"Don't be a scammer."_ This is because players used it in minigames to pretend that it was a real door.
  * Attempting to place a lock in a **Display Block** will display the message: _"Sorry, no displaying Display Blocks or Locks"_. This was due to the arise of a scam method, where the world owner would make their world public and ask others to place their locks in the display blocks, then they could steal the locks.
    * However, all of the locks that were displayed before this change was implemented continued to stay in the display blocks after the changes took place. These locks were:
      * Small Lock
      * Big Lock
      * Huge Lock
      * World Lock
      * Diamond Lock
      * Emerald Lock
      * Robotic Lock
  * Attempting to place an untradeable item in a **Display Block** will generate the message: _"You can't display untradeable items."_
  * Attempting to place anything inside a **Display Block** which has just been placed will display the message: _"The Display Block needs to warm up for 5 seconds before use!"_
  * Only the owner of the **Display Block** can add and remove displayed items.
  * Attempting to place an item in a **Display Block** as an admin will show a message displaying: _"Only the block's owner can place items in it."_
  * Attempting to break the **Display Block** will display a slightly different message saying:  _"Only the block's owner can break it!"_
  * You cannot place a background behind a **Display Block** as it thinks that you're trying to display an item in it nor can you place a **Display Block** on it as it thinks that you're trying to edit the item in it.
