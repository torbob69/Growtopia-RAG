# Event Mystery Blocks (block category)

**Event Mystery Blocks** are special blocks that are used in events to drop random items, these blocks can be spawned trough events or placed by the player.
##  List of Event Mystery Blocks
Items: Special FunctionLava Pinata: Placeable block, which when broken to receive exclusive items during the Cinco De Mayo 2021 timed event.
Mystery Pinata: Placeable block, specific dropped items in it to transform them into event exclusive items when the _Mystery Pinata_ is broken.
Organic Turkey: Placeable block, that when broken drops a random reward which will appear randomly near the block.
Pinata: Placeable block, dropped items in it will appear randomly near the block when broken.
Summer Surprise: Placeable block, items will appear randomly near the block when broken.
Thanksgiving Turkey: Special event block, when broken, players will receive Dead Thanksgiving Turkey.
Ultra Pinata: Special event block, when broken, players in the world will receive Cinco De Mayo Week rewards.
