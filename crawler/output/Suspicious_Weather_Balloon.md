The **Suspicious Weather Balloon** is an unsplicable hand item which was added as part of the Aliens update on November 14, 2021.
##  Function
Nothing to see here!

Nothing to see there!

When equipped, the **Suspicious Weather Balloon** grants the _Punch Range: Suspicious Weather Balloon_ mod, which allows the player to punch one tile further.
