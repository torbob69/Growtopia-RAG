# Pointy Sign

This sign includes a bit of added information - an arrow! The arrow points whichever direction you are facing when you place the sign.
Pointy Sign (Rarity: 4)
Properties
This item has special properties you can adjust with the Wrench.
This item can be placed in two directions, depending on the direction you're facing.

The **Pointy Sign** is a splicable non-solid sign foreground block which has been added since Growtopia's launch.
##  Function
Being a sign, a Pointy Sign allows players with access to it to edit its message for other players to view.
