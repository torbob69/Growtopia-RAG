The **Dummy Item for Checkout Counter Dialog** is an unobtainable and untradeable component which was added as part of Store Wars update on January 2, 2020.
##  Function
This item serves as an image placeholder for Vending Hub - Checkout Counter menu, which can be seen when the inside of the DigiVend Machine is empty or sold out.
##  Trivia
  * Dummy Item for Checkout Counter Dialog uses the same sprite as DigiVend Machine.
