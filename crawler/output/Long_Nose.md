# Long Nose

Be the Growtopian with the long nose who knows! Just don't go sticking it into other peoples business!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Face – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Mining

1 has a chance to be dropped from exploding  Pure Magic Ore using  Mining Explosives, which are naturally generated in mines.
The **Long Nose** is an unsplicable face item which was added as part of Player Appreciation Week 2020 Day 7.
##  Function
When equipped, the Long Nose serves a purely cosmetic purpose, giving the player a long nose.
##  Trivia
  * The Long Nose is one of the three clothing items added on Player Appreciation Week 2020 Day 7 obtainable via breaking Pure Magic Ores, alongside the Handlebar Mustache.
