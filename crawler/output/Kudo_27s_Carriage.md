**Kudo's Carriage** is a feet item which was the May 2017's Item Of The Month.
##  Function
You can jump in mid-air! It's like flying, but less.

Gravity - it's the law.

When equipped, the **Kudo's Carriage** grants the _Double Jump_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * Before the item came out, it was going to be given the Speedy mod but was later changed to the Double Jump mod.
  * Kudobelle sponsored this item by being the second Growtopian to complete all Epic Quests.
  * Kudo's Carriage is the only sponsored item whose sponsor's name is written using an abbreviation. Kudobelle was abbreviated as Kudo.
