The **Dragon Gate** is a splicable toggleable foreground block which has been added since Growtopia's launch.
##  Function
Being a toggleable foreground block, a Dragon Gate works like a Fissure, allowing eligible players to open and close the Dragon Gate by punching it. When toggled on, the item acts as a solid block which players cannot pass while killing all players trapped inside it. When toggled off, it opens and acts as a non-solid block which players can walk through. It can be wrenched to be made public or not.
Step 4 of the  Quest For Fire requires the player to deliver 600 of this item.
