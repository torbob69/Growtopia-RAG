The **Stinky Ogre Ears** is an unsplicable hat item which was added as part of Halloween Week 2023 on October 19, 2023.
##  Function
Just like an onion!

Peeling back the layers!

When equipped, the **Stinky Ogre Ears** grants the _Orge skin: Stinky Orge Ears_ mod, which allows the player to change their skin color to green.
##  Trivia
  * The item itself is a reference to the main character of a 2001 American animated fantasy comedy film, Shrek.
