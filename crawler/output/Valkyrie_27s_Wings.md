# Valkyrie's Wings

Flawless warrior wings for an unstoppable Chooser of the Slain!
Properties
This item never drops any seeds.

Type: Back – Clothes

Treasure Hunting

Has a chance to be obtained from completing a Map of Loki.
The **Valkyrie's Wings** is an unsplicable back item which was added as part of Player Appreciation Week 2019 Day 4 on August 22, 2019.
##  Function
Valhalla awaits!

Time to feast!

When equipped, the **Valkyrie's Wings** grants the _Double-Jump: Valkyrie_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * This item is considered a part of the Valkyrie set, which consists of the following items:

    * Valkyrie's Helm (hat)

    * Valkyrie's Cuirass (shirt)

    * Valkyrie's Sandals (feet)

    * Valkyrie's Wings (back)
