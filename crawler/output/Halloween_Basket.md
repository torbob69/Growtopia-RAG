# Halloween Basket

A basket of treats stacked from candy earned by performing tricks during Halloween. You can use to trade for gifts from the Shady Salesman in Growganoth.
Properties
This item cannot be dropped or traded.
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Double Tap/Click in Inventory

Made by double-tapping/clicking  Halloween Candy **(×100)** in one's inventory.
Always creates **1** item each.
The **Halloween Basket** is an unsplicable component which was added as part of Halloween Week 2022 on October 22, 2022.
##  Function
Just like Halloween Candy, the Halloween Basket can be used to purchase items from the Shady Salesman. A Halloween Basket has the same value as 100 Halloween Candy.
