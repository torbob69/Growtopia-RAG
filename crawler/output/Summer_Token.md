The **Summer Token** is an unobtainable component that was added as part of Summer Clash 2018.
##  Function
The Summer Token item was added as a placeholder for Summer Clash's main currency, which can be obtained by reaching milestone points during a Grow Event while a Summer Clash is still ongoing. They can be used to purchase items on the Summer Clash Rewards Store.
This item cannot be obtained in the player's inventory by regular means, as collected Summer Tokens are stored in a separate entry in the player data.
