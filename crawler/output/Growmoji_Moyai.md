# Growmoji Moyai

Feeling like a Easter Island Head? Prove it with this growmoji! Just consume to add it to your available growmojis!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Discord Exclusive Item

Given exclusively to players who won a giveaway on Growtopia Discord server.
The **Growmoji Moyai** is an unsplicable growmoji consumable which was added as part of Player Appreciation Week 2022 Day 4 on August 18, 2022.
##  Function
When consumed, the player will be able to use the (moyai) Growmoji.
