# Courage Mooncake

This pastry is filled with a sweet lotus paste. "Courage" is imprinted on the top in ancient Growtopian script.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Harvesting

Harvest a  Courage Shrub Tree.__
The **Courage Mooncake** is an unsplicable consumable which was added as part of Harvest Festival 2023 on September 21, 2023.
##  Function
Attempting to eat a Courage Mooncake will make the player say "_Looking at this fills you with Determination, but you'd better not eat it._ "
