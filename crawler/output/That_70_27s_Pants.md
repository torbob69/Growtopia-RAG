**That 70's Pants** is an unsplicable pants item which was added as part of Player Appreciation Week 2023 Day 7 on September 3, 2023.
##  Function
When equipped, That 70's Pants serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the That 70's set, which consists of the following items:

    * That 70's Jacket (shirt)

    * That 70's Pants (pants)
