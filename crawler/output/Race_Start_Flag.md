The Race Start Flag is a non-solid block, introduced along with the Racing Action Pack.
##  Function
When a player walks through the item, a timer will begin, ending when they walk through a Race End Flag. If the player dies, the timer will be removed. The player's resulting time will be displayed in the chat to all players in the world.
