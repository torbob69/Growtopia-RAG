The **Pocong Statue** is an unsplicable non-solid foreground block which was added as part of Garuda's Glory 2023 on August 17, 2023.
##  Function
When placed, the Pocong Statue serves a purely aesthetic purpose.
##  Trivia
  * The Pocong Statue is a reference to a Javanese ghost of the same name that is said to be the soul of a dead person trapped in their shroud.
