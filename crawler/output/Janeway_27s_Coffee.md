# Janeway's Coffee

Taste Janeway's favorite drink! When consumed, you will recieve a temporary Speedy mod!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Coffee **(×1)** ,
Rocket Thruster **(×1)** and
Steel Block **(×1)**.
This recipe will yield **1** item.
The **Janeway's Coffee** is an unsplicable consumable which was added as part of Star Trek Prodigy on June 27, 2022.
##  Function
On my mark... Go Fast!

Speed normalized!

When consumed, Janeway's Coffee grants the _Janeway's Coffee: Speedy_ mod, which allows the player to move faster on land. This mod lasts for 10 minutes.
