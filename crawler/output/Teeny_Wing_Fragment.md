# Teeny Wing Fragment

This is about an eighth of a Teeny Devil Wing. So if you had 16 of these, you could make a pair of Teeny Devil Wings!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **3 Hits** **3 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Rewards of Sacrifice

Sacrifice a(n)  Teeny Angel Wings or  Dark King's Offering (chance) to Growganoth.
The **Teeny Wing Fragment** is a consumable which was added during Halloween Week 2015.
