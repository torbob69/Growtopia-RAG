The **Spelunker's Headlamp** is an unsplicable hat item which was added as part of the Spelunkorama! update.
##  Function
When equipped, the **Spelunker's Headlamp** grants the _Light Source_ mod, which allows the player to emit light in dark areas. It will also illuminate a slightly bigger area when compared to a Flashlight.
