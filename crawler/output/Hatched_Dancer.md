The **Hatched Dancer** is an unsplicable hat item which was added as part of Easter Week 2024 on April 7, 2024.
##  Function
Away from the nest!

Hatched this way!

When equipped, the **Hatched Dancer** grants the _Build Range: Hatched Dancer_ mod, which allows the player to build one tile further.
