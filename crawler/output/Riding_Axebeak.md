The **Riding Axebeak** is an unsplicable feet item which was added as part of the Dungeons update on December 9, 2024.
##  Function
This is going to be Axe-citing!

It was an Axe-cident!

When equipped, the **Riding Axebeak** grants the _Speedy + High Jump: Riding Axebeak_ mod, which allows the player to move faster on land and jump one tile higher.
