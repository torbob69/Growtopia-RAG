# Guild Lock

Locks an entire world for the guild. Use your wrench to set guild member and non-member access. The guild lock cannot be broken.

##  Function
_For more information on guilds and how they work, seeGuilds._
In order to create a guild, a player must be in a world that they own. They will be able to create a guild by going through the Social Portal and selecting the "Create Guild" button. Creating a guild costs 200,000 Gems each (or 100,000 for Super Supporters) and requires either the Supporter or Super Supporter status. Before the 200,000 Gems are deducted from the player's balance, the player must first choose a guild name (which can be changed later with a Guild Name Changer) and insert a guild statement (which can also be changed later, at no additional cost).
When a guild has been created, a Guild Lock will be created in the world lock's place. The latter will immediately return to the player's inventory. As a type of world lock itself, a Guild Lock has all the basic properties of a regular World Lock. The lock's appearance changes to reflect its corresponding guild's level.
Unlike the other types of locks, a Guild Lock cannot be broken by the player. The only method to move a Guild Lock to another world is through the use of a Change of Address. It can also be moved to a different spot in the same world using a Lock Mover.
