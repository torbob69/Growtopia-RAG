# Villain Portrait

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.

A Villain Portrait is a portrait of a villain which a player has defeated. It is a possible drop from successfully defeating its respective villain. There is one portrait for each villain.
