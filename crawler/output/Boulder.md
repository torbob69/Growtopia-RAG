It can be found naturally generated in Desert-blasted worlds.

The **Boulder** is an unsplicable solid foreground block which was added as part of the Rise of the Desert Dragons update on August 3, 2013.
##  Function
When placed, the Boulder serves a fully aesthetic purpose.
