The **Iron Maiden** is an unsplicable toggleable foreground block which added as part of Halloween Week 2017 on October 30, 2017.
##  Function
Being a toggleable foreground block, an Iron Maiden works like a Dragon Gate, allowing eligible players to open and close the Iron Maiden by punching it. When toggled on, the item acts as a solid block which players cannot pass while killing all players trapped inside it. When toggled off, it opens and acts as a non-solid block which players can walk through. It can be wrenched to be made public or not.
