# Riding Bull

YEEHAW! Saddle up this bucking bull and charge its horns for maximum fury! This beastly bovine is none too happy to have a rider, so make sure you take its fury out on your foes, instead!
Properties

This item can be transmuted.

The **Riding Bull** is an unsplicable feet item which was added as part of the Role Up! update.
##  Function
Bull smash!

Bull needs a nap!

When equipped, the **Riding Bull** grants the _Punch Damage: Bull_ mod, which allows the player to break blocks faster.
