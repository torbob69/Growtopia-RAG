# Farmability Guide

This page is a list of items which can be farmed.
All items that grow on trees have a drop chance, this is always a multiple of four, four being the lowest. If a tree can only drop a maximum of four, it is considered "not farmable". If it can drop a maximum of eight, twelve or more, then it is considered a farmable.
