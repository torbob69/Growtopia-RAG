# Wool Scarf

Your neck is toasty warm. Maybe you should put some pants on too.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Chest – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Wool Bolt.
Sew a  Silk Bolt - Grey to the previous bolt using a(n) **Locking Stitch**.
Lastly, sew a  Wool Bolt to the previous bolt using a(n) **Triple Stretch Stitch**.
Each recipe gives **1** item.
**Wool Scarf** is a neck item that was added with Harvest Festival 2016. It is made by sewing. If a player makes it for the first time, they will get the _"Sew a Wool Scarf"_ Epic Quest.
