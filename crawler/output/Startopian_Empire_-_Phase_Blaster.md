**Startopian Empire - Phase Blaster** is an unsplicable hand item which was added in the Startopia update on July 1, 2018.
##  Function
Phaser set to "punch"!

Battery at 0%

When equipped, the **Startopian Empire - Phase Blaster** grants the _Phase Blaster_ mod, which allows the player to knock back other players further. It will also replace the player's punching animation with a green laser which appears as red to other players.
