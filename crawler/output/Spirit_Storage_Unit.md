The **Spirit Storage Unit** is a splicable non-solid spirit storage foreground block which was added as part of the Battlers Of the Otherworldly update on July 15, 2016.
##  Function
A Spirit Storage Unit is used to store Ghosts by dropping them on the block and sending steam power through it.
One Ghost-In-A-Jar will fill up the Spirit Storage Unit by 5%. After reaching 100%, any ghost added afterwards has a chance to explode the machine and give a random B.O.O item, increasing the chance to explode the machine per ghost added.
