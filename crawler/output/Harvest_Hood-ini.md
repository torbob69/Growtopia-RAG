The **Harvest Hood-ini** is an unsplicable hat item which was added as part of Harvest Festival 2021 on September 16, 2021.
##  Function
Now you see me!

Now you don't!

When equipped, the **Harvest Hood-ini** grants the _Speedy : Harvest Hood-ini_ mod, which allows the player to move faster on land. The Harvest Hood-ini will disappear when a player who wears it stands still for some while. It will reappear when the player moves or does an action like punching.
