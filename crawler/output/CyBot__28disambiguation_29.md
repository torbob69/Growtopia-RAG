# CyBot (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
The **CyBot** is an unsplicable NPC. There are 5 different cybots in Growtopia:
Items: RecipeShockBot: 1 can be obtained from purchasing the CyBlocks Starter Pack for 5,000 gems in the Growtopia Store.
SearBot: 1 has a chance to be obtained from the Summer Planner (#10 Personal) tier.
ShooterBot: 1 has a chance to be obtained from purchasing the CyBot Pack for 15,000 gems in the Growtopia Store.
