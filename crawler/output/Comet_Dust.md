# Comet Dust

This is the sparkly dust from a passing comet. It seems to whirl around like a tiny galaxy. Perhaps if you collected enough of it, it would merge into a solid mass!

##  Trivia
  * Picking up a Comet Dust for the first time will give the player the _Sparkly Dust_ achievement.
  * Consuming 200 Comet Dust for the first time will give the player the _We Are All Stardust_ achievement.
