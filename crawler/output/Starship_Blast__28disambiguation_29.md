# Starship Blast (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
The **Starship Blasts** are blasts added in the Startopia Update which generate starship worlds when used. These worlds are required in order to perform Star Voyages.
