This item does not have any recipe because it is no longer, or was never obtainable.
The **Pure Magic Ore** is an unbreakable solid foreground block that was added as part of the Spelunkorama Strikes Back! update.
##  Function
Unlike most blocks, a Pure Magic Ore cannot be broken by being punched. A Mining Explosives block needs to be placed next to it and detonated for the block to be destroyed.
