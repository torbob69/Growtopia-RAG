# My First World Lock

This is the page for **My First World Lock**.
You may be looking for **World Lock** instead.
Locks an entire world. Place it in your world to keep it safe from other players breaking your stuff. It doesn't prevent them entering though, so be sure to add a door if you don't want others around.
Properties
This item never drops any seeds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item cannot be dropped or traded.
This item has special properties you can adjust with the Wrench.
A lock makes it so only you (and designated friends) can edit an area.

Tutorial

One of this item is obtained by a new player while accomplishing the tutorial.
**My First World Lock** is an unsplicable solid lock foreground block which was added as part of the Tutorial Improvements update on May 1, 2020.
##  Function
My First World Lock has the appearance and function of a World Lock, except that it is untradable to prevent players from creating multiple accounts to obtain them. Unlike the latter, My First World Lock cannot be used in Vending Machines.
