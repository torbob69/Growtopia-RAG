# Luchador Announcer

A new challenger enters the ring! Summons the villain "El Peligro"...
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **3 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Pinata Bash

Participate in successfully smashing an  Ultra Pinata during the **Pinata Bash!** event.
May give **1** item each time.
The **Luchador Announcer** is an unsplicable consumable which was added as part of Cinco De Mayo Week 2017 on May 5, 2017.
##  Function
When consumed on a tile, this item summons El Peligro on the tile.
