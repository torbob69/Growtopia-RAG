# Greezak Horde Starship Helm - Mk.III

Hunt down your prey with speed and savagery from behind the Greezak Horde helm! Provides a Ship Rating of 2640. One of three components - Helm, Viewscreen, and Reactor - needed to fly a starship. Wrench this to start a Star Mission (but make sure you have enough Star Tools)!
Properties
This item has special properties you can adjust with the Wrench.
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

**Greezak Horde Starship Helm - Mk.III** is an unsplicable block which was added in the Startopia Update.
##  Function
When placed in a Starship, it will provide a Ship Rating of 2640. One must wrench this to start a Star Mission.
