# Reliable Anomarod

Built to exacting specifications by GrowTech engineers to find and remove temporal anomalies from infected fish, and guaranteed to never break!

Breaking Anomalizers

Can be obtained from breaking  Pristine Anomarod.
The **Reliable Anomarod** is an unsplicable hand item which was added as part of Summer Clash Series 1.
##  Function
Reliable Anomarods are used to score points during Fishing Fanatics. While equipping this item, each fish caught yields 3,400 points. Reliable anomalizers, such as this item, will not break upon usage.
