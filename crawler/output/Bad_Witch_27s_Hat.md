A wicked hat for someone who loathes it all, every little trait, however small!

The **Bad Witch's Hat** is an unsplicable hat item which was added as part of Halloween Week 2024 on October 23, 2025.
##  Function
When equipped, the **Bad Witch's Hat** allows the player to change their skin color to green.
##  Trivia
  * This item is considered a part of the Bad Witch set, which consists of the following items:

    * Bad Witch's Hat (hat)

    * Bad Witch's Dress (shirt)
  * The full Bad Witch set is a reference to a fictional character called Elphaba Thropp, from the movie Wicked.
