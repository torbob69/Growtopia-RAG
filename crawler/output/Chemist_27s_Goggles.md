# Chemist's Goggles

The perfect eyewear for doing chemistry! Grants a 10% chance to not consume a chemical when you use a Chemsynth tool.
Properties
This item never drops any seeds.
Data

Type: Face – Clothes
Render Type: Single

Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Daily Challenge

Place in the top three of the **Chemical Conundrum** Daily Challenge.
The **Chemist's Goggles** is an unsplicable face item which was added as part of the Night Of The Chemicals update.
##  Function
When equipped, the **Chemist's Goggles** allows the player to increase the odds of not consuming a chemical when using a Chemsynth tool by 10%.
