The **Red Pet Tyranodon** is an unsplicable hand item which was added as part of Growassic Park on October 7, 2016.
##  Function
When equipped, the Red Pet Tyranodon serves a purely cosmetic purpose and summons a Red Pet Tyranodon which follows the player around.
