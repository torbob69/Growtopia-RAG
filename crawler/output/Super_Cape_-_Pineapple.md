The **Super Cape - Pineapple** is an unsplicable back item which was added as part of Super Pineapple Party 2015 on May 30, 2015.
##  Function
You can jump in mid-air! It's like flying, but less.

Gravity - it's the law.

When equipped, the **Super Cape - Pineapple** grants the _Double Jump_ mod, which allows the player to jump a second time in mid-air.
##  Trivia
  * The description of this item refers to the Heroman Cape.
  * Due to a developer oversight, Super Cape - Pineapple didn't grant its user the _Double Jump_ mod when it was first released.[[1]](https://growtopiawiki.com/w/Super_Cape_-_Pineapple#cite_note-1)
