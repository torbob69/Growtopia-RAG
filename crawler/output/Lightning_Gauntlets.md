# Lightning Gauntlets

Stores magic energy and then releases it in a bolt of lightning from your fingertips. Like a sith lord but cooler.
Properties
This item never drops any seeds.
This item can be transmuted.

**1h**
Mining

1 has a chance to be dropped from exploding  Pure Magic Ore using  Mining Explosives, which are naturally generated in mines.
The **Lightning Gauntlets** is an unsplicable hand item introduced during the Spelunkorama Strikes Back! update.
##  Function
Like a jedi but cooler.

Your fingers still tingle.

When equipped, the **Lightning Gauntlets** grants the _Build Range: Lightning Gauntlets_ mod, which allows the player to build one tile further. Additionally, it replaces the player's punching animation with lightning.
