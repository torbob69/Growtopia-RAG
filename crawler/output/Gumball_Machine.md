The **Gumball Machine** is an unsplicable non-solid provider foreground block which was added as part of the Grow4Good Week 2026 on April 24, 2026.
##  Function
When a Gumball Machine is harvested by being punched, it drops 1-2 Bubble Gums. It can be harvested approximately every 22 hours.
