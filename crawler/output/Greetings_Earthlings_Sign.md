# Greetings Earthlings Sign

How nice, the aliens decided to set up signs greeting us!
Properties
This item never drops any seeds.
This item has special properties you can adjust with the Wrench.
Data: Paint PreviewType — Sign – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single
Collision Type: No Collision
Hardness: **6 Hits** **5 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Consumption

Consume a(n)  Alien Landing Pod **(x1)**.
May yield **2** item each.

The **Greeting Earthlings Sign** is an unsplicable sign which was added as part of the Aliens update on November 14, 2021.
##  Function
Being a sign, a Greetings Earthlings Sign allows players with access to it to edit its message for other players to view.
