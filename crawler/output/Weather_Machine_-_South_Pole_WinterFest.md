The **Weather Machine - South Pole WinterFest** is an unsplicable non-solid weather machine foreground block which was added as part of WinterFest 2025 on December 18, 2025.
##  Function
As a weather machine, the Weather Machine - South Pole WinterFest can be toggled on or off via punching. When toggled on, it will change its appearance, transforming the world's background.
