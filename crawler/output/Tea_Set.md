The **Tea Set** is a splicable non-solid provider foreground block which was added as part of Harvest Festival 2017.
##  Function
The Tea Set is a type of provider. When a Tea Set is harvested (by being punched), 1-2 Tea will drop. One can be harvested every 21-24 hours.
The Tea Set also has a small chance to drop 1 Antique Tea Caddy instead.
