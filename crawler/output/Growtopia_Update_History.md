# Growtopia/Update History

< Growtopia
**Updates** are a bundle of changes to the official _Growtopia_ game client that are released periodically by Ubisoft. Updates to _Growtopia_ may add, remove, or tweak features such as blocks, clothes, consumables, and game mechanics.
This page includes an updated list of updates which were made into _Growtopia_.

  * On September 27, 2020, an official Growtopia Discord server was announced for players to join.
  * The Steam release allows underscores in your username, but not periods.
