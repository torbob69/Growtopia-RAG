The **Needlessly Cryptic Scroll** is an unsplicable component which was added as part of SummerFest 2015 on July 3, 2015.
##  Function
This item serves as a key element in The Wizard's Staff Mystery.
##  Trivia
  * The instructions to create a Needlessly Cryptic Scroll can be found by using a Shifting Scroll.
  * This item shares the same recipe as the Cryptic Scroll, Really Cryptic Scroll and Exceedingly Cryptic Scroll. Each attempt to make one would give the player a random scroll out of the four.
  * When created, the player will be frozen for a moment, preventing them from making more scrolls.
