# Healing Station Checkpoint

Every good battle field needs one of these. Remember, if you die, you'll respawn at the last checkpoint you touched!

The **Healing Station Checkpoint** is an unsplicable non-solid checkpoint foreground block which was added as part of Grow4Good Week 2023 on April 20, 2023.
##  Function
Being a checkpoint block, the Healing Station Checkpoint acts as where the player respawns after dying.
After going through a Race Start Flag and then through a Race End Flag, all checkpoints will be reset and the player would respawn at the Main Door on death. The same goes with the Challenge Timer and /kick, /kickall command.
