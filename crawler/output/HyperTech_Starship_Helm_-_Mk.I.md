# HyperTech Starship Helm - Mk.I

Blast off into the great unknown at ludicrous speeds with the HyperTech helm as your navigator! Provides a Ship Rating of 4200. One of three components - Helm, Viewscreen, and Reactor - needed to fly a starship. Wrench this to start a Star Mission (but make sure you have enough Star Tools)!
Properties
This item has special properties you can adjust with the Wrench.
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

**HyperTech Starship Helm - Mk.I** is an unsplicable non-solid starship foreground block which was added in the Startopia Update.
##  Function
When placed, _Hypertech Starship Helm - Mk.I_ acts as a console to start Startopia missions as well as increase the ships rating by 4200.
