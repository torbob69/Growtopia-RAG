# Chic White Dress

Not just any white dress! If you couldn't already tell by how pretty this looks, we've carefully added the word 'chic' in the title to let everyone know the style here is off the charts!
Properties
This item never drops any seeds.
Data

Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - White.
Sew a  Silk Bolt - White to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Wool Bolt to the previous bolt using a(n) **Locking Stitch**.
Each recipe gives **1** item.
The **Chic White Dress** is an unsplicable shirt item which was added as part of Player Appreciation Week 2019 Day 3 on August 21, 2019.
##  Function
When equipped, the Chic White Dress serves a purely cosmetic purpose.
