# White Tuxedo

When you want to stand out in a crowd of penguins (or investment bankers) without ruining the super-classy mood, try on this bright and beautiful tux!
Properties
This item never drops any seeds.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - White.
Sew a  Silk Bolt - Black to the previous bolt using a(n) **Triple Stretch Stitch**.
Lastly, sew a  Wool Bolt to the previous bolt using a(n) **Saddle Stitch**.
Each recipe gives **1** item.
The **White Tuxedo** is an unsplicable shirt item which was added as part of Player Appreciation Week 2019 Day 3 on August 21, 2019.
##  Function
When equipped, the White Tuxedo serves a purely cosmetic purpose.
##  Trivia
  * White Tuxedo is a recolored version of  Salmon Suit & Blue and Black Tuxedo.
