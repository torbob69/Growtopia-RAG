**Cave Dirt** is a solid foreground block which is naturally found in Cave Blasted worlds. It was introduced during the Spelunkorama! update.

##  Trivia
  * The item's description is a reference to Dirt.
  * Placing 2 Cave Dirts will cause them to connect, thus creating a continuous pattern.
  * A Mining Mech will allow the player to break Cave Dirt and Dark Cave Background in one hit.
