Hold this cane and you'll be in a world full of pure imagination!

The **Creepy Chocolatier's Cane** is an unsplicable hand item which was added as part of Halloween Week 2023 on October 19, 2023.
##  Function
Taste the rainbow!

Have a break!

When equipped, the **Creepy Chocolatier's Cane** grants the _Punch Range: Creepy Chocolatier's Cane_ mod, which allows the player to punch one tile further.
##  Trivia
  * This item is considered a part of the Creepy Chocolatier set, which consists of the following items:

    * Creepy Chocolatier's Hat (Hat)

    * Creepy Chocolatier's Cut (Hair)

    * Creepy Chocolatier's Spectacles (Face)

    * Creepy Chocolatier's Robe (Shirt)

    * Creepy Chocolatier's Shoes (Feet)

    * Creepy Chocolatier's Cane (Hand)
  * The full Creepy Chocolatier set is a referance to a fictional character called Willy Wonka, from movie: Charlie and the Chocolate Factory.
