# Cursed Jet Engine

If the sky were to suddenly open up, there would be no law, there would be no rule. There would only be you and your memories.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **3 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Easter Egg - Jagged **(×1)** ,
Easter Egg - Wavey **(×1)** and
Easter Egg - Dark **(×5)**.
This recipe will yield **1** item.
The **Cursed Jet Engine** is an unsplicable consumable which was added as part of Easter Week 2015.
##  Function
When consumed, the item summons Bunny Barko, an Easter Week villain.
##  Trivia
  * The item's description is a reference to a quote by the fictional character Lilian Thurman from the 2001 movie _Donnie Darko_.
