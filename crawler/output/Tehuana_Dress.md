# Tehuana Dress

Wear this beautiful floral dress!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Black.
Sew a  Silk Bolt - Red to the previous bolt using a(n) **Overcasting Stitch**.
Lastly, sew a  Silk Bolt - Aqua to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **Tehuana Dress** is an unsplicable shirt item which was added as part of Cinco De Mayo Week 2023 on May 5, 2023.
##  Function
When equipped, the Tehuana Dress serves a purely cosmetic purpose.
