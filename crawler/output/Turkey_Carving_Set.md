# Turkey Carving Set

Reach out and get a handle on the holidays with a turkey touch! Gobble gobble gobble!

The **Turkey Carving Set** is an unsplicable hand item which was added as part of Thanksgiving Week 2017 Day 5 on November 27, 2017.
##  Function
When equipped, the Turkey Carving Set serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Turkey set, which consists of the following items:

    * Turkey Onesie Hood (Hair)

    * Turkey Onesie Beak (Face)

    * Turkey Onesie Body (Shirt)

    * Turkey Onesie Legs (Pants)

    * Turkey Onesie Feet (Feet)

    * Turkey Onesie Tail (Back)

    * Turkey Carving Set (Hand)
  * In 2017, the Turkey Carving Set could be obtained as a random drop by smashing blocks on the fifth day of Thanksgiving Week 2017.
