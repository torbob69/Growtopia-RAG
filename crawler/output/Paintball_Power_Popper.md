The **Paintball Power Popper** is an unsplicable hand item which was added as part of Spring Clash 2019 on March 1, 2019.
##  Function
Time to paint!

Safety first!

When equipped, the **Paintball Power Popper** grants the _Build Range: Paintball_ mod, which allows the player to build one tile further and paint blocks in areas they are accessed to.
Compared to the Paintbrush, however, the Paintball Power Popper has the advantage of being able to temporarily paint other players, as well as the player themself. When a paint is consumed on a player, that player will receive the _Paintball_ mod, which lasts for 5 seconds. Using Paint Bucket - Varnish on a painted player will immediately wear off the paint.
Painting a block uses up a paint bucket, whereas painting another player doesn't cost the user in any way. Moreover, the user isn't restricted to only painting players in worlds they own.
##  Trivia
  * Attempting to paint blocks in areas one isn't accessed to will give the message, "_Don't tag people's worlds._ "
  * The message which appears in the chat when the _Paintball_ mod gets added says, "_You've been painted!_ ", while the removed message says, "_The paint's been absorbed!_ "
