# Honey

The sweet nectar of bee spit! Bees also craft plastic bear shapes to store it in. Nobody knows why.
Properties
This item never drops any seeds.

The **Honey** is an unsplicable consumable which was added as part of Player Appreciation Week 2016.
##  Function
When consumed, the player will say "YUM!" and do the :D ⦅⦆ emote.
