# Radioactive Chemical

This is a dangerous chemical that emits radiation. You probably shouldn't keep it in your pants pocket.
Properties
This item never drops any seeds.
This item has no use... by itself.
Data

Type: Component
Render Type: Single

Gems Drop: **N/A**
**1h**
Hunting

1 may be obtained by using a  Geiger Counter.
The **Radioactive Chemical** is an unsplicable component that was introduced along with the Superhero Pack.
##  Function
Being a type of chemical, the Radioactive Chemical can be used for combining alongside two other types of chemicals in a Chemical Combiner to create certain items.
