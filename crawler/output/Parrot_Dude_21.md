The **Parrot Dude!** is an unsplicable hand item which was added as part of SummerFest 2022 on July 28, 2022.
##  Function
Skating Buddy!

Crashed!

When equipped, the **Parrot Dude!** grants the _Build Range: Parrot Dude!_ mod, which allows the player to build one tile further.
##  Trivia
  * The Parrot Dude!'s description mentions Tony Parrote, a reference to an American professional skateboarder, Tony Hawk.
