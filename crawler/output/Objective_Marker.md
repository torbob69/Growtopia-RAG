# Objective Marker

Use these sort of like Doors - They have IDs, so Doors can lead to them, though you can't travel from them. Use your wrench to set their ID.
Properties
This item never drops any seeds.
This item has special properties you can adjust with the Wrench.

Purchased from Sales-Man

Buy this item from the  Sales-Man ( 53785) for  Zombie Brain **(x50)**.
Each purchase comes with **3** items.
The **Objective Marker** is an unsplicable non-solid marker foreground block which was added as part of the Night of the Sewing Dead update.
##  Function
It functions the same as a Path Marker, where players can set a door ID for it.
