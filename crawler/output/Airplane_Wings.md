The **Airplane Wings** is an unsplicable back item which was added as part of Spring Clash 2019 on March 1, 2019.
##  Function
Hooah!

Back in the hangar!

When equipped, the **Airplane Wings** grants the _Double-Jump: Aim High_ mod, which allows the player to jump a second time in mid-air.
