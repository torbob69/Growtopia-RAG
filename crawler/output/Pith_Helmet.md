##  Trivia
  * The description of this item is a reference to a quote from the 1984 film _Indiana Jones and the Temple of Doom_, which states, "And you, sir, are Dr. Jones, I presume."[[1]](https://growtopiawiki.com/w/Pith_Helmet#cite_note-1)
  * This item is considered a part of the adventurer set, which consists of the following items:

    * Pith Helmet (hat)

    * Explorer's Ponytail (hair)

    * Adventuring Mustache (face)

    * Safari Jacket (shirt)

    * Jodhpurs (pants)

    * Explorer's Shovel (hand)
