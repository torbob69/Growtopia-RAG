The **Sunnyside Yolkfall** is an unsplicable foreground block which was added as part of Easter Week 2023 on April 7, 2023.
##  Function
Being a type of vertical one side collision block, the **Sunnyside Yolkfall** allows players to pass through the block downwards but blocks them from passing the block upwards.
