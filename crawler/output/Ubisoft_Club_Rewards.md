# Ubisoft Club Rewards

The **Ubisoft Club Rewards** was a feature available only to the discontinued console edition of Growtopia. As part of the Voucher Dayz update, all Console-exclusive rewards that were previously obtained from this feature would be released to the mobile/PC version of Growtopia through the Console Classix Pack.
The **Ubisoft Club Rewards** added into consoles at Console Edition's launch 18 July, 2019
