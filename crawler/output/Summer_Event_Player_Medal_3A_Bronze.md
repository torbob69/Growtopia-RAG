# Summer Event Player Medal: Bronze

Awarded for achieving THIRD PLACE in the Player Leaderboards during the Summer season. Show off your victory by placing this medal in your world, and congratulations!
Properties
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item cannot be dropped or traded.

The Summer Event Player Medal: Bronze is an item added alongside the Summer Clash Update. It is awarded to players who place third in a Summer Clash event on the Personal Event Leaderboard.
##  Function
A Summer Event Player Medal: Bronze behaves as a platform, thus a player can jump pass through it from underneath.
