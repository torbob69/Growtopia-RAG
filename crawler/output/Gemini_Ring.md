# Gemini Ring

This ring is imbued with astrological power. It makes you a twin!

The **Gemini Ring** is an unsplicable hand item which was added as part of The Carnival update on October 13, 2014.
##  Function
When equipped, the Gemini Ring does not grant any mod, but it creates a full-sized leash of the player themself.
