# Emperor's New Robes

Look like the Emperor of the ancient world with these fancy robes!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Black.
Sew a  Silk Bolt - Red to the previous bolt using a(n) **Overcasting Stitch**.
Lastly, sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **Emperor's New Robes** is an unsplicable shirt item which was added as part of Lunar New Year 2023 on January 21, 2023.
##  Function
When equipped, the Emperor's New Robes serves a purely cosmetic purpose.
