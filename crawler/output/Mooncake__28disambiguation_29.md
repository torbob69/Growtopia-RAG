# Mooncake (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
**Mooncakes** come in seven types that can each be obtained from any tree during the Harvest Festival. The rarer the tree, the higher the chance of it spawning a Mooncake, but _not_ a Songpyeon, Ancestor Mooncake or a Purity Mooncake.
