# Mage's Bookcase

A bookcase sealed by a magic so powerful it does not allow for the removal of any books.
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.
Data: Paint PreviewType — Platform – Foreground — Aqua Blue Charcoal Green Purple Red Varnish Yellow
Render Type: Single
Collision Type: Collision on top
Hardness: **10 Hits** **8 Hits** – Restores after **3s** of inactivity
Gems Drop: **N/A**
**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
Dungeons

It can be found naturally generated in Dungeon worlds.

Dungeons Reward

2 may be awarded to the player for completing a Dungeon at **Silver Tier or higher**.
The **Mage's Bookcase** is an unsplicable non-solid platform block which was added as part of the Dungeons update on December 9, 2024.
##  Function
When placed, the Mage's Bookcase serves a fully aesthetic purpose.
