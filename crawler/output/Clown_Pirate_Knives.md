##  Function
A taste of the terror!

Time to exit stage left!

When equipped, the **Clown Pirate Knives** grants the _Punch Range + Punch Damage : Clown Pirate Knives_ mod, which allows the player to punch one tile further and break blocks faster.
##  Trivia
  * This item is considered a part of the Clown Pirate set, which consists of the following items:

    * Clown Pirate Hat (Hat)

    * Clown Pirate Makeup (Face)

    * Clown Pirate Cloak (Back)

    * Clown Pirate Shirt (Shirt)

    * Clown Pirate Pants (Pants)

    * Clown Pirate Shoes (Feet)

    * Clown Pirate Knives (Hand)
  * The full Clown Pirate set is a reference to a character named Buggy the Star Clown, who is from a Japanese manga series called One Piece.
