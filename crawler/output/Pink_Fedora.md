The **Pink Fedora** is an unsplicable hat item that was added as part of the Locke The Traveling Salesman update on March 22, 2015.
##  Function
When equipped, the Pink Fedora serves a fully cosmetic purpose.
##  Trivia
  * This item is considered a part of the Locke The Salesman set, which consists of the following items:

    * Pink Fedora (hat)

    * Distinguished Grey Hair (hair)

    * Pencil Mustache (face)

    * Pink Suitcoat (shirt)

    * Fancy Pants (pants) .
  * Equipping the set completes the _"Dress up asLocke The Salesman"_ Epic Quest.
  * The  Pink Fedora is a retexture of the  Old-Timey Hat.
