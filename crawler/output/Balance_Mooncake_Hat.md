# Balance Mooncake Hat

What better to wear when hunting for Mooncakes than a Mooncake hat! There's one for each Mooncake type so keep a look out for all of them.
Properties
This item never drops any seeds.
This item can be transmuted.

The **Balance Mooncake Hat** is an unsplicable hat item that was added as part of Harvest Festival 2020 on September 24, 2020.
##  Function
When equipped, the **Balance Mooncake Hat** serves a purely cosmetic purpose.
