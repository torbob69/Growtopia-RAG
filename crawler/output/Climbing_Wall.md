Install this right next to walls. It will add bumps and grooves for Climbing Boots to latch onto, so people can climb the wall with the right tools!

The **Climbing Wall** is a non-solid block which was added as part of the Spelunkorama! update on May 2, 2016.
##  Function
When placed against a vertical wall, players can cling onto Climbing Walls by holding their jump when using one of the following items:
  * Claws of Barko
  * Climbing Boots
  * Climbing Picks
  * Ezio's Boots
  * Mountain Boots
  * S.P.I.D.E.R. Legs
  * Tarantula Legs
  * Will of the Wild (earth version)
