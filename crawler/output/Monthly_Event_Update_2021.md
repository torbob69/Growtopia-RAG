# Monthly Event Update 2021

Growtopia Gazette
> Monthly Event Update!
> Today we're launching one of multiple small Monthly Event revamps, starting with All Howl's Eve! But you will see new additions to Surgery Day, Mutant Kitchen and last but not the least, the Carnival! Once one of these updated events starts, you can find a description in the store, including which new items were added!
> And remember, the new Item of the Month Soul Scythe is still available! Don't miss out!

Multiple **Monthly Event** revamps are planned for 2021, including new additions to All Howl's Eve, Surgery Day, Mutant Kitchen, and the Carnival.[[1]](https://growtopiawiki.com/w/Monthly_Event_Update_2021#cite_note-1) The updates were officially announced on July 21, 2021, the same day as the update to All Howl's Eve.
