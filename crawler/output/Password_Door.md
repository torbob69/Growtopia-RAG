The **Password Door** is a non-solid door foreground block which was added alongside Lokster Hair and G-Virus in version 1.20.2 on May 11, 2013.
##  Function
As a door, the Password Door can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
A Password Door, however, is different from normal doors in the sense that it requires a password which can be set by any player with access to the block. If any player inserts the correct password, they will be redirected to the set location. If an incorrect password is entered, though, the player will not pass through.

##  Trivia
  * The idea of a Password Door was first suggested by ex-moderator Seil in a forum post.[[1]](https://growtopiawiki.com/w/Password_Door#cite_note-1) _Growtopia_ 's creator Seth responded to the post, insinuating that he liked the suggestion and would love to implement it soon.[[2]](https://growtopiawiki.com/w/Password_Door#cite_note-2)
  * If a swear word is used in the password, the password will change into WALT, possibly making a reference to the world DISNEYLAND.
