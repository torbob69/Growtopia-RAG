The **Haunted Jack O’ Lantern** is an unsplicable hat item which was added as October 2020’s Item Of The Month on October 1, 2020.
##  Function
Pump up the Pumpkin Power!

Lights out, going mouldy!

When equipped, the **Haunted Jack O' Lantern** grants the _Punch Damage: Haunted Jack O' Lantern_ mod, which allows the player to break blocks faster. It will also release green smokes in the player's body.
