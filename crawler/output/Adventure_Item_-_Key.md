The **Adventure Item - Key** is a splicable non-solid adventure item foreground block which was added alongside the Adventure Pack on June 14, 2014.
##  Function
As a type of adventure item, the Adventure Item - Key may work in conjunction with the Gateway To Adventure and the Locked Adventure Door. A Locked Adventure Door acts as a solid block except for anyone who has picked up an Adventure Item - Key.
