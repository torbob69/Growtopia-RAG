##  Function
When equipped, the Long Polka Dot Hair serves a purely cosmetic purpose.
##  Trivia
  * The Long Polka Dot Hair is a reference of Diavolo in Jojo's Bizarre Adventure.
    * The method of obtaining the hair is a subtle reference to the referenced character's occupation, which is crime.
