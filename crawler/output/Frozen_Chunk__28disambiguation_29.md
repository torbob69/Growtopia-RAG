# Frozen Chunk (disambiguation)

This is a **disambiguation** page.
There are more than one subjects in the **Growtopia Wiki** using this name.
**Frozen Chunks** are consumables added as part of the Gone Fishin'! update that are obtainable from fishing with any bait (excluding the Mega-Pellet Bait) in a hand-drilled Ice Crust Block with a Water on it.
##  Function
Consuming several of them while equipping a Buckskin Hood, Buckskin Jacket, Buckskin Pants and Winter Scarf will result in a Mega-Pellet Bait.
