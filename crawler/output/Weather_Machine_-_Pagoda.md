The **Weather Machine - Pagoda** is a weather machine which was added as part of the The Grand Tournament update.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into a mountainous pagoda scenery.
##  Trivia
  * The TOURNAMENT worlds use this weather machine.
  * The scenery created by this weather machine is almost identical to the scenery created by Weather Machine - Night, with the exception of several pagodas located on the hills.
  * The scenery can be seen in one of Hamumu's gameplay videos, Super Happy Go Go Ninja Time, found in his YouTube channel.
