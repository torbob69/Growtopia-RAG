# Winter Event Guild Medal: Bronze

Awarded for achieving THIRD PLACE in the Guild Leaderboards during the Winter season. Show off your victory by placing this medal in your world, and congratulations!
Properties
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item cannot be dropped or traded.
This item never drops any seeds.

The **Winter Event Guild Medal: Bronze** is an untradable platform which was released as part of the Winter Clash. One is given to the leader of a Guild that places 3rd in a Summer Grow Event.
##  Function
A Winter Event Guild Medal: Bronze behaves as a platform, thus a player can jump pass through it from underneath.
