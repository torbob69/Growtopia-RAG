The **Rainbow Cloud Rider** is an unsplicable feet item which was added as part of St. Patrick's Week 2022 on March 11, 2022.
##  Function
Ride the rainbow!

Multicolored fruit-flavored candy!

When equipped, the **Rainbow Cloud Rider** grants the _Speedy: Rainbow Cloud Rider_ mod, which allows the player to move faster on land.
