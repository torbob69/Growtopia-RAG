The **Olde Ye Tavern Door** is a splicable non-solid door foreground block which was added as part of St. Patrick's Week 2022 on March 11, 2022.
##  Function
As a door, the Ye Olde Tavern Door can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
##  Trivia
  * This item is considered a part of the Olde Ye Tavern set, which consists of the following items:

    * Ye Olde Tavern (background block)

    * Ye Olde Tavern Door (door)

    * Ye Olde Tavern Roof (platform)
  * The phrase "ye olde" is a pseudo–Early Modern English phrase used to suggest a connection between a place and the late medieval period.
