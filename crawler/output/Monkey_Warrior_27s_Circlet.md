# Monkey Warrior's Circlet

The golden circlet of the famous Monkey Warrior!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Yellow.
Sew a  Silk Bolt - Blue to the previous bolt using a(n) **Zigzag Stitch**.
Lastly, sew a  Silk Bolt - Red to the previous bolt using a(n) **Saddle Stitch**.
Each recipe gives **1** item.
The **Monkey Warrior's Circlet** is an unsplicable hat item which was added as part of Lunar New Year 2022 on February 1, 2022.
##  Function
When equipped, the Monkey Warrior's Circlet serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Monkey Warrior set, which consists of the following items:

    * Monkey Warrior's Circlet (hat)

    * Monkey Face Mask (face)

    * Monkey Warrior's Shirt (shirt)

    * Monkey Warrior's Pants (pants)

    * Monkey Warrior's Staff (hand)
