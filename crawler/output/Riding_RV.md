# Riding RV

A rapid, revving, recreation vehicle! Sit atop this automotive icon and cruise from coast to coast in comfort and style!

This item can be transmuted.

In any Chemical Combiner, mix together...
Colonization Wagon Base **(×200)** ,

This recipe will yield **1** item.
The **Riding RV** is an unsplicable feet item which was added as part of Thanksgiving Week 2020 on November 19, 2020.
##  Function
Going coast to coast!

Oh no, you've got a flat tire!

When equipped, the **Riding RV** grants the _Speedy: Riding RV_ mod, which allows the player to move faster on land.
The  Myths and Legends : The Search for Nessie mission requires 1 of this item.
