# Legendary Clash Key - Series 7

A key to a mysterious treasure! This key is for Clash Series 7, running from Summer Clash 2024 through Spring Clash 2025. After three seasons, those who collect at least 10 of these keys will be able to open a special treasure chest. Make sure you have enough - just one won't do it!
Properties
This item cannot be dropped or traded.
This item never drops any seeds.
This item has no use... by itself.

**1h**
**Legendary Clash Key - Series 7** is an unsplicable component that was added on July 19, 2024. It can be obtained after completing a branch which can be found by tapping on the Leaderboard Button and tapping on "Summer/Winter/Spring Clash Rewards". The player needs to buy everything in the branch before receiving the Legendary Clash Key & Finale Ticket in the event span from Summer 2024 to Spring 2025.
##  Function
One needs to collect 10 **Legendary Clash Key - Series 7** throughout all the Seasonal Clashes to be able to claim Anomaly Aura during Spring Clash 2025.
