# Tidal Gate

These rippling magical doors connect all the worlds in Growtopia. Place one and then use your Wrench on it to set the destination. Ah, refreshing!

Combination

In any Chemical Combiner, mix together...
Water Essence **(×20)** ,
Wind Essence **(×5)** and
Crystal Gate **(×1)**.
This recipe will yield **1** item.
The **Tidal Gate** is an unsplicable non-solid door foreground block which was added as part of the Hidden Riches update.
##  Function
As a door, the Tidal Gate can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
