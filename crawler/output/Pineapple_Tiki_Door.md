The **Pineapple Tiki Door** is an unsplicable toggleable foreground block which was added as part of Super Pineapple Party 2018 on June 1, 2018.
##  Function
Being a toggleable foreground block, a Pineapple Tiki Door works like a Dragon Gate, allowing eligible players to open and close the Pineapple Tiki Door by punching it. When toggled on, the item acts as a solid block which players cannot pass while killing all players trapped inside it. When toggled off, it opens and acts as a non-solid block which players can walk through. It can be wrenched to be made public or not.
