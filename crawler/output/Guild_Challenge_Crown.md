This is the page for **Guild Challenge Crown**.

Daily Challenge

Place in the top one of any Guild Daily Challenge, only if the player had contributed points to the challenge.
The **Guild Challenge Crown** is an unsplicable hat item which was added as part of the Challengers Approach! update on October 9, 2019.
##  Function
When equipped, the Guild Challenge Crown serves a purely cosmetic purpose.
