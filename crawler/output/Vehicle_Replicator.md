# Vehicle Replicator

Use the Protostar's Vehicle Replicator to make an exclusive set of items. This item can also function as a chemical combiner.

In any Chemical Combiner, mix together...
U.S.S. Protostar Bulkhead **(×200)** ,
Steel Block **(×200)** and
Protostar Captain's Seat **(×10)**.
This recipe will yield **1** item.
The **Vehicle Replicator** is an unsplicable chemical combiner foreground block which was added as part of Star Trek Prodigy on June 27, 2022.
##  Function
A Vehicle Replicator can be opened or closed by being punched. As a Chemical Combiner, it can be used to combine three different sets of items. A stack of new items will be created afterwards.
The Vehicle Replicator is used to create The Runaway and the Class D Loader. Trying to use a Chemical Combiner other than a Vehicle Replicator will show the message "_Vehicles can only be fabricated in a Vehicle Replicator!_ ".
