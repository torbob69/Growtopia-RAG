The **Waterfall** is an unsplicable foreground block which was added as a part of the Hidden Riches update on September 1, 2017.
##  Function
Being a type of vertical one side collision block, the **Waterfall** allows players to pass through the block downwards but blocks them from passing the block upwards.

##  Trivia
  * When the item was introduced, it did not have any rarity. It was later given the rarity 15 as it could drop seeds.
  * While the block exclusively permits a player to move downwards, there is a flaw in the server-sided pathfinder which overcomes this (which is directly responsible for verifying the client's location for security reasons). Exploits may be used to move through the block into what would be an illegal area, given that one of two sides are left exposed.
