# Punched Tournament Ticket

Your ticket has been punched! You can battle in the current Tournament as many times as you like. The ticket will self-destruct when the tournament ends. Don't lose it, or you can't battle anymore!
Properties
This item cannot be dropped or traded.
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **6 Hits** **5 Hits** – Restores after **5s** of inactivity
Gems Drop: **N/A**
**1h**
**Punched Tournament Ticket** is an unsplicable consumable item that was added in The Grand Tournament update.
##  Function
It is the used state of the Tournament Ticket. This item replaces the Tournament Ticket if the user participates, and it disappears once the tournament ends.
