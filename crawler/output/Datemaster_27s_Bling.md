The **Datemaster's Bling** is an unsplicable hand item which was added as part of Valentine's Week 2020.
##  Function
Bling Time!

Boring old me!

When equipped, the **Datemaster's Bling** grants the _Punch Damage: Bling_ mod, which allows the player to break blocks faster. It also replaces the player's punching animation with rings being thrown. The ring emits star-like blue particles every second.
