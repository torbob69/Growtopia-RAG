The **Note Block** is a splicable toggleable animated foreground block.
##  Function
<https://growtopiawiki.com/w/File:Noteblockold.ogg>The old version of the Note Block's music. <https://growtopiawiki.com/w/File:Naughty_princess.ogg>The new version of the Note Block's music.
Being a toggleable animated foreground block, a Note Block can be toggled on or off via punching. When toggled on, a Note Block will change its appearance and play a piece of music.
