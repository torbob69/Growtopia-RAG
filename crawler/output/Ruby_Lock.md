# Ruby Lock

Locks an entire world. And looks lovely doing it. There's a 1% chance each day that a rock in the world will become Heartstone! More rocks do not increase the chance.
Properties
This item never drops any seeds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!
This item has special properties you can adjust with the Wrench.
A lock makes it so only you (and designated friends) can edit an area.

The **Ruby Lock** is a solid lock foreground block which was added as part of Valentine's Week 2017 on February 10, 2017.
##  Function
A Ruby Lock has all the basic properties of a World Lock. In addition, a ruby-locked world has a 1% chance of transforming a Rock inside into a Heartstone everyday.
##  Trivia
  * The Ruby Lock is the third lock in a trio of locks that require shards/other ingredients, the other two being the Emerald Lock and Robotic Lock.
