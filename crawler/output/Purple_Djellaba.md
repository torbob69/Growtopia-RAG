# Purple Djellaba

This long robe is suitable for male or female Growtopians, provided they want to look snazzy and colorful!
Properties
This item never drops any seeds.
Data

Type: Shirt – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Purple.
Sew a  Silk Bolt - Purple to the previous bolt using a(n) **Saddle Stitch**.
Lastly, sew a  Silk Bolt - Grey to the previous bolt using a(n) **Blind Stitch**.
Each recipe gives **1** item.
The **Purple Djellaba** is an unsplicable shirt item which was added as part of Player Appreciation Week 2016 Day 2 on August 6, 2016.
##  Function
When equipped, the **Purple Djellaba** serves a purely cosmetic purpose.
##  Trivia
  * Purple Djellaba is one of the three djellabas added on Player Appreciation Week 2016, with the others including Yellow Djellaba and Green Djellaba.
