# Spring Bouquet

Aw, a lovely bunch of flowers to share!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hand – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Easter Egg - Rainbow **(×1)** ,
Easter Egg - Checkered **(×1)** and
Easter Egg - Striped **(×1)**.
This recipe will yield **1** item.
The **Spring Bouquet** is a hand item which was added as part of Easter Week 2016 on April 2, 2016.
##  Function
Toss flowers to your friends!

You are disarmed.

When equipped, the **Spring Bouquet** grants the _Sharing Flowers_ mod, which allows the player to punch one tile further, pull other players towards them upon punching them, and break blocks more slowly.
