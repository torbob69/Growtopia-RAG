# Guild Entrance - Normal

Members only! This plain - but effective - private door only lets people in your guild (or folks you like) pass through. Wrench it to add guild members and any 'others'. Note: Guild members will automatically be removed if they leave the guild!
Properties
This item has special properties you can adjust with the Wrench.
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

The **Guild Entrance - Normal** is an unsplicable entrance foreground block which was added alongside the Guilds update on April 1, 2018.
##  Function
Being an entrance, a Guild Entrance - Normal allows guild members to walk through it, or, when its property is changed, allowing any player to walk through it. When placed in a public area, it is impossible to be closed for anyone.
