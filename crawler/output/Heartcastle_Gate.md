The **Heartcastle Gate** is a splicable non-solid door foreground block which was added on Valentine's Week 2019 on February 8, 2019.
##  Function
As a door, the Heartcastle Gate can be entered (via punching) by a player, moving them instantly to another tile. A block with an ID must first be placed on the tile for this to work.
