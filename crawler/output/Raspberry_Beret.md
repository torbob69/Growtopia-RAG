# Raspberry Beret

This is the kind you find at a second-hand store.
Properties
This item never drops any seeds.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Red.
Sew a  Silk Bolt - Purple to the previous bolt using a(n) **Triple Stretch Stitch**.
Lastly, sew a  Silk Bolt - Black to the previous bolt using a(n) **Blind Stitch**.
Each recipe gives **1** item.
The **Raspberry Beret** is an unsplicable hat item that was added as part of the Artsy April update.
##  Function
When equipped, the Raspberry Beret serves a fully cosmetic purpose.
