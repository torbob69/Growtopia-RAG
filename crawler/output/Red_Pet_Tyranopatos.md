The **Red Pet Tyranopatos** is an unsplicable hand item which was added as part of Growassic Park on October 7, 2016.
##  Function
When equipped, the Red Pet Tyranopatos serves a purely cosmetic purpose and summons a Red Pet Tyranopatos which follows the player around.
