The **Shifting Scroll** is a splicable component which was added as part of SummerFest 2015 on July 3, 2015, along with the Wizard's Staff riddle. The scroll is used to find the recipe for the Wizard's Staff.
##  Function
On each account, the words in the description (in red) will be different (there are 20 different words). When collected, a sentence can be formed saying:
_"PLACE LABORATORY ON LEAF BLOCK AND INSERT AFRO AND DUNGEON DOOR SEED AND THIS SCROLL THEN PUNCH IT AT MIDNIGHT."_
