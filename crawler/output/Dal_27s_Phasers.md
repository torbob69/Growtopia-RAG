# Dal's Phasers

In case of emergency, pull up a pair of Federation Type 1 Phasers to defend yourself! Wrench yourself and transform into the charming maverick Dal, the Captain of the Protostar crew!

The **Dal's Phasers** is an unsplicable hand item which was added as part of Star Trek Prodigy on June 27, 2022.
##  Function
Set phasers to stun!

Set phasers to none!

When equipped, the **Dal's Phasers** grants the _Build Range & Punch Range : Dal's Phasers_ mod, which allows the player to build one tile further, punch one tile further, and switch between its wearable form and its morph form by wrenching oneself and clicking 'Transform'.
##  Trivia
  * This item is considered a part of the Dal set, which consists of the following items:

    * Dal's Hair (Hair)

    * Dal's Goggles (Face)

    * Dal's Shirt (Shirt)

    * Dal's Pants (Pants)

    * Dal's Shoes (Feet)

    * Dal's Phasers (Hand)
