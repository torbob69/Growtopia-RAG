The **Grow X Rocket Wings** is an unsplicable back item which was added as April's Item Of The Month on April 1, 2021.
##  Function
Commencing countdown, engines on!.

No longer floating in a most peculiar way!

When equipped, the **Grow X Rocket Wings** grants the _High Jump & Slow Fall : Grow X Rocket Wings_ mod, which allows the player to jump one tile higher and glide slowly to the ground when holding the jump button.
