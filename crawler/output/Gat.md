# Gat

This style of hat is cleverly strapped to your head so it won't blow away.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hat – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Peace Mooncake **(×3)** ,
Longevity Mooncake **(×3)** and
Prosperity Mooncake **(×3)**.
This recipe will yield **1** item.
The **Gat** is an unsplicable hat item that was added as part of Harvest Festival 2013 on September 18, 2013.
##  Function
When equipped, the Gat serves a purely cosmetic purpose.
