# Soft-boiled Scepter

An egg-cellent staff whose origins are lost to time, kind of like Humpty Dumpty.
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Hand – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity

**1h**
Combination

In any Chemical Combiner, mix together...
Easter Egg - Golden **(×1)** ,
Water Bucket **(×50)** and
Egg **(×50)**.
This recipe will yield **1** item.
The **Soft-boiled Scepter** is an unsplicable hand item which was added as part of Easter Week 2022 on April 15, 2022.
##  Function
Egg-cellent!

Cracked into pieces!

When equipped, the **Soft-boiled Scepter** grants the _Punch Range : Soft-boiled Scepter_ mod, which allows the player to punch one tile further.
