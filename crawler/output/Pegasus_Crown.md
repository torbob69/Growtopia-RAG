The **Pegasus Crown** is an unsplicable hat item that was added as part of the Pegasus Pursuit update on June 28, 2021.
##  Function
Feather Reach!

Plucked!

When equipped, the **Pegasus Crown** grants the _Build Range : Pegasus Crown_ mod, which allows the player to build one tile further.
##  Trivia
  * This item is considered a part of the Pegasus set, which consists of the following items:

    * Pegasus Crown (hat)

    * Pegasus Pauldrons (neck)

    * Pegasus Shirt (shirt)

    * Pegasus Pants (pants)

    * Pegasus Shoes (shoes)

    * Pegasus Lance (hand)
