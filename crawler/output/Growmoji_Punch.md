# Growmoji Punch

Behold the mighty fist of Growtopia! Punch it into your chat so all may see your power! Just consume this to add it to your available growmojis!
Properties
A tree of this type can bear surprising fruit!
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **5 Hits** **4 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
The **Growmoji Punch** is a Growmoji that was released as part of the March Update. One is obtained through a special event.
##  Function
When consumed, the player will be able to use the (punch) Growmoji.
