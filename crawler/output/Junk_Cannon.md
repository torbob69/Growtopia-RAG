# Junk Cannon

No block stays awesome forever, even if you're firing it out of a recoilless GrowTech-certified gauss chamber with 1.21 growgajoules of force... which is why the Junk Cannon is leagues ahead of all other block-blasting battlegear! What CAN'T it fire? Where does it get all those blocks from? How can it never run out of ammunition? Sorry, the answers to those questions can only be provided if you have GrowTech Security Clearance Level Indigo or higher, but hey - you can still shoot the gun as much as you want! Woohoo!
