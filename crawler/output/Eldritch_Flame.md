The **Eldritch Flame** is a consumable which was added as part of Halloween Week 2015.
##  Function
When consumed, the Eldritch Flame ignites a small area, creating bursts of fires which may span across multiple blocks. This may only work as long as water isn't present on the tile. The Eldritch Flame is considerably more powerful than the Pocket Lighter, which can only be used to set a single block on fire.
Fire does not destroy any block, apart from the Highly Combustible Box. However, players can still be harmed by touching fire, which burns them in a similar manner to Lava. If not put out, fires may randomly spread to surrounding blocks in all 4 directions.
In order to reduce lags, there is an established limit of 150 fires per world.
The player who uses the Eldritch Flame consumable, will also emit a message.

##  Trivia
  * It isn't recommended to use an Eldritch Flame in a world with a Firehouse placed, since any fire started will be put out almost instantly.
  * Putting out a single fire gives the player 1 XP. Putting out 100 fires gives the player a Highly Combustible Box, which can later be used to transform certain items into exclusive rewards by dropping the items within the box, then setting it on fire.
