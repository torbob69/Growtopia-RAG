# Pick Blade

This pick blade is forged from Deep Iron, which makes it particularly attuned to pickin' real darn good.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **9 Hits** **7 Hits** – Restores after **4s** of inactivity
Gems Drop: **N/A**
**1h**
Forging

Obtained from forging Deep Iron Ingot **(x100)**.
The **Pick Blade** is an unsplicable consumable which was added as part of the Spelunkorama! update on May 2, 2016.
##  Function
The Pick Blade is primarily used in forging.
