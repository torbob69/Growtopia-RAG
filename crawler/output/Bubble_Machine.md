# Bubble Machine

Bubble up! This machine will fill the air with bright and beautiful bubbles - perfect for a summer pool party, a sweet midnight rave, or a really classy pizza night.
Properties
This item has special properties you can adjust with the Wrench.
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

The **Bubble Machine** is an unsplicable non-solid toggleable animated foreground block which was added as part of SummerFest 2018 on July 6, 2018.
##  Function
Being a toggleable animated foreground block, a Bubble Machine can be toggled on or off via punching. When toggled on, a Bubble Machine will change its appearance, showing bubbles being created by the machine.
