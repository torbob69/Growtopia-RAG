# Harvest Horn

Don't blow this horn. Never blow this horn. It is evil.
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **3 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Balance Mooncake **(×1)** ,
Ancestor Mooncake **(×1)** and
Peace Mooncake **(×6)**.
This recipe will yield **1** item.
Mooncake Offering

1 may be received as a common reward from offering mooncakes using an Offering Table.
The **Harvest Horn** is an unsplicable consumable item which was added as part of Harvest Festival 2016 on September 15, 2016.
##  Function
When consumed in an empty space, the Harvest Horn will summon The Harvester.
##  Trivia
  * The Harvest Horn resembles the Cornucopia.
