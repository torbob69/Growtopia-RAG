# Bulletin Board (block category)

A **bulletin board** is a type of non-solid foreground block that can contain messages left by visiting players. When placed in a world, players are able to leave a message on the board that can be read by any player. Players with access to the board can edit the settings such as changing the option for the public to add messages (players without access), hide names, clear the board, or manually removed individual messages.
A bulletin board may contain up to 20 messages before the older messages start to get replaced.
