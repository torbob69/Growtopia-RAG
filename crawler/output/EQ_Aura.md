The **EQ Aura** is an unsplicable artifact item which was added as part of Wonder Week 2022 Day 3 on October 17, 2022.
##  Function
Raising the levels!

Dropped the bass!

When equipped, the **EQ Aura** grants the _Double Jump : EQ Aura!_ mod, which allows the player to jump a second time in mid-air.
Additionally, when the player enters the command /dance, a music plays. The EQ Aura features special customizable functions. The player can set a music by wrenching oneself. To set the music for the EQ Aura, the player can select any musical block from the inventory.
##  Trivia
  * Upon release, the EQ Aura was unintentionally set to untradable. This was fixed the day after.
