# Extractium Shard

This mysterious element seems to be present in small quantities in ancient fossils. Maybe you can combine these shards into a piece large enough to have a measurable effect on something!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: No Collision
Hardness: **6 Hits** **5 Hits** – Restores after **5s** of inactivity
Gems Drop: **N/A**
**1h**
Fossil Processing

Process  Fossils or  Polished Fossils in a  Fossil Prep Station.
**Extractium Shard** is an unsplicable consumable which was added in the Growassic Park update. One can be obtained as a possible drop from processing a Fossil or a Polished Fossil in a Fossil Prep Station.
