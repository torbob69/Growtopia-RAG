# Decorative Shrine

Many of these are usually placed in the middle of koi ponds! A very fast-growing seed that only grows under the harvest moon. When harvested the trees have an increased chance of dropping a Longevity Mooncake.
Decorative Shrine (Rarity: 30)

The **Decorative Shrine** is an unsplicable solid foreground block which was added as part of Harvest Festival 2023 on September 21, 2023.
##  Function
When placed, the Decorative Shrine serves a purely aesthetic purpose.
