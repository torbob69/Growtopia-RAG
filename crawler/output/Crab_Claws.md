The **Crab Claws** is an unsplicable hand item which was added as part of SummerFest 2024 on July 11, 2024.
##  Function
The claws!

Oh crab!

When equipped, the **Crab Claws** grants the _Punch Damage : Crab Claws_ mod, which allows the player to break blocks faster.
##  Trivia
  * This item is considered a part of the Crab set, which consists of the following items:

    * Crab Hood (Hat)

    * Crab Shell (Back)

    * Crab Claws (Hand)
