# Firehouse

This building provides protection against all fires! It can put out any fire in your world in seconds.
Properties
This item can only be used in World-Locked worlds.
This item can't be destroyed - smashing it will return it to your backpack if you have room!

The **Firehouse** is an unsplicable platform foreground block which was added alongside the Firefighter Pack.
##  Function
A Firehouse automatically puts out Fires one by one. Each world can only contain one of this block. In addition, a Firehouse behaves as a platform, thus a player can jump pass through it from underneath. Only usable in world locked worlds.
