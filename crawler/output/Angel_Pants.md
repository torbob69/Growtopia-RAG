# Angel Pants

Become an Angel with these blue pants!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Pants – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - Aqua.
Sew a  Silk Bolt - Blue to the previous bolt using a(n) **Straight Stitch**.
Lastly, sew a  Silk Bolt - White to the previous bolt using a(n) **Zigzag Stitch**.
Each recipe gives **1** item.
The **Angel Pants** is an unsplicable pants item which was added as part of Grow4Good Week 2026 on April 24, 2026.
##  Function
When equipped, the **Angel Pants** serves a purely cosmetic purpose.
##  Trivia
This item is considered a part of the Angel set, which consists of the following items:

  *     * Angel Halo (Hat)

    * Angel Hair (Hair)

    * Angel Coat (Shirt)

    * Angel Pants (Pants)
