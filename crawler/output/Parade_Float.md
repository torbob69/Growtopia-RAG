# Parade Float

Can't do an Easter Parade without your very own float!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Feet – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Combination

In any Chemical Combiner, mix together...
Easter Egg - Rainbow **(×1)** ,
Easter Egg - Golden **(×1)** and
Cardboard Egg **(×20)**.
This recipe will yield **1** item.
The **Parade Float** is an unsplicable feet item which was added as part of Easter Week 2024 on April 7, 2024.
##  Function
Egg-cellent!

Never egg-ain!

When equipped, the **Parade Float** grants the _Speedy + Punch Range: Parade Float_ mod, which allows the player to move faster on land and punch one tile further.
