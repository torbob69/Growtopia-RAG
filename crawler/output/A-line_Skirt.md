# A-line Skirt

A beige skirt that's aligned!
Properties
This item never drops any seeds.
This item can be transmuted.
Data

Type: Pants – Clothes
Render Type: Single
Collision Type: Full Collision
Hardness: **0 Hits** **0 Hits** – Restores after **0s** of inactivity
Gems Drop: **N/A**
**1h**
Sewing

With a  Sewing Machine...
Start with a  Silk Bolt - White.
Sew a  Silk Bolt - Yellow to the previous bolt using a(n) **Straight Stitch**.
Lastly, sew a  Silk Bolt - White to the previous bolt using a(n) **Straight Stitch**.
Each recipe gives **1** item.
The **A-line Skirt** is an unsplicable pants item which was added as part of Player Appreciation Week 2022 Day 7 on August 21, 2022.
##  Function
When equipped, the A-line Skirt serves a purely cosmetic purpose.
