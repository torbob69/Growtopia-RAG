# Sheep Shears

This handy tool is a lot more effective at cutting wool than your fingers are, so you can get twice as much when you use it to shear a sheep!
Properties
This item never drops any seeds.

Combination

In any Chemical Combiner, mix together...
Balance Mooncake **(×1)** ,
Ancestor Mooncake **(×1)** and
Prosperity Mooncake **(×7)**.
This recipe will yield **1** item.
Mooncake Offering

| 1 may be received as a common reward from offering mooncakes using an Offering Table, when the offering contains:
•  Balance Mooncake  |
The **Sheep Shears** is an unsplicable hand item which was added as part of Harvest Festival 2016 on September 15, 2016.
##  Function
Harvesting a Sheep while equipping the Sheep Shears will drop twice as many Wool. This item doesn't give any punch effect.
