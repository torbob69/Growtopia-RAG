The **Minokawa Wings** is an unsplicable back item which was added as part of Wonder Week 2022 Day 7 on October 21, 2022.
##  Function
Break Free!!

Broke Down!

When equipped, the **Minokawa Wings** grants the _Double Jump: Minokawa Wings!_ mod, which allows the player to jump a second time in mid-air.
The Minokawa Wings features special customizable functions. The player can select which items to appear by wrenching oneself. The player can choose between the Minokawa Wings and the Minokawa Pet, of which at least one has to be selected.
