# Galactic Starseed

This is the exact opposite of sparkly dust from a passing comet. It seems to whirl around backwards like a tiny galaxy. Perhaps if you collected enough of it, it would merge into an astonishingly valuable solid mass!
Antimatter Dust (Rarity: 50)
Properties
This item never drops any seeds.

The **Galactic Starseed** is a special seed which was added as part of the original Night Of The Comet update on November 27, 2014.
##  Function
A Galactic Starseed is used to splice certain exclusive trees during the Night Of The Comet, such as the Riding Comet, Star Iron, Weather Machine - Meteor Shower and a range of other items. If the seed is planted by itself, it will drop a Galactic Starseed back upon harvest.
