# Storage Box (block category)

**Storage Box** es are solid foreground blocks that can store up to 20 items. Only people who own the world have access to this block and its contents, however, anyone with access can wrench this block type and see the items and their respective quantities.
##  List of Storage Boxes
Items: Special FunctionDynasty Vase: None.
Storage Box Xtreme - Level 1: None.
Storage Box Xtreme - Level 2: Holds up to 40 items.
Storage Box Xtreme - Level 3: Holds up to 90 items.
Untrade-a-Box: Can only hold untradable items.
Safe Vault: A password is required to access the items inside the safe.
