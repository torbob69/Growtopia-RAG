# Growmoji Lucky Token

Celebrate the New Year by popping a little luck into your chat! Just consume this to add it to your available growmojis!
Properties
This item never drops any seeds.

**Growmoji Lucky Token** is an unsplicable growmoji consumable which was added as part of Chinese New Year 2019.
##  Function
When consumed, the player will be able to use the (lucky) growmoji.
