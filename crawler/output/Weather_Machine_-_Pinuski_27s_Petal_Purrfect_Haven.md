The **Weather Machine - Pinuski's Petal Purrfect Haven** is an unsplicable non-solid weather machine foreground block which was added as part of Harvest Festival 2024 on September 12, 2024.
##  Function
As a weather machine, the Weather Machine - Pinuski's Petal Purrfect Haven can be toggled on or off via punching. When toggled on, it will change its appearance, transforming the world's background weather into a pink spring scenery containing lake and cherry blossom trees in the background.
##  Trivia
  * This item is sponsored by Pinuski for completing all the Epic Quests.
  * Weather Machine - Pinuski's Petal Purrfect Haven is the first sponsored item to be a Weather Machine.
