# Tempered Steel Fragment

This is a beautiful tempered steel fragment of a sword blade. If you had enough of these, you could probably forge them into a new sword blade!
Properties
This item never drops any seeds.
Data

Type: Consumable
Render Type: Single
Collision Type: Full Collision
Hardness: **4 Hits** **3 Hits** – Restores after **8s** of inactivity
Gems Drop: **N/A**
**1h**
Combustion

Burn a(n)  Blade Fragment **(x1)** in a  Highly Combustible Box.
**Tempered Steel Fragment** is an unsplicable consumable which was added as part of the Daily Challenges update on November 21st, 2015.
