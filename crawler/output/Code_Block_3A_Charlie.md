# Code Block: Charlie

This block looks like a mysterious computronic data reference. But that's just for fun, I'm sure. I mean, this is just a game... isn't it?
Properties
This item never drops any seeds.
This item can be placed in two directions, depending on the direction you're facing.

**1h**
Paint Preview Aqua Blue Charcoal Green Purple Red Varnish Yellow
The Code Block: Charlie is a block added along with the Systems Update and is part of the Discover The Truth riddle. It can be obtained by placing a Cow painted blue above the moon in a world with a Weather Machine - Night turned on. Instead of dropping Milk when harvested, the Cow will drop the Code Block: Charlie.
