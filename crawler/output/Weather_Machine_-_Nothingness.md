**Weather Machine - Nothingness** is an unsplicable non-solid weather machine foreground block which was added as part of the Growtokens! update on March 30, 2014.
##  Function
As a weather machine, this item can be toggled on or off via punching. When toggled on, it will change its appearance, showing a 2-frame animation, and transform the world's background weather into a completely empty and dark scenery.
