The **Kuchisake Kimono** is an unsplicable shirt item which was added as part of Halloween Week 2022 on October 22. 2022.
##  Function
When equipped, the Kuchisake Kimono serves a purely cosmetic purpose.
##  Trivia
  * This item is considered a part of the Kuchisake set, which consists of the following items:

    * Kuchisake Mask (face)

    * Kuchisake Kimono (shirt)
  * The Kuchisake set is a reference to Kuchisake-onna, a malevolent figure in Japanese urban legends and folklore.
