The **Super Summer Surprise** is an unsplicable non-solid foreground block which was added as part of SummerFest 2020 on July 3, 2020.
##  Function
When placed, the Super Summer Surprise serves a purely aesthetic purpose.
Breaking a Super Summer Surprise would drop a random SummerFest-exclusive item. A list of possible drops obtained from breaking one can be seen below.
